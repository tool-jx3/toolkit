About

This is a simple app that creates colored Discord messages using the ANSI color codes available on the latest Discord desktop versions.

To use this, write your text, select parts of it and assign colors to them, then copy it using the button below, and send in a Discord message.

Source Code

This app runs entirely in your browser and the source code is freely available on GitHub. Shout out to kkrypt0nn for this guide.

Changelog

2026 October update

As of October 2026, Discord has significantly increased the amount of ansi codes supported. Thus, you're now able to use far more colors, as well as additional formatting options. These have been added to the website.

Okay here's like a more proper changelog (2026-10-07):

  • Italic and strikethrough options available
  • Custom colors can now be used, picked, and saved
  • Various effects are now available
  • FG/BG is a toggle instead of separate button rows
  • Text selection is now subtle to make it easier to see changes
  • Copy-pasting colored text now retains color
  • Multiple formatting options can be applied together now
  • Fixed various cases of nested formatting not copying correctly
  • Random tweaks and optimizations and fixes
  • Still handwritten <3 (i dont use ai)

If you don't like this new update, the legacy version of my tool is available here, and the gist will always have the history of the source code changes.

Thank you TinyVirtual for letting us know about this change.

2026 August update

As of August 2026, Discord has changed the color palette used for ansi colors. I have updated this website to match that, as well as added an option to choose the Discord theme to preview the colored text as.

2022 Initial release

This webapp was first made in May 2022. It has since received various updates, the full list of code changes can be found in the GitHub history.
