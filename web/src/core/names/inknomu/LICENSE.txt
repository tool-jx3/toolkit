二、沒有使用的部分

  - 中文參考譯名表（https://inknomu.com/data/translit/<地區>.json）：沒有標示授權，不使用。
  - 原站的程式（app.js、build.js）：沒有標示授權，只參考產生名字的規則（見 docs/refactor/specs/npc-names.md 3.5），
    程式是本站自己寫的；原站的彩蛋、「組合模式」（搜尋零件、收藏、合成）、發音功能沒有做。

三、本站做的變更

  1. 格式：29 個 JSON 依地區合併成 8 個 TypeScript 資料檔（inknomu-jp.ts、-tw、-kr、-uk、-us、-ru、-nordic、-fantasy），
     一筆一行；包的順序與每個包裡的順序照原檔。
  2. 拿掉本站用不到的欄位：
     - 包：region、era、coverage（地區與年代另見 label）、license、license_note（寫在本檔）、tts（發音）、group（分組名稱）。
     - 姓：weight（常見度；原站說明是備用欄位，抽名不參與，本站同樣平均抽）、tags、zh（韓國姓的漢字，涵義裡已經有）。
     - 名：weight、confidence（推定的標記）、tags。
     - 綽號：original（古諾斯語原文）。
     - 沒有值的欄位（null 或空字串，例如空白的 note、name_sep）不寫。
  3. 其他欄位（姓名的寫法、reading、meaning、note、class、countries、f_form、f_reading、pat、diminutive、綽號的 e、meaning、note，
     包的 id、label、note、corpus_note、rules、name_order、name_sep）照原文，沒有改寫。
  4. catalog.ts 是從同一份資料算出來的摘要（有沒有中性名、階級與國家的標記、讀音的種類、是不是以父名構成、原檔的 SHA-256）。
  5. sources.ts：8 個地區頁面（https://inknomu.com/namegen/<地區>）底部「資料來源」的清單（2026-10-29 整理），
     分組、每一筆的文字與連結照原文；只留 https 的連結。
