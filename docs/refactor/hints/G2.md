# G2（轉場與動態）各工具的共用層使用提醒

G2 共用層已合併（2026-10-01）。各模組與元件的完整 API 見 DESIGN.md 第 4 節；實際用法看元件展示頁的「轉場與動態」分頁
（`web/src/tools/_gallery/g2/`）。照 PROCESS.md 第 0 節：實作時讀原作的程式，把功能改寫成下列共用模組。

## 共通

- **影格序列**：用 `core/timeline` 的影格表來源（`AnimationSource.frames`）與取樣函式（格數四捨五入至少 2、進度型含頭尾、
  循環型 k÷n、停留加在某一格、延遲總長拆成整數毫秒餘數給前面）；匯出走 `exportAnimation`。
- **曲線**：轉場用 `CURVES`（二次、smoothstep、smootherstep、S 形、階梯、不規則、非單調），不要和 `EASE` 混用。
- **預覽**：`usePlayback({ loopGap })`（不循環時每輪之間停 1.2 秒）、`<Transport {...playback} onRateChange={playback.setRate} />`
  顯示預覽速度；Stage 的 `backgrounds` 列出 `'scene'` 就有示意場景背景。
- **編碼**：WebP「每格比較無損與有損取較小者」用 `webpPickSmaller`；GIF 透明「≥ v 算不透明」用 `gifAlphaThresholdInclusive(v)`；
  播放次數上限 `MAX_PLAYS`（65535）。匯出前的預估列（影格數、每格毫秒、未壓縮資料量）與像素總量上限、畫質決定輸出尺寸
  用 `core/image` 的 sizing 函式。
- **效果選擇**：`EffectGrid`（單選、分組、示意動畫、`allowDeselect` 再按一次取消）；節點表用 `KeyframeTable`。
- **雜訊**：`core/timeline` 的二維值雜訊與 5 層 fBm（決定性，種子相同結果相同）。

## scene-transition（場景轉換素材產生器）

- 轉場本體：`core/transition`——`buildArrivalMap(shape, w, h, params)` 建一次「到達先後圖」，每格只換查表
  （柔和度、推進比例、反向、四種方式、帶寬、邊緣發光、邊緣實心、雙色閃換）。20 種形狀對應原作的效果；原作有、共用層沒有的形狀，
  加進 `core/transition`（向下相容）而不是寫在工具目錄。
- 「蓋上再揭開」共 2n−1 格、倒著播時停留移到第一格：用影格表來源組。
- 字幕：`core/typeset` 與 `FontPicker`（Google Fonts＋電腦字型）。

## bg-motion（動態背景產生器）

- 濾鏡：`core/image` 的 `FilterOp` 系列（26 種零件），輸出以 `bg-motion.examples.json` 的量測值驗證。
- 圖片動態：`core/motion`（蓋滿、平移縮放旋轉、疊色漸變、水波、淡化、多張交叉溶接／硬切／擦除、結尾消失演出）。
- 多張圖片的順序：`core/files` 的 `naturalSort`；縮圖清單用 `ThumbnailList`（格線版面 `thumbAspect`、`axis: 'xy'` 拖曳排序）。
- 延遲「總長拆成整數毫秒、餘數給前面的格」用 `core/timeline` 的取樣函式。

## loading-maker（讀取動畫產生器）

- 角色動畫輸入（APNG／GIF／WebP）：`core/decode` 的 `decodeAnimatedImage` 拆成影格與延遲，`frameAtTime` 取某一刻的影格。
- 讀取條、圖示形狀：`core/shapes`（星、愛心、六角形、菱形、三角、圓角矩形）。
- 畫布上元素的拖曳與吸附：`LayoutEditor`（G2 加了吸附線）。
- 角度：`core/gradient` 的 0° 朝上，loading-maker 原作 0° 由左到右，換算時注意。
