# G3（立繪工作台）共用層使用提醒

由 G3 共用層實作者整理（2026-10-01）。API 細節見 DESIGN.md 第 4 節。

## ccfolia-cropper
- 預覽：`<Stage dragPan wheelZoom="plain" zoomBase="fit" zoomRange={[0.2,5]} wheelFactors={[1.1,0.9]}>`，zoom 與 pan 都受控，R 才能一起歸位。
- 裁切框：`<CropFrame axis="x">`，用 `start`／`end` 記成一步復原。
- 頭部中心：`imageOpaqueSpanInRows(img, top, top+max(20,0.35H))`；依裁定上半身用 55%；角色高度 +1 px 的修正由工具做。
- 效果：預覽與下載都跑 `applySilhouetteEffects(getImageData(裁切圖), outlineLayers(...))`，預設的 `keepPartial` 就符合裁定。
- 記住設定：`createToolStore` 的 `partialize` 存比例、範圍、基準、效果；圖片清單不在 store 裡。
- 批次下載：`downloadSequentially({ intervalMs: 200 })`；檔案類型用 `detectImageType`。

## icon-maker
- 版面：1024 的 canvas＋`LayoutEditor units="percent" frame={內側}`。圖片用 `clampBoxPosition(..., 'center')` 夾在 −20～120；名字牌與 HO 牌夾左上角在 −10～110−自身大小。
- 鍵盤：`nudgeStep={0.2} nudgeShiftStep={2}`；`onEscape` 關說明面板；`safeArea` 畫 7% 的安全範圍虛線。
- 作畫：`roundRectPath`、`fillPattern`。複製：`copyImage(canvasToBlob(c))`，直接傳 Promise，不要先 await。
- 所見即所得（裁定）：預覽與下載用同一段 canvas 繪製程式。

## variant-manager
- 清單：`ThumbnailList layout="list" numbered thumbSize={82}`＋`onReorder`＋`renderFields`；建議詞用 `Chips`。
- 檔名：`safeFileName(s, { underscore: true, fallback: '' })`；ZIP 用 `uniqueFileName`＋`zipFiles`（原檔位元組）。
- ↑↓ 只在清單有焦點時作用；要像舊版那樣整頁都能用，工具要自己加 window 監聽。

## height-board
- 盤面：`PanZoomViewport`，世界座標 y＝−cm，`baseScale="fit-height" extend="x" align={{x:'start',y:'end'}}`；尺規放 `gutter`，用 `rulerTicks({ floor: 0 })`。
- 點選與拖線：`hitTest`＋`onPointerDown` 回傳拖曳處理；拖基準線時凍結盤面比例由工具做。
- 縮放與捲動：`zoomBy(1.25)`、`zoomTo(1)`、`fitWidth({max:1})`、`scrollToWorld`。
- 清單：`LayerList`（數字欄 `onCommit` 配 history gesture、篩選中 `sortDisabled`、`onMoveStart`／`onMoveEnd`＝一步復原）。
- 圖片：`createAssetStore`、`gc(referencedAssetIds(...))`。專案檔：`ProjectMenu` 給 `getFiles`、`fileNameFor`、`beforeSave`、`confirmOpen`；`onLoad(data, project, files)` 讀回後 `importAssetFiles` 並清空復原歷史。
- 拖放：`WindowDrop`＋`clientToWorld`。匯出解析度：`limitResolution`；透明邊門檻：`imageOpaqueBounds(img, 16)`。方向鍵 0.8 秒內合併成一步由工具處理。

## color-palette
- 取色視窗：`ImageSampler` 放進 `<Dialog size="xl">`；自動取色用 `vividColorsBySplits(getImageData(img), splits, {tolerance})`（比例已四捨五入），手動用 `samplePixel`。
- 主預覽：`Stage wheelLinear={0.5}`。段的排序：`SortableList mode="drop"`。
- 畫布上的分段把手：用 DOM 元素自己做，配合 `useStageScale`＋`clientToLocal`。

## emotion-maker
- 部件：`PartPicker`（眼、眉、嘴單選，裝飾複選；`base` 放頭部填色層與輪廓層）。部件圖全部自己畫（向量），題材照規格 3.1。
- 合成：一律用 `drawLayers` 的等比置中（contain）。裝飾順序：`LayerList moveButtons={{up:'往前一層',down:'往後一層'}}`。
- 已儲存清單：`SelectableCardList`。合輯圖：`layoutSheet`／`drawSheet`＋`captionMeasure`，畫之前先 `ensureFont`。
- 匯入：`useChoice` 做加入／取代／取消。自訂部件：`createAssetStore`；匯出時用 `serializeProjectZip`＋`exportFiles` 夾帶圖片。
