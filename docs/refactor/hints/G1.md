# G1（文字演出）共用層使用提醒

由 G1 共用層實作者整理（2026-10-01）。API 細節見 DESIGN.md 第 4 節。

## typewriter
- 打字步驟：用 `Array.from(text)` 切字（含換行），`typingSteps(units, { reverse })`；先排好全文（`typeset`，可用 `scaleX`、`vertical`），每格畫 `typingVisibleAt` 給的字。
- 影格：`uniformFrames(n, fps, { holdMs })` 再接上淡出格，放進 `source.frames`；預覽用 `frameIndexAt` 找目前的格；`ExportPanel` 給 `fixedFps={fps}`。
- 底線、刪除線：`textDecorationRects` 傳給 `paintGlyph(..., { decorations })`，圖形模式用 `mode: 'path'`。
- 圖形模式：`loopShape` 取形狀，`layoutOnPath` 排字（`offset: S/2`、`rotate`、`center`）。
- 卡拉 OK：`drawKaraokeLine` 畫每一句，淡化的句子用 `withLayer` 先合成再套透明度。
- 片尾分段：`exportAnimationBatch`，回傳 `{ files, zipName }`。
- 音效：`decodeAudio`、`mixAtTimes`、`skipOverlapping`、`fade`；介面用 `AudioDrop`、`AudioPlayer`。靜音檔：`createSilence`＋`downloadSequentially({ intervalMs: 500 })`。

## text-path
- 軌跡：`presetPath(shape, 634, 300)` 和附件一致；另有 `sampleEvenly`、`reversePath`、`scalePath`（預設以外接框中心縮放）。
- `PathPad`：`width={634} height={300} minDistance={2}`，疊字用 `labels`＋`labelSize`。
- 結果：`TextOutputPanel font="mono" wrap="off" count={…}`。
- 格子對應、找空格、修剪的規則屬於工具本身，要自己寫。

## cutin
- 字級：`typesetToFill`；`padPerSize` 用 `textFxExtent(layers 以字級 1 算).outlineSum` × 字型倍率；要用「行數 × 字級 × 行距」當高時傳 `boxOf`。
- 加工與特效：`shapeFromTypeset`＋`renderTextFx(..., { transform, offset, pool })`；特效用 `drawLoopFx`、`LOOP_FX_ORDER`、`LOOP_FX_PARAMS`；抖動用 `loopNoise2`。
- `ThumbChoice` 在滑鼠停留時每格都會呼叫 `draw`，排版請先快取。
- 用途與匯出：`EXPORT_TARGETS`、`checkTarget` 接 `IssueList`；`nextShrinkStep` 接 `ExportPanel` 的 `autoShrink`；`limit`、`colorOptions`。GIF 底色用 `matte`（不是 `background`）。
- 其他：分享連結用 `core/share`（從頭來過用 `clearShareHash`）；進階開關 `useAdvancedMode('cutin')`；字型清單 `defineFontChoices`；字數 `countGraphemes`。

## collage-letter
- 清單：`FontPoolList`（預設勾幾套繁中字型）、`ColorPairList`；切字用 `splitGraphemes`。
- 輸出：JPG 用 `canvasToJpeg(c, { background: null })`（紙張底自己畫好）；HTML 文字用 `escapeHtml`；圖片進剪貼簿用 `copyImage`（`@/core/files`）。
- 測試用種子：網址參數 `?seed=<整數>` 配 `createRandom(seed)`。
