# 社群貼文產生器（social-post）行為規格

## 0. 概要

做出「相片社群 App」的畫面，存成 PNG 或可以點來點去的 HTML 檔：跑團用的角色社群帳號、劇本 handout、宣傳、團後梗圖。
四種畫面——**貼文**（帳號列、照片輪播、按讚與留言數、內文）、**留言**（疊在貼文上的留言面板，或只有面板）、
**限時動態**（1～6 格的照片版面＋貼紙＋進度條與帳號列）、**個人頁**（數字、簡介、精選動態、貼文格狀）；
可以做好幾則貼文與限時動態，個人頁的格狀縮圖連到貼文、精選動態連到限時動態。全部在瀏覽器內處理，不上傳。

輸入：照片（選檔、拖放、貼上、圖片網址）、文字與選項。
輸出：目前畫面的 PNG（預設 3 倍：貼文／留言／個人頁寬 1170，限時動態 1080 × 1920）；HTML 檔（只有這個畫面，或個人頁＋所有貼文＋留言＋限時動態的一個檔案）；新版另有專案檔（ZIP）。

靈感來源：s2ndrome/4layout（<https://s2ndrome.github.io/4layout/>；對照的原始碼是 repo 的 `index.html`、`app.js`（約 1,430 行）、`style.css`、`README.md`，commit `3297da5`；
原作還在更新，以這個 commit 為準）。原作**沒有授權檔（未授權）**：只參考功能、數值與做法；程式、介面文字（原作是韓文）、預設文案、範例帳號與貼文、
圖示、樣式都自己做（繁中），不放 `UPSTREAM_LICENSE`。原作 `vendor/` 的 html-to-image（MIT）不帶進來（新版直接畫在 canvas，不需要）。

**商標**：原作仿 Instagram 的介面（品牌字樣「SEOL INSTA」「ZZUN MAKER」、下載檔名 `instagram-…`、HTML 標題「… • Instagram」、Instagram 的漸層與圖示）。
新版不用「Instagram」這個名字、標誌、字標與專有圖示，做成通用的「相片社群 App」樣式：版面的配置（帳號列、照片、按鈕列、數字、內文、格狀個人頁、
限時動態的進度條）是這類 App 的通用做法，照原作的數值；**圖示本站自己畫**（線條圖示，見 D5），**配色本站自己定**（深淺兩組，見 3.2）。
介面、檔名、匯出的 HTML 都不出現「Instagram」「IG」「Insta」（E2E 檢查）。

用語：「原作」＝上述網站；「畫面單位」＝畫面的 CSS px（貼文、留言、個人頁寬 390；限時動態寬 360、高 640）；「倍率」＝匯出時的放大（預設 3）；
「cqw」＝限時動態寬的 1%（3.6 畫面單位）；「字級倍率」＝F11 的 80%～140%；「次要色」「連結色」等見 3.2 的配色。

## 1. 功能清單（對等驗證以此為準）

原作是左邊的預覽（標題、淺色／深色、「PNG 存檔」、HTML 檔的兩個按鈕、預覽）＋右邊一欄設定（上方四個分頁：貼文、留言、限時動態、我的帳號；
每個分頁都有「帳號資訊」「上方時間・字級」兩個共通區塊，下面是分頁自己的區塊，最下面是「重設這個畫面」「全部重設」），頁首另有「暫存」。
新版用共用外框：設定分成五個分頁「貼文」「留言」「限時動態」「個人頁」「帳號與畫面」（共通的兩個區塊集中在最後一個分頁）；
選前四個分頁時預覽換成那個畫面，選「帳號與畫面」時預覽停在上一個畫面。預覽區是畫面名稱與淺色／深色、舞台、操作說明與共用的匯出區（PNG、HTML）。

## 2. 輸入

- 圖片：瀏覽器能解碼的圖片都可以（PNG、JPEG、WebP、GIF〔第一格〕、AVIF…）；長邊超過上限時縮小（F98）後存進資產庫（IndexedDB），狀態只記 id。
- 圖片網址：`http://`、`https://` 開頭；Google 雲端硬碟、Dropbox 的分享連結先轉換（F99）。以 `fetch`（CORS）下載；伺服器不允許跨網域讀取、回應不是圖片、
  逾時 15 秒都算失敗，照實說明（同一批的成功的照樣加入）。
- 文字：見各欄的上限（以字元計，emoji 算一個；原作沒有上限，D10）；數字欄（讚數、粉絲數…）是文字，原樣顯示。
- 數值：電量 5～100、字級 80～140%、間距 0～3、進度 0～100、段數 1～12、空格數 0～30、隱藏的回覆數 0～999、貼紙大小 0.2～6、旋轉 −180～180；超出時夾回。

### 3.8 HTML 檔

3. 輸出：PNG 尺寸（3 倍）；HTML 的結構（畫面、留言面板、限時動態的數量與連結）、互動（換畫面、輪播、打開與關閉）。

## 4. 互動與手感

- 預設：範例內容（D2）、淺色、狀態列與圖示開、時間 23:47、電量 100%、字級 100%；分頁「貼文」、目前的貼文與限時動態是第一則；匯出 PNG、3 倍、HTML 範圍「只有這個畫面」。
- 照片在預覽上的拖曳：照片跟著指標移動（位移以框的大小計，夾在蓋滿的範圍）；滾輪每 100 px 約 × e^(−0.15)（同原作 e^(−0.0015 × 滾動量)）、以框中心縮放；兩指捏合以距離比縮放。
- 貼紙：拖曳、捏合（縮放＋旋轉）、滾輪（同上）、Shift＋滾輪（每 100 px 轉 20°）；放開時中心夾在 −10%～110%。
- 文字欄從聚焦到離開算一步復原；滑桿放開才算一步；拖曳照片、貼紙從按下到放開算一步；滾輪連續轉動 0.4 秒內算一步。
- 個人頁預覽：滑過貼文縮圖與有連結的精選動態時出現外框，點了切換分頁。

## 5. 容易做壞的地方

- **同一份畫法**：預覽、PNG、HTML 用同一段程式畫，PNG 只是不畫編輯用的框（F86）。
- **字級倍率只套在原作那些字**（3.3），帳號列、按鈕列等的高度不變。
- **折疊**只看第一行、38 個字（emoji 算一個），第一行就是全部時不加「更多」。
- **#標籤的判斷**：前面要是開頭、空白或「(」；「a#b」不算。
- **圓點最多 5 個**，第 6 張以後停在第 5 個圓點。
- **換版面不丟照片**（6 格都記著）。
- **刪除、換位置限時動態時精選動態的連結跟著同一則**（以 id 記，不以順序）。
- **刪除、移動第一張照片時格狀縮圖回到預設**（原作的行為；縮圖的位置是跟著「第一張」）。
- **疊在貼文上的留言面板**：背後的貼文畫面一樣受字級、深淺色、目前照片影響。
- **只有面板時沒有狀態列**、面板上方不是圓角（原作的做法）。
- **個人頁開著底部分頁列時高 844**，格狀裁掉；關掉時依內容加高，格狀全部畫。
- **網址的圖片**：跨網域讀不到的不能畫進 PNG（canvas 會被污染），所以一定先下載；讀不到就說明，不偷偷放一張畫不出來的圖。
- **HTML 的輪播**換的是照片＋膠囊＋圓點那一段（新式的圓點在照片下面，舊式在按鈕列中間）。
