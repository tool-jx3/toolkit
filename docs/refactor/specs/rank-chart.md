# 排行榜產生器（rank-chart）行為規格

## 0. 概要

「盲選排行榜」：先寫好標題（誰排的、排什麼、最後的問題）、放進一份角色名單（名字＋選填的照片）、決定名次格數，
按「開始」後工具把名單洗牌、決定出場順序（事先不公開），**一次揭曉一位**，玩家當場把這一位放進一個空的名次；
下一位是誰不知道、同一位不會出場兩次、**確定的名次不能移動、交換或刪除**。全部名次確定後存成 PNG 或 WebP
（可以 2 倍解析度、可以在下方附上這次沒出場的角色）。排名者自己的照片可以放在圖的右欄，並把「下一位」的抽選卡片擺到喜歡的位置。
全部在瀏覽器裡處理，不上傳。

輸入：標題文字、角色的名字與照片（選檔、拖放、貼上）、排名者照片（選填）、規則與外觀的設定、遊戲中的名次選擇。
輸出：PNG／WebP（1080 × 1350、1080 × 1920 或 1080 × 1080，可 2 倍、可加附錄，見 3.1）；新版另有專案檔（ZIP）。

靈感來源：sotsotssi/would-you-rank（<https://github.com/sotsotssi/would-you-rank>；對照的原始碼是 commit f323b87 的
`index.html`、`app.js`）。原作 **MIT 授權**：配色的色值、預設的文字（翻成繁中）、圖上的英文裝飾字可以沿用；授權全文放在
`web/src/tools/rank-chart/UPSTREAM_LICENSE`（建置時併入 THIRD_PARTY_NOTICES）。原作的名稱與作者帳號不放進介面與輸出（D4、D15）。

用語：「原作」＝上述網站（韓文介面，沒有語言切換）；「畫布 px」＝輸出圖的像素（1 倍）；「名單」＝角色池；
「K」＝名次格數；「N」＝名單人數；「這一局」＝按「開始」到回到設定之間（含完成）；「揭曉」＝抽選演出結束、顯示這一位。

## 1. 功能清單（對等驗證以此為準）

原作的設定欄有三個分頁（01 主題·參加者、02 角色池、03 進行·設計）；新版同樣三個分頁：「01 主題與排名者」「02 角色名單」「03 規則與外觀」，
每個分頁最下面有「下一步：…」（切到下一個分頁、焦點移到分頁列）。

## 2. 輸入

- 照片：PNG、JPEG、WebP、GIF（第一格）、AVIF、BMP（看 MIME 類型或副檔名）。一張 25 MB 以內、6,400 萬像素以內。
  角色照片長邊超過 1500、排名者照片長邊超過 1800 時縮小（WebP，瀏覽器不能存 WebP 時 PNG）；沒超過時新版直接存原檔（原作一律重新存成 WebP，D18）。
  照片方向依檔案的 EXIF。
- 不是圖片：錯誤訊息「「檔名」不是圖片檔。」；讀不到：「無法讀取「檔名」…」；太大：「「檔名」超過 25 MB…」「…像素太多…」。
- 文字：名字 30、連接文字 40、主題 80、問題 100、角色名稱 50 字（以字元計，emoji 算一個字；原作的輸入欄以 UTF-16 計）。

名字、連接文字、主題、問題去頭尾空白、截字數；名字的助詞（auto 依收尾子音選 이／가）放在連接文字前面（「가 말아주는」；沒有助詞時連接文字前面加一個空白）、主題的助詞接在主題後面（「OOOO 등장인물과」），
所以排出來的標題與原作相同；名次格數、演出時間、三個開關、比例、配色（色碼不對時用奶油玫瑰的）、卡片位置與大小、排名者照片（擺法、放大、位置）照搬；
角色 id 符合 `[A-Za-z0-9_-]` 1～100 字時保留，重複時整份不收；角色照片用原圖（沒有原圖時用裁切圖）＋裁切重新做 512 × 512。
不是原作的第 1 版設定、JSON 錯誤、超過 120 位、照片資料不對：錯誤訊息、不套用。

### 3.8 對等驗證的比對方法

1. 原作用 `file://` 開 commit f323b87 的 `index.html`，新版開 `next/rank-chart/`；兩邊擋掉網路字型（都退到同一套電腦字型）。
2. 同一份原作的設定 JSON（英數字的標題與名字、助詞「沒有」）分別用原作的「불러오기」與新版的「開啟原作的設定檔」讀入；
   兩邊把 `crypto.getRandomValues` 換成同一個可重設的亂數（LCG），開始前重設同一個種子 → 出場順序必須相同。
3. 照同樣的順序點名次、確定，在「開始前／揭曉／待確定／確定後／完成／匯出（2 倍＋附錄）」比對畫布的繪圖紀錄：
   每個文字的位置、字級、對齊、字重（依 3.2 的對應）、顏色；每張圖片的位置與大小；圓角框的起點；圓；填色與線條。翻譯過的文字只比位置與對齊。
4. 匯出的 PNG 並排算像素差：除了翻譯過的文字與原作名稱，應該完全相同。
5. 擺放模式：放同一張排名者照片，在兩邊做同樣畫布座標的拖曳（卡片、控點、照片），讀出存下來的位置與大小比對。

## 4. 互動與手感

- 抽選演出 1／1.8／2.8／4 秒；換圖間隔 70 ＋ 160 t² ms；自動抽下一位 0.8 秒；名次按鈕一列 5 個。
- 擺放：控點 ±36 畫布 px、卡片的抓取範圍上 26、左右下 13 px；拖曳與滑桿放開才記一步復原。
- 預設：小明／的盲選排行／○○○○ 登場角色／能交往嗎？、10 位範例、6 格、1.8 秒、再確認開、自動抽關、不要快速切換＝依系統、4:5、奶油玫瑰、卡片 58%（50%、6%）、沒有排名者照片。
- 鍵盤：Tab／Enter 選名次；分頁列 ←／→；Ctrl＋Z／Ctrl＋Shift＋Z／Ctrl＋Y（遊戲中停用）；`?` 快捷鍵說明。
- 存檔：設定與這一局即時存；重新整理後接著玩（抽選中 → 直接揭曉同一位）。

## 5. 容易做壞的地方

- **出場順序開始時就決定並存好**：抽選演出只是畫面；重新整理、離開再回來都不能換掉下一位（抽選中重新整理直接揭曉）。
- **抽選的候選是整份名單扣掉已確定的**（包括這局不會出場的人），不是只有出場順序裡的人——不然看演出就能猜到誰會出場。
- **確定的名次不能改**：遊戲中不能復原（這一局不在復原紀錄裡）、設定全部鎖住；只有「回到設定」或「再玩一次」能清掉。
- **標題預算**：三行一起等比例縮小，換行是縮小前決定的。
- **卡片的位置只在有排名者照片時才看設定**；沒有照片時固定置中、縱向 34%。
- **改卡片大小時左上角不動**：位置要依新的可移動範圍重算。
- **照片位置相對於「超出的部分」**：換比例、換擺法後同一個位置值代表不同的距離（換擺法時歸零）。
- **英數字與中文之間的空格**只在標題第一行自動加（名字＋連接文字）；連接文字以空白開頭時一律隔一格（讀原作設定檔時用來保留原作的空格）。
- **檔名的上限 55 字**、不能用的字元換成「_」。
