# VTT 棋子產生器（token-maker）行為規格

## 0. 概要

把角色圖（立繪、頭像）做成 VTT（CCFOLIA、Roll20、Foundry、Owlbear Rodeo 等）用的**圓形棋子 PNG**：圖片剪進有花紋的外框裡，
頭、角、帽子、武器可以「**出框**」——蓋在外框上面、甚至伸到外框外面；外框可以是金屬、石材般有光影的浮雕環，或霓虹、幾何的平面框。
一次可以做好幾個（名單），敵人可以做成徽章 1～N 的一組（ZIP）。圖片只在瀏覽器裡處理，**不會上傳**；設定、圖片與遮罩自動存在這個瀏覽器。

輸入：角色圖（PNG、JPEG、WebP…；可以一次好幾張）、選填的遮罩圖、自訂外框、自訂遮罩。輸出：透明背景的 PNG（或 WebP），
可以把設定嵌進 PNG 之後再開來改；多張與編號組打包成 ZIP；專案檔。

**和簡易頭像產生器（icon-maker）的差別**：icon-maker 做的是正方形的頭像加名字牌，圖片與名字牌各自擺放、不重疊；
這個工具做的是 VTT 的圓形棋子，重點是外框的花紋與「出框」（圖片的一部分蓋在外框上）。

靈感來源（三個原作都是 MIT，可以參考程式改寫，數值、外框樣式、預設集可以沿用；授權全文在 `web/src/tools/token-maker/UPSTREAM_LICENSE`，
原作清單在 `UPSTREAM_SOURCES.json`）：

- TW＝**arcana-hanna/token-workshop**（<https://github.com/arcana-hanna/token-workshop>，讀的是 `c27f41e`，2026-10-26）：單檔工具。
  程式畫的環形外框 16 種與外觀 18 組、金屬／石材的顏色與光照、程式產生的質感；出框用魔術棒、筆刷、自動偵測主體；
  匯出 256～2048 px；設定與圖片嵌進匯出的 PNG，之後可以再開來改。頁尾的靈感來源是 TW（registry）。
- ED＝**CyberDelaai/eidolon-ui**（<https://github.com/CyberDelaai/eidolon-ui>，讀的是 `43c44b6`，2026-10-27）：12 種程式畫的外框（霓虹、幾何）、
  自訂外框與遮罩、出框筆刷與讀入遮罩、名單、名字牌與弧形文字、徽章、編號組 ZIP、Roll20 280／Foundry 400 的尺寸、背景（單色／延伸／透明）、
  色彩調整、效果、預設集、參考輪廓。**範例圖片（examples/ 的吉祥物）與 previews/ 不拿**。
- TF＝**Sectr99/TokenForge**（<https://github.com/Sectr99/TokenForge>，讀的是 `ff7ad73`，2026-10-26）：**只參考**「自訂外框時自動偵測外框的開口半徑」的做法；
  它的外框圖檔來源不明，不沿用任何圖檔。

三個原作的介面文字（英文等 8 種語言）與說明都不沿用（本站自己寫繁中）；版面、圖示照本站的共用元件。

用語：「棋子」＝一張輸出的圖；「外框」＝環或框；「開口」＝外框裡面、圖片看得到的範圍；「出框」＝遮罩選到的部分蓋在外框上；
「遮罩」＝圖片上每個像素要不要出框（0～255）；「R」＝外框的外半徑；「自訂」＝原作沒有、數值由本站決定。

  讀不出來的列在通知裡；不是圖片的也是。
- 遮罩圖：任何圖片，拉伸到圖片的範圍（F22）。

## 3. 輸出與數值

### 3.1 繪製（預覽與匯出同一段）

棋子是 N × N 的正方形（預覽 1024、匯出依尺寸），中心 c＝N ÷ 2，外框的外半徑 R＝N ×（0.5 − 邊距），外框寬 w＝R × 寬度 %。

1. **圖片層**：圖片的中心在 (c＋x·R, c＋y·R)，縮放 s＝2R ÷ 圖片短邊 × 縮放，再旋轉、鏡像。
2. **開口層**：背景（透明／單色／延伸）＋圖片層，剪成開口：外框的形狀往內縮 cut × w（浮雕環 0.7、霓虹 0.5、雙環 0.15、無外框 0）。
3. **外框層**：外框（主色依光照做成金屬漸層；光照強度 0＝平塗）；漸層色時先用灰色畫再以 overlay 疊漸層；有質感時質感一格一格鏡像相接鋪滿（格寬 2R ÷ 密度）、
   只留外框的範圍（浮雕環扣掉內側陰影），以 overlay（能量是先描對比色的光暈再疊能量色）、強度 % 疊上。
4. **光暈**：外框層的模糊（外框色，模糊 N × 0.028）扣掉外框本身；內側／外側只留外緣以內／以外。外框層與光暈乘外框不透明度。
5. **出框**：遮罩（柔邊後）依圖片的擺放畫上，只留圖片層在遮罩裡的部分，蓋在最上面；陰影（rgba(0,0,0,0.6 × 陰影)、
   模糊 R × 0.05 ×（0.4＋陰影）、往下 R × 0.02）只留在外框層有東西的地方、扣掉出框本身。
6. 名字、徽章畫在最上面（3.11）。色彩調整（每個棋子；延伸背景也套）與效果的色調、故障、RGB 分離、顆粒在圖片層的像素上算（Safari、Node 沒有 ctx.filter）；
   暗角、掃描線以 source-atop 疊在開口層與出框上（不會畫到透明的地方）。故障與顆粒用決定性的亂數（棋子 id＋種子），重畫時不會閃。
7. 自訂外框：外框層是外框圖（拉伸到 2R 的正方形）乘上主色；開口是 R ×（開口半徑 %）的圓。自訂遮罩：開口層以遮罩的不透明度剪（destination-in），取代外框形狀的開口。

延伸背景：圖片最外圈的一列／一行往外拉長（四個角的像素往斜角拉），在 N ÷ 8（32～256）的小畫布上做三次方框模糊（半徑＝小畫布 × 0.025）再放大。

### 3.3 自動邊距

出框的邊界點（遮罩 > 0、圖片不透明度 > 8、旁邊有不是的像素）依擺放換成離中心的距離（R 為單位），最遠的 d：
d ≤ 1 時邊距 0；否則 d ×＝1.005，加上柔邊（換成 R 單位）、有陰影時再加 0.01＋0.05 × 陰影；外光暈（外側、全部）時 d 至少 1.06。
邊距＝0.5 − 0.5 ÷ d，夾在 0～0.45。拖曳、捏合中邊距固定，放開才重算。

### 3.4 自動選出主體（不透明的圖，TW 的做法）

縮到長邊 ≤ 360 px（區塊平均）；四邊的像素中，和四邊中位數顏色距離 < 110 的當起點（沒有時全部當起點）往內「淹」背景：
相鄰像素各色差 ≤ 14、和起點各色差 ≤ 130；剩下的像素分成相連的塊，留下 ≥ 最大塊 12% 的；主體 < 1% 或 > 93% 算找不到。放大回遮罩大小（雙線性，> 0.5）。

### 3.5 質感（TW）

512 × 512 程式產生（值雜訊、四層碎形、Worley），同樣的種子每次相同；刮痕金屬另外畫 340 條細刮痕與 16 條深溝。選了時的強度：
石材 85%、刮痕金屬 85%、鎚目 80%、木紋 65%、液體 60%、能量 80%。

### 3.6 自訂外框的開口（TF 的做法）

外框圖縮到 512 × 512，從中心往 72 個方向找第一個不透明度 > 128 的點，取第 90 百分位的距離＋4 px（÷ 256 換成比例）；
中心本身不透明時 200 ÷ 256；72 個方向裡找到的少於 36 個也是 200 ÷ 256。

### 3.7 檔名

- 單張：`〈名稱〉_〈尺寸〉.png`（或 `.webp`）；名稱＝棋子的名稱，空白時用圖片的檔名（拿掉副檔名），再沒有就是「棋子」；不能用的字元換成 `_`、最多 60 字。
- 全部打包：ZIP 裡每張照上面的規則（同名的加 `_2`、`_3`），ZIP 名稱 `棋子_〈年月日〉-〈時分〉_〈尺寸〉.zip`（例：`棋子_20261029-0805_512.zip`）。
- 編號組：ZIP 裡 `〈名稱〉_〈編號〉_〈尺寸〉.png`（編號補零到 N 的位數：N＝12 時 `_01`～`_12`），ZIP 名稱 `〈名稱〉_編號組〈N〉_〈尺寸〉.zip`。
- ZIP 不壓縮（PNG 本身已經壓過）。

### 3.8 嵌進 PNG 的設定

- 本站：PNG 的 iTXt（共用的 `setPngText`／`readPngText`，`core/encode`；放在 IEND 前面，同關鍵字的先拿掉），關鍵字 `trpg-toolkit`，zlib 壓縮；內容是 JSON：
  `{ format: 'trpg-toolkit-token', version: 1, look, token: { name, badge, view, popOn, adjust }, image: { name, type, data }, mask: { width, height, data } | null }`，
  `data` 是 base64（圖片是資產庫裡存的那份；遮罩是 256 色的遮罩 PNG）。讀的時候外觀、擺放、色彩調整都經過整理（同專案檔），名稱最多 40 字、徽章 4 字；
  遮罩大小和圖片對不上時重新取樣。`format` 不對、JSON 壞掉時當成一般圖片（不問）。
- token-workshop：PNG 裡的私有 chunk `tkWs`＝4 位元組的 JSON 長度＋JSON（`app: 'token-workshop'`、`img.type`、`mask: { w, h, rle }`、`settings`）＋原圖的位元組；
  遮罩是交錯的 0／1 長度（7 位元一組的可變長度整數，從 0 開始）。設定的對應：`formula`→外框、`color`／`colorKey`（小寫，不在色票裡時自訂）、`gradOn`→漸層、
  `width`／`depth`／`lineW`／`texAmt`／`texDens`／`lInt`／`pad`／`shadow`（比例 → %）、`count`、`tex`（`marble`→石材）、`texRot`／`gAng`／`lAng`（弧度 → 度）、`seed`、`eCol`、`g1`／`g2`、
  `bgOn`／`bg`→單色或透明、`autoFit`→自動邊距、`feather`；擺放 `ix`／`iy`／`zoom`／`rot`（弧度 → 度，夾在 ±180）／`flip`（−1＝鏡像）；`popOn`。TW 沒有的（光暈、不透明度）用關、100%，其他沿用目前的外觀。

### 3.9 專案檔與自動儲存

- localStorage `trpg-toolkit:token-maker`：外觀、棋子（圖片與遮罩只記 id 與寬高）、目前的棋子、自訂外框與遮罩（id、檔名、寬高）；
  `trpg-toolkit:token-maker:preview`：工具、模式、容許度、筆刷大小、顯示選取外框、讀入時自動選出主體、分頁、尺寸、格式、嵌入設定、編號組的張數、
  顯示內建的預設、含匯出設定、我的預設、參考輪廓（種類、不透明度、輔助線、參考圖的 id）。
- 開頁的整理：目前的狀態、復原紀錄、參考圖用到的圖都保留。
- IndexedDB（共用的資產庫）：圖片（原檔或縮小後的 PNG／JPEG）；遮罩存成 256 色調色盤的 PNG（第 i 色＝白色、不透明度 i），id 依內容產生。
- 專案檔：共用的 ZIP（`project.json`＋`files/〈id〉.png` 等）。

### 3.10 自動配色（ED 的 AUTO）

- 外框色：圖片縮到長邊 64 px（中心的像素份量大）；背景＝四邊 4% 的像素分 3 群；和背景色相近的像素份量降低（扣完剩不到 15% 時不扣），
  k-means 6 群，分數＝份量 ×（0.15＋鮮豔度）×（0.3＋和外緣的亮度差）；亮度夾在 0.3～0.8，和外緣的亮度差不到 0.22 時拉開到 0.22。
- 第二色：整張圖以 5 位元分箱（細小的顏色也留得住）；離外框色 RGB 距離 > 90、彩度 > 0.2、飽和度 ≥ 0.45 的像素（不夠時放寬）分 5 群，
  分數＝份量^0.2 ×（0.2＋鮮豔度）× 和外框色的距離；先依色相分家族再挑。
- 和目前的顏色太像（距離 ≤ 30）的跳過；第一次（種子 0）取分數最高的，之後每按一次依分數加權隨機換下一個。完全透明的圖找不到。

### 3.11 名字與徽章的版面（ED）

- 名字牌：字高 N × 0.068、字距 0.08 字高（比 N × 0.8 寬時縮小）；牌子高 1.6 字高、寬＝字寬＋1.6 字高，左上與右下切角（0.38 × 牌高）；
  中心在 (c＋x·R, c＋y·R)，整個牌子留在畫面裡（離邊 N × 0.012）；有第二色時描邊。
- 弧形文字：字高 N × 0.062，沿半徑 R − 0.8 × 字高的圓排，每個字寬＋0.12 字高；總角度超過 150° 時字縮小（每次 × 0.92，最小 N × 0.02）；
  中心角＝位置的方向（沒有位置時朝下）；底下是 1.6 字高粗的弧（底色）；上半圈反過來排才不會倒著讀。
- 徽章：半徑 N × 0.088 的圓（底色），外圈 N × 0.012（背景單色時是背景色，否則近黑），中心在位置上（留在畫面裡）；文字自動時依底色挑深或淺（亮度 > 0.55 用深色）。
- 顏色來源：外框色（漸層時起點色）、第二色（樣式沒畫出第二色時同外框色）、背景色、自訂。

## 5. 容易做壞的地方

- **出框蓋在外框上**：出框層要畫在外框（與光暈）之後；陰影只留在外框有東西的地方，不能壓暗開口裡的圖片或外面的空白（單元測試量像素）。
- **遮罩在圖片的座標**：平移、縮放、旋轉、鏡像時遮罩跟著動；筆刷的大小要換成遮罩的 px（外框半徑的 % ÷ 縮放）。
- **自動邊距在拖曳中要固定**：不然外框會一邊拖一邊縮放，拖起來會跳。
- **預覽與匯出同一段繪製**：匯出全尺寸重畫，不是放大預覽；外框層的快取依外觀與大小（拖曳圖片時不重畫外框）。
- **質感產生要分段**：一次做完約 0.1～0.3 秒，畫面會卡；預覽先畫沒有質感的，好了再重畫；匯出前等它好。
- **ctx.filter 不能用**：Safari、Node 沒有；延伸背景的模糊、柔邊都自己算（能量質感的光暈沒有 filter 時不模糊，同 TW）。
- **鏡像以棋子的中線翻**：只翻圖片本身時，有位移或旋轉的圖會跑到另一邊。
- **魔術棒的容許度改了要從同一點重選**：拖滑桿時不能每一格都記一步復原，也不能每一格都存一次遮罩。
- **Alt 鍵**：視窗失去焦點時要放開（不然一直是「去掉」）。
- **App 本身在 ToolShell 外面**：快捷鍵的通知要透過 ToolShell 裡的元件。
- **文字欄的手勢在失去焦點的 microtask 才結束**：焦點在名稱欄時在預覽上按下去，要先把打字那一步結束、再開始拖曳的手勢，
  並在那個 microtask 之後還在拖曳就再開始一次；不然拖曳的手勢被它結束，拖曳中每一格都變成一步（驗證時發現，e2e 有這個順序）。滾輪同理（先提交文字欄再算）。
- **名單很大時的記憶體**：大圖不要全部解碼留著（60 張 2048 px 約 1.6 GB）；見 D7。共用資產庫的 `bitmap()` 會一直留著解碼結果，棋子的大圖自己解碼、自己放。
- **遮罩依序存**：畫完馬上擦時，後一筆（清空，不用存檔）會比前一筆（要存 PNG）先寫進狀態；所以一筆接一筆存，復原也等存好再做。
- **色彩調整要逐步夾值**：合成一個矩陣的話，亮度、對比拉高後超出 0～255 的值會在下一步被拉回來，和瀏覽器的 filter 不同。
