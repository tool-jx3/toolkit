# 填字遊戲產生器（crossword）行為規格

## 0. 概要

把一組單字排成填字遊戲（crossword）：盤面上只有格子與號碼，旁邊列出「橫向提示」「直向提示」；題目版把提示裡出現的答案蓋成 ○，
解答版在格子裡填上答案、提示裡標出答案。可以當劇本的謎題講義，或拿跑團日誌做成團後的小遊戲。

**原作只有一種用法：從一段文字擷取**——貼上（或讀進）一段文字（TXT、HTML、JSON、Markdown；原作是韓文介面，主要拿 CCFOLIA 的
跑團日誌用），工具把文字切成句子、挑出單字當答案、整句當提示，依「出現次數」「句子長度」的比重與亂數挑出候選，再自動排成盤面。
新版另外加了**自己列答案**（一行一個「答案：提示」，派工的摘要寫的用法；5. D1），開頁就是這個模式。

輸入：答案清單或一段文字（打字、貼上、讀進文字檔）、單字數與兩個比重、外觀（標題、空格的顏色、三種字型）。
輸出：題目版與解答版各一份的 PNG（2 倍）、HTML（單一檔案）、列印（新版）；新版另有自動儲存與專案檔。

靈感來源：sotsotssi/text2crossword（<https://github.com/sotsotssi/text2crossword>；對照的原始碼是 commit 1031c06 的
`index.html`、`script.js`）。原作 **MIT 授權**：韓文的不用詞與詞尾清單、版面的尺寸與配色沿用；授權全文放在
`web/src/tools/crossword/UPSTREAM_LICENSE`（建置時併入 THIRD_PARTY_NOTICES）。原作頁首的作者帳號連結不移植（主控決定）。
原作沒有範例文字；新版的範例（答案清單、跑團日誌）是本站自己寫的。

用語：「原作」＝上述網頁（只有韓文介面）；「詞」＝排進盤面的一個答案；「候選」＝從文字挑出來、可以當答案的單字；
「候選池」＝這一次拿來排列的候選；「圖 px」＝輸出圖的 1 倍像素（PNG 是 2 倍）；「題目版」／「解答版」＝原作的 문제／정답 버전。

## 2. 輸入

- **答案清單**：任意文字，規則見 3.1。
- **文字**：任意文字（打字、貼上、讀檔）。讀檔：拖放或選檔，一次一個檔；接受 .txt .html .htm .json .md（與 text/plain、text/html、
  text/markdown、application/json）。讀成文字時先看 BOM（UTF-8、UTF-16），沒有 BOM 時先試 UTF-8，不是合法的 UTF-8 再試 Big5，
  都不是時以 UTF-8 讀（有些字變成 �，通知會說明）。原作一律以 UTF-8 讀（5. D4）。
- **數值**：單字數 5～100 的整數、比重 0～100 的整數（數值欄可以打字，離開時夾到範圍）。
- **專案檔**：共用格式（3.8）；讀回時逐欄整理（3.8）。

## 3. 輸出

### 3.1 自己列答案的格式（新版）

- 一行一個答案；空白行略過。答案與提示用這一行**最先出現**的分隔符號分開：全形冒號「：」、半形冒號「:」、Tab、全形「｜」、半形「|」。
  分隔符號之後的整段（去頭尾空白）是提示，裡面可以再有冒號。沒有分隔符號時整行是答案、沒有提示。
- 答案裡的空白（含全形空白）全部拿掉（New York → NewYork）。答案以字（Unicode 字元）計，至少兩個字；不到兩個字的行不用。
- 同樣的答案只用第一個。答案的順序就是候選池的順序（3.4 的洗牌從這個順序開始）。

### 3.2 文字整理（照原作；新版的擴充標「新版」）

1. **JSON**：去頭尾空白後以 { 或 [ 開頭、而且能解析時，依序取出所有的值：字串值接一個空白；物件與陣列遞迴取出後再接一個空白；
   數字、布林、null 不取。順序是 JavaScript 走訪物件鍵的順序（整數鍵由小到大在前，其餘依出現順序）。
   例：`{"a":"x","b":[1,"y",{"c":"z"}],"d":2}` → 「x y z␣␣␣」。不能解析時照一般文字處理。
2. **HTML**：拿掉 `<style…>…</style>`、`<script…>…</script>`（不分大小寫），再拿掉所有「<」到下一個「>」（沒有「>」時到文字結尾）的片段。
3. **新版**：解 HTML 實體：&amp; &lt; &gt; &quot; &apos; &nbsp;（換成空白）與數字實體（&#23383; &#x5B57;），其他照原樣（5. D3）。
4. 依換行（連續的換行算一個）切成行；每行去頭尾空白，空行略過。
5. **行首**：反覆做，直到不再改變——
   - 拿掉開頭的「名字＋冒號＋空白」：名字 1～20 個字、不含冒號與 ?.!（新版：冒號也可以是全形「：」，名字也不含「：？！。」）；
   - 開頭是一串括號標籤時拿掉：每個標籤是一個開括號 ( [ < { （ 〈 《（新版加【 〔 ［ ｛）、一個以上不是閉括號的字、一個閉括號
     ) ] } > ） 〉 》（新版加】 〕 ］ ｝），後面可以接空白或冒號（新版加全形冒號）；但這串標籤後面緊接「.」（新版也認「。」）時保留
     （例：「(《네크로노미콘》. 이라는…」整行保留）。
6. **切句**：逐字看，遇到開括號 ( [ { <（新版加（「『【〔［｛）進入括號、閉括號 ) ] } >（新版加）」』】〕］｝）離開括號
   （只記「在不在括號裡」，不記層數；書名號《》〈〉不算，免得括號裡的書名讓句子提早結束，和原作不同）；不在括號裡遇到 . ? !（新版加。？！）而且下一個字不是這些符號時結束一句。去頭尾空白後
   **超過 5 個字**（UTF-16 長度）才算一句；行尾剩下的也一樣。

### 3.3 單字

1. 每一句依序取出「韓文（가～힣）、英文字母、數字」的連續字串（新版：另外取出連續的漢字，依出現順序混在一起）。
2. 韓文、英數：反覆切掉字尾的助詞與詞尾（原作的清單 52 個，長的在前：으로부터、으로서…은、는、이、가…다），直到切不掉；
   切完至少兩個字，而且切完的詞與原本的字串都不在原作的不用詞清單（308 項）裡，才算一個單字。英文區分大小寫（The 與 the 是兩個單字），
   沒有英文的不用詞（照原作；5. D9）。
3. **新版**：連續的漢字用瀏覽器的斷詞（Intl.Segmenter，zh-Hant-TW、以詞為單位）切成詞，取「像詞的」片段；至少兩個字、
   不在中文的不用詞清單（`stopwords.ts`：代名詞、連接詞、副詞、常見的動詞與方位詞，繁簡都有）裡才算。瀏覽器不支援斷詞時，
   2～6 個字的整串當一個詞，更長的不取。斷詞的結果依瀏覽器的字典而定（Chrome、Firefox、Safari 可能略有不同）。
4. 同一個單字：出現次數加 1；句子沒記過時記下來（依出現順序）。候選的順序是第一次出現的順序。
5. 句子排序：120 字以內的依長度由長到短，接著超過 120 字的由短到長（同長度保持出現順序）；第一句是代表提示。

### 3.4 候選池與排列（照原作：同樣的候選與同樣的亂數序列 → 同樣的盤面）

亂數是 0 以上、小於 1 的數，依下列順序取用：

1. **候選池**（從文字擷取）：最多次數 M、最長的代表提示長度 L（UTF-16 長度）。每個候選依序取一個亂數 r，分數＝
   （次數比重 ÷ 100）×（次數 ÷ M）＋（長度比重 ÷ 100）×（代表提示長度 ÷ L）＋ r × 0.3。依分數由高到低排（同分保持順序），
   取前 min(候選數, 單字數 × 3) 個。自己列答案時候選池就是清單（不取亂數）。
2. **排列**：最多試 20 次（自己列答案 100 次）。每一次：
   - 洗牌：從最後一個往前，第 i 個（從 0 起）和第 floor(r × (i＋1)) 個交換（每個位置取一個亂數，共「池的大小 − 1」個）。
   - 第一個詞橫放，第一個字在 (0, 0)。其餘的詞照洗牌後的順序成為「還沒排的」。
   - 一輪：依序看每個還沒排的詞（已經排滿目標數就停）：走訪盤面上**所有已經有字的格子（依那一格第一次放字的順序）**，
     對詞裡每個和這一格相同的字（第 j 個字），先試「橫放、第 j 個字落在這一格」，再試「直放」。能放的條件：
     詞的每一格要嘛是空的、要嘛已經是同一個字（算一次交叉）；空的格子在垂直於詞的方向上兩旁都要是空的；詞的前一格與後一格要是空的。
     能放而且至少交叉一次、交叉次數**大於**目前最好的位置時，記成最好的位置（相同時留先找到的）。有最好的位置就馬上放上去
     （之後的詞看得到），否則留到下一輪。
   - 一輪都沒放進任何詞、排滿目標數、或沒有還沒排的詞時結束。
   - 排進的詞數**大於**之前最好的一次時留下這一次；排滿目標數就不再試。
3. 只要能交叉就放，所以會出現原作的怪癖：比較長的詞可以和比較短的詞**同方向重疊**（例：先排了「등대」，「등대지기」可以把它整個蓋住），
   兩個詞的格子相同、號碼相同（照原作保留；5. D7）。
4. 字以 Unicode 字元計（原作以 UTF-16 計；只有中日韓擴充區的罕用字不同）。

### 3.5 提示

依擺放順序，每個詞從它的句子清單（3.3 的 5）裡挑第一句還沒被前面的詞用過的；全部用過時用第一句。用過的句子記下來。
自己列答案時每個詞的句子只有清單上的那一句（所以兩個答案寫了同樣的提示時照樣用）。

### 3.6 編號、盤面與提示的遮蔽

- 盤面：所有詞的格子的外接矩形，座標改成以左上角為 (0, 0)。寬、高是格數。
- 編號：依擺放順序，詞的第一格還沒有號碼時給下一個號碼（從 1 起）；同一格開始的詞（一橫一直，或 3.4 的 3 的重疊）共用號碼。
  原作比對「同一格」時用座標字串的開頭比對，例如 (1,2) 會和 (1,20) 被當成同一格，不同的格子會出現同一個號碼（5. D5）；新版比對完整的座標。
- 格子：依擺放順序填字（重疊的格子字相同）；號碼放在詞的第一格。
- 提示清單：橫向、直向分開，各依號碼由小到大（同號碼保持擺放順序）。
- 遮蔽：提示裡**每一處**和答案完全相同的字串（區分大小寫，由左到右、不重疊）——題目版換成和答案字數一樣多的「○」，
  解答版保留答案；兩者都以粗體顯示（題目紅、解答藍）。答案沒出現在提示裡時整句照原樣。

單位是圖 px；PNG 是 2 倍（太大時降低倍率，讓長邊不超過 32,000 px、面積不超過 2.6 億畫素），白底、不透明。

- **整張**：外圍留白 60；裡面是卡片，卡片內距 40。圖寬＝卡片寬 ＋ 120；圖高依內容（標題區＋盤面與提示＋上下各 100）。

    盤面外框寬＝盤面寬 ＋ 50，合起來是 max(1300, 盤面寬 ＋ 810)。盤面 9 欄以下（寬 ≤ 490）時是 1300，和原作相同；

## 5. 容易做壞的地方

- **亂數的取用順序**：候選池每個候選一個、每次洗牌「池的大小 − 1」個，不能多取（例如另外洗一次牌、或在排列時取亂數），否則同樣的種子排出不同的盤面。
- **走訪格子的順序**是「那一格第一次放字的順序」（交叉時重新寫入同一格不改變順序）；換成依座標排序就會和原作不同。
- **最好的位置要「大於」才換**：相同交叉數時留先找到的（同一格先橫後直）。
- **候選池的分數**：亂數要和次數、長度分數一起算（不是先排序再加亂數），同分保持順序。
- **提示的長度用 UTF-16 長度**、**句子超過 5 個字才算**、**代表提示 120 字的分界**：都和原作相同才會挑出同樣的候選與提示。
- **韓文的不用詞要同時檢查切完的詞與原本的字串**。
- **遮蔽區分大小寫、所有出現的地方都要蓋**；○ 的數量＝答案的字數。
- **新版的擴充不能影響原作的輸入**：只有半形標點、韓文與英數的文字，擷取結果要和原作逐項相同（單元測試同時跑「只做原作的處理」與預設）。
- **自動儲存的文字上限**：整個網站共用 localStorage 的空間，跑團日誌的 HTML 動輒數 MB，不能整份存進去。
