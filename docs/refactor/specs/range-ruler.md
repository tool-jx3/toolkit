# 距離量尺產生器（range-ruler）行為規格

## 0. 概要

以中心格為起點，把範圍內每一格的距離寫在格子上、依距離上色，做成可以疊在地圖上的量尺 PNG（透明背景），用來量移動距離、射程、法術範圍。
方格有 5 種距離算法（曼哈頓、切比雪夫、直線的進位／四捨五入／捨去），六角格有「格數」（步數）與「直線」兩種，並可網格化給 CCFOLIA 這類只支援正方形網格的工具用。
配色有彩虹、暖色、冷色、灰階、無色、自訂，每個距離一個色彩欄；點預覽裡的格子可以個別改那一格的文字、格子顏色、文字顏色與文字大小。

由舊版「違法建築的 TRPG 實驗室」（`tools/trpg-lab/`）的兩頁合併：**方格量尺** `grid_ruler.*`（下表「方」）與**六角格量尺** `hex_ruler.*`（下表「六」）。
新版最上方切換形狀，兩種形狀各存一整份設定與各自的自訂格（兩頁原本不同的預設值照舊）。距離、點擊判定等幾何用共用模組 `web/src/core/grid/`。

## 2. 輸入

- 只有數字、顏色、選項與編輯面板的文字，沒有檔案輸入（專案檔除外）。
- 數字欄：打字時在範圍內即時套用、離開或 Enter 時夾到範圍並取整數；畫圖時和舊版一樣取整數部分。舊版只限下限（範圍打 50 就畫 50 格），新版夾在標示的範圍（D6）。
- 自訂文字：最多 8 個字（以 UTF-16 計，同 HTML 的 maxlength）。

## 3. 輸出

### 3.1 方格的排法與畫法

- 畫布：寬＝高＝(2 × 範圍 ＋ 1) × 大小，中心格在正中央。
- 依序由上而下、由左而右走過每一格 (dx, dy)（−範圍～範圍），距離大於範圍的跳過；每一格：
  1. 格子顏色（自訂格的顏色，否則該距離的顏色）的不透明度 × 格子不透明度 > 0 時，以「顏色、不透明度 × 格子不透明度」填滿整格。
  2. 1 px 的框（20% 不透明的黑），畫在格子的邊界上（線寬 1 落在整數座標，是 2 px 的淡線）。
  3. 文字：`bold <文字大小>px Arial`，在格子中心水平、垂直置中；描邊開啟時先描邊（描邊顏色、不透明度 × 文字不透明度、寬 max(2, 文字大小 × 0.18)、圓角接合），
     再以文字顏色（不透明度 × 文字不透明度）填色。文字＝自訂文字（不是空字串時），否則距離數字。
- 後面格子的填色會蓋在前面格子超出的文字上（一格一格依序畫）。

### 3.2 六角格的排法

- 欄距 step＝使用網格 ? 大小 : 大小 ÷ 2 × √3；橫向欄數 distX＝範圍（直線時 round(範圍 × 2 ÷ √3)），列數 distY＝範圍。
- 畫布（橫向）：寬＝使用網格 ? (2 × distX ＋ 2) × step : (2 × distX ＋ 1 ＋ 1/3) × step，高＝(2 × distY ＋ 1) × 大小；直向時寬高對調。
  寬高設成小數時**取整數部分**（畫布寬高屬性的轉換）。
- 格子 (c, r)（odd-q：奇數欄往下錯開半格；c＝−distX～distX、r＝−distY～distY，由上而下、由左而右，距離大於範圍的跳過）的左上角：
  hx＝使用網格 ? (c ＋ distX ＋ 1/6 ＋ 0.5) × step : (c ＋ distX ＋ 1/3) × step，hy＝(r ＋ distY ＋ 奇數欄 ÷ 2) × 大小；
  六個角從左上角起：(hx, hy)、(hx − step/3, hy ＋ 大小/2)、(hx, hy ＋ 大小)、(hx ＋ 2step/3, hy ＋ 大小)、(hx ＋ step, hy ＋ 大小/2)、(hx ＋ 2step/3, hy)；
  中心（文字的位置）＝(hx ＋ step/3, hy ＋ 大小/2)。直向時每個點的 x、y 對調。
- 每一格：填色（條件同方格，沿上面的六角形）→ 同一個六角形畫 1 px 的框（22% 不透明的黑）→ 文字（同方格）。

### 3.3 六角格的距離

- **格數**：odd-q 轉立方座標 x＝c、z＝r − (c − 奇數欄) ÷ 2、y＝−x − z，距離＝max(\|x\|, \|y\|, \|z\|)。
- **直線**：round(√(3c² ÷ 4 ＋ (2r ＋ 奇數欄)² ÷ 4) ＋ 0.14)。使用網格時也用正六角形的比例算（舊版如此）。

### 3.4 配色

距離 d、範圍 N：中心（d＝0）一律白色 #ffffff（無色除外）；N＝1 時距離 1 是固定色；其餘 t＝(d − 1) ÷ (N − 1)：

| 配色 | N＝1 的距離 1 | 其餘 |
|---|---|---|
| 彩虹 | #ff6464 | HSL(t × 270°, 100%, 70%)，各色版 round(255 × 值) |
| 暖色 | #ff4040 | #ff4040 → #ffee40 依 t 內插（各色版四捨五入） |
| 冷色 | #64d4ff | #64d4ff → #4040ee |
| 灰階 | #aaaaaa | #dddddd → #444444 |
| 無色 | 全部完全透明 | |
| 自訂 | 全部 #aaaaaa（不透明） | |

範圍 5 的彩虹：#ffffff、#ff6666、#ecff66、#66ff8c、#66c6ff、#b366ff。範圍 3 的暖色：#ffffff、#ff4040、#ff9740、#ffee40。

### 3.5 點擊判定

- 滑鼠位置換算成畫布像素（依畫布在畫面上的縮放）。
- 方格：所在的格子（⌊x ÷ 大小⌋、⌊y ÷ 大小⌋）在畫布內、且距離不大於範圍時選到它，否則關閉編輯面板。
- 六角格：在畫出來的格子裡找中心最近的一格（距離相同取先畫的），距離超過大小 × 0.65 時當作點在格子外。

### 3.6 PNG

- 檔名：方格 `grid_ruler_<n>x<n>.png`（n＝2 × 範圍 ＋ 1）；六角格使用網格時 `hex_ruler_<round(寬 ÷ 大小 × 2)>x<round(高 ÷ 大小 × 2)>.png`（寬高是取整後的畫布尺寸），否則 `hex_ruler.png`。

### 3.7 存檔與專案檔（新版）

- 自動保存：localStorage `trpg-toolkit:range-ruler`，`{ data: { shape, square, hex } }`。讀回時逐欄整理（數值夾在範圍內並取整數、未知的選項換成預設、
  各距離的顏色補齊或截成「範圍 ＋ 1」個、自訂格只留鍵是「整數,整數」的、文字截成 8 個字）。
- 專案檔：共用格式的 JSON `{ format: 'trpg-toolkit-project', tool: 'range-ruler', version: 1, savedAt, data }`，檔名 `距離量尺_<年月日>.json`。
- 每種形狀：`range`、`size`、`scheme`（`rainbow`／`heat`／`cold`／`mono`／`none`／`custom`）、`distColors`（色碼陣列，索引＝距離）、`cellOpacity`、`textColor`、
  `fontSize`、`textOpacity`、`stroke`、`strokeColor`、`customs`（鍵 `"x,y"`／`"c,r"` → `{ text, color, textColor, fontSize }`）；
  方格另有 `method`（`manhattan`／`chebyshev`／`ceil`／`round`／`floor`），六角格另有 `orientation`（`flat`／`pointy`）、`method`（`steps`／`straight`）、`fit`。

## 4. 互動與手感

- 設定與編輯面板都是改了就重畫（打字中、拖滑桿中也是）。
- 編輯面板在預覽下方（手機在預覽與設定之間）；點另一格就換成那一格；換形狀、開啟專案檔、重設、清除全部自訂、格子因範圍或算法改變而不再畫出時關閉。
- 快捷鍵：D 匯出、Ctrl＋Z／Ctrl＋Shift＋Z／Ctrl＋Y、Esc 關閉編輯面板；預覽聚焦時方向鍵選格子、Enter 開中心格（F30）。

## 5. 容易做壞的地方

- **範圍與配色一改就重建各距離的顏色**（自訂配色時變回灰色）；手動改過的距離顏色會被洗掉——這是舊版的行為。新版只在數值真的改變時重建（D2）。
- **自訂格四個值一起凍結**（F21）：只改了文字大小，格子顏色也會固定成當時那個距離的顏色。
- **六角格的直線距離**加 0.14 再四捨五入，橫向欄數另外算；**網格化時距離仍用正六角形的比例**。
- **六角格畫布的寬取整數部分**（不是四捨五入；網格產生器的六角格才是四捨五入）。
- **框線落在整數座標**（1 px 線是 2 px 的淡線），六角格是 22%、方格是 20% 的黑。
- **文字一格一格畫**：後面格子的填色蓋在前面格子超出的文字上。
- **配色的內插各色版四捨五入**，彩虹用 HSL 公式的 round(255 × 值)。
- **編輯面板的預設值**：文字欄是距離數字（不是空白）；所以只改顏色時，自訂文字是當時的距離數字，之後改算法也不會跟著變（舊版如此）。
- 驗證時兩邊顏色的透明度要用 1/255 的倍數（見 grid-maker 規格 D8）。

### 舊版的問題與新版的做法（主控已裁定，見第 7 節）

| # | 項目 | 建議（新版目前的做法） |
|---|---|---|
| D1 | **匯出含編輯中的醒目框** | 舊版的醒目框畫在畫布上，編輯中按下載時青色框會一起存進 PNG。新版醒目框是疊在預覽上的另一層，匯出永遠不含。建議維持新版。 |
| D2 | **範圍「確定同一個值」時重建顏色** | 舊版每次範圍欄有輸入事件就重建各距離的顏色（重打同一個數字也會洗掉手改的顏色）；新版只在範圍的值改變時重建（離開欄位確定同一個值不會洗掉）。建議接受。 |
| D3 | **編輯面板的位置與關閉時機** | 舊版是跟著滑鼠的浮動視窗；新版固定在預覽下方（手機也能用、不擋住預覽）。編輯中的格子因範圍或算法改變而不再畫出時，新版關閉面板（舊版視窗留著，改了仍會存成看不到的自訂格）。建議接受。 |
| D4 | **還原這一格** | 舊版沒有自訂時按「重設這一格」只是關閉視窗；新版沒有自訂時停用這個按鈕（關閉用 ×）。建議接受。 |
| D5 | **編輯面板預設值的時間點** | 舊版打開浮動視窗時記下當時的預設顏色、文字顏色與大小，視窗開著時改了配色，之後的編輯仍用打開時的值；新版每次編輯都用當下的值。只在「視窗開著時改配色」才看得出差別。建議接受。 |
| D6 | **數字欄的範圍** | 舊版只限下限（範圍、大小、文字大小打超過上限照用；空白時用備用值 5、48、方 40／六 20）；新版夾在標示的範圍（1～20、10～200、6～200、0～100%）。建議接受。 |
| D7 | **新增的功能** | 兩頁合併（F01）、鍵盤選格子（F30）、自動保存（含自訂格）、復原、專案檔、快捷鍵、預覽背景與縮放、畫布太大的提示。建議接受。 |
| D8 | **方格距離算法的名稱** | 舊版「無條件進位／四捨五入／無條件捨去」，新版寫成「直線（無條件進位）」等，選單裡另有一行說明。建議接受。 |
| D9 | **清除全部自訂** | 照舊版不確認（新版可以復原）；沒有自訂格時停用。建議接受。 |
