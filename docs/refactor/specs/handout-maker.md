# 線索道具產生器（handout-maker）行為規格

## 0. 概要

做跑團用的線索道具圖（handout）：報紙剪報、通緝令、便條、便利貼、拍立得、電腦的系統視窗、遊戲／網路小說的系統通知（狀態視窗）、
終端機的紀錄、手機簡訊、電子郵件，共 11 種主題。寫標題與本文（`||文字||` 塗黑；簡訊主題是自己發的訊息），放一張附圖（可以加濾鏡）、
蓋一個狀態印章，換字型、顏色、紙張質感、背景圖與大小（可以對齊 CCFOLIA 的 24 px 格），匯出 PNG 或直接複製，貼到 CCFOLIA 或 Discord。
好幾張存成一份清單（自動存在瀏覽器），也可以存成專案檔。全部在瀏覽器內處理，不上傳。

輸入：文字與設定；附圖、背景圖（選檔、拖到視窗裡、貼上）。
輸出：PNG（1／2／3 倍，預設 2 倍；外形以外、打孔處、半透明的背景是透明的）、清單裡全部（每張一個 PNG，可以全部下載或打包成 ZIP）、
複製到剪貼簿（PNG）、專案檔（ZIP）。

靈感來源：KKumuu/trpgforkk 的 `D.html`（<https://github.com/KKumuu/trpgforkk>；韓文介面的 handout 編輯器，對照的版本是本機的上游複本，最後更新 2026-08-08）。
原作**沒有授權條款（未授權）**：只參考功能、選項、範圍與預設值；程式、版面、各主題的畫法與外觀、範例文字、圖示、紙張圖樣全部自己做（繁中），不放 `UPSTREAM_LICENSE`。
原作用 Tailwind 的 CDN 排版、html2canvas 的 CDN 存圖、Google 與 jsDelivr 的字型；本站不從 CDN 載入 JS，畫法改成 canvas（預覽與匯出同一段程式）。

本站另有拍立得相框產生器（polaroid）、鎖定畫面訊息產生器（lock-screen）、社群貼文產生器（social-post）：這裡的拍立得、簡訊、電子郵件主題是 handout 的樣式，
要更完整的效果用那幾個工具（頁首「說明」裡有連結）。

用語：「畫面 px」＝線索道具本身的座標（＝匯出 1 倍的像素）；「內容寬」＝扣掉左右內距的寬度；「字級」＝本文的字級（px）；
「主題預設」＝ 3.4 的主題字型與 3.1 的主題配色；「自訂」＝原作沒有或拿不到，本站決定的數值與做法。

## 1. 功能清單（對等驗證以此為準）

原作是三欄：左欄設定（主題與字型、內容、背景與大小，最下面「保管目前這張」）、中央預覽、右欄保管清單（全部存圖、清空清單）；頁首有「複製」「存圖」。
新版用共用外框：設定欄最上面是「道具清單」，下面三個分頁「內容」（主題、範例、文字）、「外觀」（字型、顏色、紙張質感、大小）、「圖片」（附圖、背景圖）；
預覽欄是舞台、提醒、共用的匯出區（含範圍與「複製圖片」）。

## 2. 輸入

- 文字：標題 120 字、本文 4,000 字、主題專用的文字 80 字（以字元計；超過的部分不接受）；換行統一成 `\n`（標題與主題文字的換行變空白）。
- 圖片：瀏覽器能解碼的圖片（類型 image/*、圖片的副檔名，或檔頭是 PNG／JPEG／GIF／WebP／AVIF／BMP）；長邊超過 2048 px 時等比縮小（JPEG 存 JPEG 品質 0.92，其他存 PNG）。
  不是圖片、讀不出來：通知寫出檔名與原因。存不進 IndexedDB（容量不足、私密瀏覽）時這次可以用、提醒重新整理後會不見。
- 專案檔：共用專案檔格式（3.8）；舊的 JSON 專案檔也讀（共用的專案選單）。

### 3.2 本文的標記

- 一般主題：每一行各自由左往右把 `||` 兩兩配對，成對的中間塗黑；落單的最後一個 `||` 照原樣顯示；`||||`（中間空的）不畫；
  三個以上連在一起的 `|` 從左邊先配（例：`|||a|||` 塗黑「|a」、後面留一個「|」，同原作的配對結果）。標記不跨行。
- 簡訊：每一行一則（空白行略過）；行裡只要有 `||` 就是自己發的；`||` 全部拿掉後去頭尾空白，剩下空字串的略過。泡泡裡不塗黑（同原作）。
- 跳脫（自訂）：`\` 後面接 `|` 或 `\` 時是那個字本身、不算標記；其他的 `\` 照原樣。
- 整段本文先去掉頭尾的空白（同原作）。
- 換行：共用的換行規則（`core/richtext` 的 'word'）——中文逐字、英數字詞不拆開（比一整行還長時才逐字切）、句讀不放行首（連同前一個字換下去）、左括號不放行尾；

### 3.5 附圖的濾鏡

照原作的 CSS 濾鏡，換成同一套算式的像素運算（Filter Effects 規格；sRGB、每一步夾在 0～255）：
黑白＝grayscale(100%)：三個色版都換成 0.2126 R ＋ 0.7152 G ＋ 0.0722 B（Rec.709，例：(220, 30, 30) → 70）；
懷舊＝sepia(80%)：(1 − 0.8) × 原色 ＋ 0.8 × 褐色矩陣；模糊＝blur(2px)：高斯模糊 2 畫面 px（匯出 2 倍時 4 px）；
鮮明＝brightness(1.2) contrast(1.2)：先各色 × 1.2，再 (v − 127.5) × 1.2 ＋ 127.5；反相＝invert(100%)：255 − 值。
e2e 用瀏覽器畫布的 `filter`（同樣的 CSS 寫法）算出的顏色比對（差 ≤ 3／255）。結果依（圖、濾鏡、輸出像素）快取。

### 3.9 清單的縮圖與打字的反應（2026-10-27 驗證後）

- 縮圖（長邊 180 px，同一段程式畫）只在內容、圖片或字型變了的時候重畫；要重畫的放進佇列，在閒置時分批畫（每批約 8 ms，目前這張優先），還沒畫好的先顯示舊的縮圖。

## 5. 容易做壞的地方

- **便條的打孔要真的透明**：挖空時填色要不透明（前面畫線留下的半透明填色會只挖掉一部分）。
- **陰影的模糊不受縮放影響**：發光、泡泡的陰影、內側光暈的 blur 要乘倍率，不然 1 倍與 3 倍的樣子不同。
- **塗黑的留白要算進排版**：只畫寬一點的條會蓋到相鄰的字；跨行時接續那一側不留白。
- **標記只在同一行配對**：跨行的 `||` 不算一對；落單的最後一個照原樣顯示；跳脫的不算標記，但簡訊裡也要照跳脫處理。
- **對齊 24 px**：打字中不要對齊（打「4」就被改成 96）；離開欄位或 Enter 才對齊；打開開關時現有的寬高也要馬上對齊。
- **讀檔時換了編輯的那一張**：圖片要放進開始讀的那一張，不是讀完時正在編輯的那一張。
- **換主題的配色判斷**：兩個顏色都是「某個主題的預設」才換（背景、文字可以是不同主題的預設）；背景色存成小寫、不透明時不帶 alpha，不然比對不到。
- **預覽與匯出同一段程式**：濾鏡、背景圖、字型都要在匯出前載好；不能有只在預覽才有的效果。
- **縮圖不能一次全部重畫**：字型的一個分片載好時字寬快取清掉、每一張都要重畫；60 張一次畫完會有 200 ms 以上的 long task（驗證時量到 267 ms）。要在閒置時分批畫（3.9）。
- **「目前這張」不在復原紀錄裡**：復原「新增一張」之後目前這張的 id 不見了，要選回新增前的那一張（不是落到第一張）。
- **濾鏡的係數**：黑白要用 CSS grayscale 的 Rec.709 係數（不是 Rec.601 的亮度），對比以 127.5 為中心，和瀏覽器的 CSS 濾鏡同色。
