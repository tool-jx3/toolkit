# 地圖編輯器（map-editor）行為規格

## 0. 概要

在瀏覽器裡畫 TRPG 的戰鬥地圖、平面圖：無限大的畫布上有方格或六角格的網格，沿著格子畫出地面、牆壁、房間（地面＋外牆），
放上家具、門、樹、地圖符號等裝飾圖章，再加上一般圖形（矩形、橢圓、直線、折線、多邊形、曲線、封閉曲線）、以格子為單位的填色、手繪、文字與圖片。
圖形可以群組、做布林運算（聯集、交集、差集、互斥），每個物件可以調不透明度、混合模式與陰影；地面與牆壁可以用自己上傳的圖片當圖樣。
畫好的地圖選一個範圍匯出成 PNG、JPEG 或 SVG（可以含網格、背景透明或白色、指定每格的解析度），帶進 CCFOLIA 等線上團工具。
地圖可以有很多張：一覽列出所有地圖（縮圖、名稱、更新時間），可以新增、複製、重新命名、刪除、匯出與讀取 JSON；編輯時自動儲存在瀏覽器（IndexedDB）。

輸入：滑鼠、觸控、鍵盤的繪圖與編輯操作；自訂圖樣與自訂裝飾的圖片（PNG、JPEG、WebP、GIF、SVG）；放進地圖的圖片；地圖的 JSON 檔（新版或舊版）。
輸出：PNG、JPEG、SVG 圖片；地圖的 JSON 檔；瀏覽器裡的地圖資料。

靈感來源：ihoukentiku/ihoukentiku.github.io（<https://github.com/ihoukentiku/ihoukentiku.github.io>），MIT（Copyright (c) 2025 ihoukentiku），
授權全文在 `web/src/tools/map-editor/UPSTREAM_LICENSE`。舊版是「違法建築的 TRPG 實驗室」（`tools/trpg-lab/`）裡的
**地圖一覽** `trpg_map_maker/map_list.*`（下表「列」）與**地圖編輯器** `trpg_map_maker/map_editor.*`、`map_grid.js`、`map_storage.js`（下表「編」），新版合併成一個工具。

素材：56 個裝飾圖章沿用舊版收錄的 SVG（`web/src/tools/map-editor/decors/`）——16 個取自 game-icons.net（作者 Delapouite、Lorc，CC BY 3.0，
有修改）、40 個取自 openstreetmap/map-icons 的 `japan/`（公有領域性質，有修改），出處與授權寫在 `UPSTREAM_LICENSE`（介面上不放作者標示）。
上游作者保留權利的 15 個格局圖 SVG 與 14 張 AI 貼圖不收（舊版收錄時已拿掉）。

技術：畫布用 Fabric **7.4.0**（舊版 5.3.1，從 CDN 載入），布林運算用 polygon-clipping 0.15.7，都從 npm 打包；取色器用共用的 ColorField（舊版 Pickr）；
格子的幾何用共用的 `core/grid`；字型用共用的 `core/fonts`（Google Fonts 按需載入）。舊版的存檔是 Fabric 5 的 `toJSON`，新版讀取時經過轉換（3.5）。

用語：「舊版」＝`tools/trpg-lab/trpg_map_maker/`（收錄版，繁中介面）；「世界座標」＝地圖本身的像素座標（縮放 100% 時 1 px），與畫面的縮放、平移無關；
「螢幕 px」＝畫面上的 CSS 像素；「格」＝網格的一格（`cellSize`，固定 72 px）；「物件」＝圖層面板上的一列（矩形、群組、格子圖層…）；
「一般圖形」＝不是地面、牆壁、房間的圖形。

## 2. 輸入

- **滑鼠、觸控、鍵盤**：見第 1 節。觸控時兩指固定是平移與縮放；文字編輯用瀏覽器的輸入法（隱藏的輸入欄）。
- **圖片**（自訂圖樣、自訂裝飾、圖片工具）：PNG、JPEG、WebP、GIF、SVG（圖片工具接受瀏覽器能讀的所有圖片）。自訂素材每個最大 4 MB。
  選檔、拖放的當下就讀進記憶體（共用的 FileDrop／pickFiles，Android 的相片挑選器）。讀不到的檔案：「讀取圖樣失敗」「讀取裝飾失敗」「讀取圖片失敗」。
  SVG 先去掉 script、事件屬性與 `javascript:` 網址（新版用 DOMPurify 的 SVG 設定，D19）。
- **JSON 檔**（F009）：新版或舊版的地圖資料（3.1、3.5），或共用專案檔格式（`{ format: 'trpg-toolkit-project', tool: 'map-editor', data }`）包住的地圖資料。

## 3. 輸出

### 3.1 地圖資料（JSON 檔、瀏覽器的儲存）

一張地圖的資料是一個物件，欄位與舊版相同（照舊版的格式，只有 `version` 與 `canvas` 的物件格式不同）：

| 欄位 | 意義 |
|---|---|
| `version` | 新版 `2`（舊版 `1`；`canvas` 是 Fabric 5 的格式） |
| `cellSize` | 格子大小（72） |
| `gridType` | `square`／`hex-flat`／`hex-flat-fit`／`hex-pointy`／`hex-pointy-fit` |
| `editMode` | 舊版留下的欄位（`simple`），照存 |
| `groundTool`、`wallTool`、`roomTool` | 子工具（地面 `cell`／`rect`／`ellipse`／`polygon`／`curve-closed`；牆壁 `rect`／`ellipse`／`line`／`path`／`polygon`／`curve`／`curve-closed`；房間 `rect`／`ellipse`／`polygon`／`curve-closed`／`path`／`curve`） |
| `groundPattern`、`wallPattern` | `{ mode: 'solid' \| 'pattern', id, genreId, solidColor }`（solidColor `#rrggbb` 或 `#rrggbbaa`） |
| `wallThickness`、`roomWallThickness` | 牆壁厚度 |
| `groundPatternOffsetX`／`OffsetY`／`Rotation`／`Scale`、`wallPattern…` | 圖樣細節（Scale 是倍率，1＝100%） |
| `textFill`、`textFillOpacity`、`textStroke`、`textStrokeOpacity`、`textStrokeWidth` | 文字的顏色（`#rrggbb`＋0～1）與描邊 |
| `userPatterns` | 自訂圖樣 `{ id, name, type: 'raster' \| 'svg', dataUrl, color, scale, ground, wall }[]`（dataUrl 是圖片本身） |
| `userDecors` | 自訂裝飾 `{ id, name, type, dataUrl, rawSvg, scale, anchorX, anchorY, genres }[]` |
| `roomGroundShadow…`、`roomWallShadow…` | 房間的陰影（Enabled、Color、Blur、OffsetX、OffsetY） |
| `roomWallStrokeDashArray`、`roomWallStrokeLineJoin`、`roomWallStrokeLineCap` | 房間牆壁的線型（虛線陣列或 null）、轉角、線端 |
| `decorId`、`decorGenreId`、`decorScale`、`decorRotation`、`decorFlipX`、`decorFlipY`、`decorFill`、`decorStroke`、`decorShadowEnabled` | 裝飾工具的設定（Fill／Stroke 為 null＝原色） |
| `freehandBrush`、`freehandWidth`、`freehandColor`、`freehandOpacity`、`freehandDecimation` | 手繪的設定 |
| `gridVisible`、`gridColor`、`gridLineWidth`、`gridDashArray` | 網格（gridDashArray：null＝實線） |
| `nextLayerId`、`layerCounters` | 下一個物件編號、各種類的命名序號（`{ '矩形': 2, … }`） |
| `viewportTransform` | 檢視 `[縮放, 0, 0, 縮放, 平移 X, 平移 Y]`（null＝原點在畫面中央、100%） |
| `canvas` | Fabric 7 的 `canvas.toObject(自訂欄位)`：`{ version: '7.4.0', objects: [...] }` |

`canvas.objects` 每個物件是 Fabric 7 的 `toObject` 結果（型別名稱 `Rect`、`Ellipse`、`Line`、`Polyline`、`Polygon`、`Path`、`Group`、`IText`、`Textbox`、`Image`…），
另外帶這些自訂欄位：`_layerId`、`_isMapLayer`、`_layerName`、`_isCellLayer`、`_isTerrainLayer`、`_isMapText`、`_isFreehandLayer`、`_isGroundLayer`、`_isWallLayer`、
`_isRoomGroup`、`_isRoomGround`、`_isRoomWall`、`_isDecorLayer`、`_decorId`、`_decorIsSvg`、`_decorScale`、`_decorFlipX`、`_decorFlipY`、`_decorFill`、`_decorStroke`、
`_terrainId`、`_worldLeft`、`_worldTop`、`_cellEntries`、`_patternOffsetX`、`_patternOffsetY`、`_patternRotation`、`_patternScale`、`_patternState`、`globalCompositeOperation`
（與舊版相同）。格子圖層的 `_cellEntries` 是 `{ col, row, fillKey, mode: 'solid' \| 'pattern', solidColor? , patternId?, patOffX?, patOffY?, patRot?, patScale? }[]`，
讀取時由它重建格子的形狀（存檔裡的子物件只是快取）。新版的新物件以中心為定位點（Fabric 7 的預設）。
新版另外存鎖定的狀態：`lockMovementX`、`lockMovementY`、`lockScalingX`、`lockScalingY`、`lockRotation`、`hasControls`（舊版沒有存，重新開啟或復原後鎖定就解除了；舊版存檔讀進來是沒有鎖定，D30）。

- **JSON 檔**（F007）：上表的物件本身（`JSON.stringify`，不縮排），檔名 `<名稱>.json`。
- 讀取時（F009、搬移）依 `canvas.version` 或物件的型別名稱判斷新舊；舊版的先轉換（3.5）。

### 3.2 瀏覽器裡的儲存

- IndexedDB `trpg-toolkit:tool:map-editor`（共用的 `toolDb`，鍵值）：`meta:<id>`＝`{ id, name, gridType, createdAt, updatedAt, thumbnail }`（時間是 ISO 字串，縮圖是 data URL 或 null）、
  `map:<id>`＝地圖資料（3.1）、`legacy-imported`＝已經從舊版搬過的 id 清單（F011）。
- 地圖 id：時間（36 進位）＋ 4 個隨機字元（同舊版）。
- 縮圖：目前的畫面縮成寬 ≤ 400、高 ≤ 250 px（等比、不放大）的 PNG data URL；不含吸附標示與匯出範圍。
- 作圖設定（F089）：localStorage `trpg-toolkit:map-editor:preview`（共用 createPreviewStore）。自動儲存的開關讀舊版的 `trpg_autoSaveEnabled`（新版之後也寫回同一個鍵）。

### 3.3 匯出圖片

- **範圍**：世界座標的矩形 (x, y, w, h)（F180）。倍率 s＝每格解析度 ÷ 格子大小。
- **PNG／JPEG**：W＝round(w × s)、H＝round(h × s) 的圖，內容＝以 s 倍縮放、範圍左上角對齊原點畫出的所有物件（不含選取框、吸附標示、作圖預覽），
  勾選網格、而且地圖設定的「顯示網格」開著時加上網格（樣式同畫面；方格 s < 0.25、六角格 s < 0.35 時不畫，同畫面的門檻）；背景白色時先塗白。JPEG 品質 0.92。
  新版的尺寸固定是 W × H（舊版在高解析度螢幕上會變成 W × H 乘上裝置像素比，D5）。JPEG 不能透明：新版選 JPEG 時背景固定白色（舊版是黑色，D6）。
- **SVG**：Fabric 的 `toSVG()`，畫布 W × H、viewBox 對應範圍；背景白色時有白色底；**不含網格**（網格不是物件，舊版亦同）。
- **檔名**：`trpg-map_<N>x<M>.<副檔名>`：方格 N＝round(w ÷ 格)、M＝round(h ÷ 格)；六角格對齊網格 N＝round(2w ÷ 格)、M＝round(2h ÷ 格)；
  六角格平頂 N＝(2w ÷ (格 × √3)) 四捨五入到 0.5、M＝(h ÷ 格) 到 0.5；尖頂 N＝(w ÷ 格) 到 0.5、M＝(2h ÷ (格 × √3)) 到 0.5；整數照寫、0.5 寫成小數 1 位；任一個 ≤ 0 時沒有 `_NxM`。
  例：方格 8 × 6 格 → `trpg-map_8x6.png`。
- **預覽**（F181）：同樣的畫法、倍率 1。

### 3.4 圖形的幾何

- **格子與吸附**：`core/grid`。方格：(col, row) 佔 [col × 72, (col＋1) × 72)。六角格：軸座標、(0, 0) 格的外接框左上角在原點；一般六角格的欄距＝72 × √3 ÷ 2，對齊網格時＝72；
  尖頂是平頂的 x、y 對調（與舊版 `map_grid.js` 相同的座標，舊版存檔的格子位置不變）。吸附候選：方格＝最近的格子點、所在格的中心、上下與左右兩邊最近的中點；
  六角格＝所在格與 6 個鄰格各自的中心、6 個角、6 條邊的中點。六角格的格線每格畫 3 條邊（平頂：左上 → 右上 → 右 → 右下；尖頂：上 → 右上 → 右下 → 下）。
- **矩形、橢圓**：外接框 (L, T, w, h)：w、h 是兩點的差的絕對值；物件的幾何（描邊的中線）剛好是這個框（描邊各往內外一半）。中心模式：r＝round(兩點距離)，框＝中心 ± r。
- **直線**：兩個端點就是點的兩點（描邊的中線）。
- **圓角（折線、多邊形）**：每個轉角 V 往前後兩邊各退 t＝min(r, 前一邊長 ÷ 2, 後一邊長 ÷ 2)，以 V 為控制點的二次貝茲接起來；折線兩端點不修圓；多邊形全部修圓並封閉；
  座標取小數 2 位。房間的折線地面以同樣的方式修圓、端點直線封閉。
- **曲線**：點 P0…Pn：從 P0 起，每個中間點 Pi 當二次貝茲的控制點、到 Pi 與 Pi＋1 的中點；最後一個中間點直接到 Pn；只有 2 點時是直線。
  **封閉曲線**：從 P0、P1 的中點起，每個點當控制點、到它與下一點的中點，繞一圈封閉。
- **格子的合併**：同一個填色的格子取外框（鄰格不同組的邊接成迴圈，洞是反向的迴圈），evenodd 填色（共用 `core/grid` 的 `squareOutline`／`hexOutline`）。
- **布林運算**：每個圖形轉成世界座標的多邊形（矩形 4 點〔不含圓角〕、橢圓與圓 64 點、路徑的二次與三次貝茲每段取 24 點），交給 polygon-clipping，結果每個環接成 `M … L … Z`（evenodd）。
- **裝飾的大小**：圖章原始外接框的長邊縮放到 72 × 大小（翻轉＝負的縮放），以中心定位。
- **圖樣**：圖樣的原點對齊世界座標 (0, 0)：圖樣位移＝−(物件外接框左上角的世界座標)＋圖樣細節的偏移（房間與格子裡的子物件用建立時記下的世界座標 `_worldLeft`／`_worldTop`）；
  填色的縮放與旋轉放在圖樣的變換；**線條的縮放先縮放圖片本身**（變換裡只放旋轉），線寬不受影響。

### 3.5 舊版存檔 → 新版的轉換

舊版的地圖資料（`version: 1`、`canvas` 是 Fabric 5.3 的 `toJSON`）讀進來時（F009 讀取 JSON、F011 搬移）經過一個轉換函式，得到新版的地圖資料：

- 上層欄位照搬；`version` 改成 2；缺的欄位補新地圖的預設值（F004、1.6～1.10）；`groundPattern`、`wallPattern` 指向不存在的圖樣時改成單色（舊版 `normalizePatternState`）；
  `decorId` 指向已拿掉的格局圖時清空。
- `canvas.objects`（含群組裡的子物件、clipPath）：型別名稱換成 Fabric 7 的名稱（`rect`→`Rect`、`ellipse`→`Ellipse`、`circle`→`Circle`、`line`→`Line`、
  `polyline`→`Polyline`、`polygon`→`Polygon`、`path`→`Path`、`group`→`Group`、`textbox`→`Textbox`、`i-text`→`IText`、`text`→`Text`、`image`→`Image`、
  `triangle`→`Triangle`）；`version` 換成 7.4.0。其餘欄位（`originX`／`originY`＝`left`／`top`、`left`、`top`、`width`、`height`、`path`、`points`、`x1…y2`、
  文字的 `styles`〔已是陣列格式〕、`shadow`、`fill`／`stroke` 的圖樣與漸層、自訂欄位）照搬，Fabric 7 讀進來的位置與大小相同。
- 舊版的作圖預覽（`isPreview`）若被存進去，刪掉。
- 平頭（butt）的水平或垂直直線：Fabric 5 計算位置時，外接框在線的方向上不含線寬，Fabric 7 含（同一個 left、top 會差半個線寬）；轉換時把 `left`、`top` 往線的方向調整半個線寬（依定位點、縮放與旋轉），讓看到的位置與舊版相同（只處理型別名稱是小寫 `line` 的舊版物件）。
- 用到已拿掉的上游內建貼圖的地方換成單色（舊版 `replaceRemovedPatterns`）：`_patternState` 的 id 不存在時改單色（草地 `#4a8c3f`、水 `#5ba3cf`、岩石 `#7a7368`、
  苔岩 `#6b7a52`、木地板 `#8a6a3f`、磚 `#9a5a3f`、石板路 `#7a7368`、森林 `#3f6a3a`、磁磚 `#d2d2d2`、黑土 `#3a3026`、圓石路 `#7a7368`、熔岩 `#5e2a20`、
  沙 `#d9c89a`、碎石 `#9a948a`），fill／stroke 的圖樣來源不是 data URL（＝上游的圖檔）時換成那個單色（沒有時填色 `#888888`、線條 `#333333`）；
  格子圖層的 `_cellEntries` 裡用到這些圖樣的格子改成單色（`fillKey` 一併改）。
- 讀進來之後（新舊都一樣）：格子圖層由 `_cellEntries` 重建、啟用群組快取（並固定不能縮放、旋轉）；房間群組與子物件關閉快取；一般的物件與裝飾關閉快取（與作圖的當下相同，D33）；群組、手繪圖層照舊快取；文字用到的字型按需載入；裝飾、自訂素材預先載入。

測試夾具：舊版實際存出來的紀錄（`web/tests/e2e/fixtures/map-editor/`：方格的全部物件種類、平頂六角格、尖頂對齊網格、空白地圖，以及舊版匯出的範圍圖；
以 Fabric 5.3.0 執行舊版產生——CDN 的 5.3.1 在這個環境連不到，npm 上沒有 5.3.1，兩者的存檔格式相同；縮圖換成很小的圖以免檔案太大）。

### 3.6 物件的名稱

`<種類><序號>`，序號依種類各自從 1 數起（`layerCounters`，跟著地圖儲存）：矩形、橢圓、直線、折線、多邊形、曲線、封閉曲線、格子、地面_矩形…、地面_格子、牆_矩形…、
房間_矩形…、裝飾_<裝飾名>、手繪、文字、圖片、群組、圖層（新增圖層）、解散（解散後沒有名稱的子物件）、聯集／交集／差集／互斥、<運算>_房間、
<原名稱> 副本（複製）。物件編號 `_layerId` 從 10 開始遞增。

## 4. 互動與手感

- 作圖：矩形、橢圓、直線、匯出範圍是「點兩下」（新版另外支援按住拖曳放開，D29）；折線類點一下加一點，Enter／確定完成、Esc／取消放棄。
- 吸附距離 18 螢幕 px（頂點 8 px），與縮放無關。測量顯示、吸附標示、選取框的大小固定在螢幕上。
- 復原：最多 50 步，連續同名修改 0.5 秒合成一步；自動儲存 2.5 秒；暫時訊息 2.5 秒。
- 預設工具：開啟地圖時是選取工具。
- 鍵盤：工具列、面板、圖層清單都可以用 Tab 走到；圖層清單的列 ↑／↓、Alt＋↑／↓；選取資訊的數字欄（共用 NumberInput：↑／↓、Shift ×10、Enter 確定）。

## 5. 容易做壞的地方

- **Fabric 版本差**：舊版存檔是 Fabric 5 的格式、型別名稱小寫；Fabric 7 預設以中心定位（舊物件的 `originX`／`originY` 一定要照搬，不能換成預設）；
  群組的子物件座標是相對於群組中心；格子圖層的子物件要由 `_cellEntries` 重建（不要相信存進去的快取）。
- **自訂欄位**：存檔、複製、復原快照都要帶 3.1 的自訂欄位（舊版右鍵選單的「複製」漏帶，複製出來的格子圖層壞掉，D8）。
- **疊放規則**：地面、牆壁各自插在最上面的同類物件的上一層；房間、一般圖形放最上面。複製的放在原物件的正上一層。
- **格子圖層**：同色合併、洞用 evenodd；整格移動後要改格子的位置；填滿只在外接框內、上限 10000 格；畫筆拖曳中同一格不要重複加。
- **圖樣的世界對齊**：位置、移動、複製後都要重新對齊；牆壁（線條）的圖樣縮放不能放進圖樣變換（會把線寬一起縮放）。
- **六角格的軸座標與舊版相同**（尖頂也是），舊版存檔的格子位置不能偏；吸附、格線、填滿的鄰格都依網格種類。
- **匯出**：尺寸四捨五入；網格要依匯出的倍率重算；不能把選取框、吸附標示、作圖預覽、匯出範圍的暗幕畫進去；SVG 不含網格。
- **文字**：編輯中的快捷鍵（Ctrl＋B／I／U）只作用在文字；編輯中的空白鍵不平移；編輯完空白的文字要刪掉。
- **觸控**：第二指放下要中止 Fabric 進行中的動作（手繪不能留下半條線）。

### 舊版的問題與新版的做法（需主控裁定）

| # | 項目 | 建議做法 |
|---|---|---|
| D1 | **Fabric 5.3.1 → 7.4.0** | 依主控決定改用 npm 的 Fabric 7.4.0。舊版存檔經 3.5 的轉換函式讀入，位置、大小、樣式相同；看得出的差異：Fabric 7.0 修正了文字的垂直位置（字的位置可能差 1～2 px）、反鋸齒的細微差別。建議接受，對等驗證以舊版夾具的匯出圖比對（容許文字的小差異）。 |
| D2 | **新物件的定位點** | 新版的新物件以中心定位（Fabric 7 的預設，`originX`／`originY` 在 Fabric 7 已列為不建議使用），看得到的位置與舊版相同（3.4）；舊物件照原本的定位點。純屬內部格式，建議接受。 |
| D3 | **文字的換行** | 舊版的文字是寬度 1 的文字方塊：每個空白都換行（「地圖 Map」會變成兩行）。建議：新增的文字一行的寬度跟著內容、只在按 Enter 時換行（Fabric 的 IText）；舊版存檔裡的文字方塊照舊。 |
| D4 | **文字的預設字型** | 舊版預設 Noto Sans JP（上游的預設，繁中字型排在選單最上面）。建議：新版預設思源黑體（Noto Sans TC），選單照舊收 37 套字型。 |
| D5 | **高解析度螢幕的匯出尺寸** | 舊版在裝置像素比 2 的螢幕上匯出的 PNG／JPEG 是 2 倍大（畫布的實際像素）。建議：一律照「輸出尺寸」。 |
| D6 | **JPEG 的透明背景** | 舊版選 JPEG＋透明時透明的地方變成黑色。建議：選 JPEG 時背景固定白色（透明選項停用並說明）。 |
| D7 | **按 I** | 舊版按 I 切到一個沒有面板、什麼都不做的「圖片工具」，要按工具列的按鈕才會選檔。建議：I 與按鈕相同，直接選圖片。 |

| D9 | **鎖定** | 舊版動作列的鎖定不隱藏控制點（拉了也不會動），右鍵選單的鎖定會隱藏控制點（動作列也一起消失，只能從圖層面板解鎖）。建議：統一成鎖定時隱藏控制點；新版的動作列是按鈕，鎖定後仍在，可以直接解鎖。 |
| D10 | **復原的範圍** | 舊版改網格、圖樣、裝飾的選擇、房間的陰影開關等設定時也記一步復原，但復原的快照不含這些設定（按復原畫面沒有變化）。建議：這些設定不記步驟（照樣跟著地圖自動儲存）；復原只管畫布上的物件。 |
| D11 | **作圖設定的保存** | 舊版的填色、描邊、線寬、線型、轉角、線端、圓角、畫法、陰影、吸附、字型與大小、格子工具的模式每次開頁回到預設。建議：記在瀏覽器（所有地圖共用，F089）；跟著地圖儲存的設定（3.1）照舊每張地圖各自一份。 |
| D12 | **取色器** | 舊版是 Pickr（色碼、不透明度、滴管）；新版用共用 ColorField（色碼、不透明度 %、吸管、常用色）。不透明度以 1/255 為單位。建議接受。 |
| D13 | **動作列與右鍵選單** | 舊版的動作列畫在畫布上（選取框右上方的圖示，滑過沒有說明）；新版是按鈕列（有名稱、可用鍵盤），位置在選取框的上方（放不下時在下方）、不超出畫布。右鍵選單用共用的選單元件。建議接受。 |
| D14 | **對話框** | 新增地圖的三步驟精靈改成一個對話框；瀏覽器的 prompt／confirm／alert 改成本站的對話框與通知。建議接受。 |
| D15 | **縮圖** | 舊版的縮圖是畫面原尺寸的 PNG（一張常常上百 KB）。建議：縮到 400 × 250 以內（3.2）。 |
| D16 | **「設定」工具** | 舊版的「設定」是工具列上的一個工具（選了之後也能選取物件）。新版是面板的「地圖設定」分頁，隨時可以看，不必換工具。建議接受。 |
| D17 | **面板顯示目前的值** | 舊版選取物件後，填色／描邊、不透明度、混合模式欄位仍顯示上次設定的值，不是物件的值。建議：顯示第一個選取物件的值。圖層清單另外支援鍵盤（↑／↓ 選取、Alt＋↑／↓ 排序）。 |
| D18 | **新增的小功能** | 縮放按鈕、方向鍵微調、地圖的網址（`?id=`）、立即儲存按鈕、把 JSON 拖進一覽、把圖片拖進畫布、搬移的提示。建議接受。 |
| D19 | **SVG 的清理** | 舊版用正規表示式去掉 script 與事件屬性；新版用 DOMPurify 的 SVG 設定（更完整）。建議接受。 |
| D20 | **刪除自訂圖樣的說明** | 舊版確認訊息說「使用中的物件會改回單色」，實際上已經畫好的物件不變（圖片已經存在物件裡）。建議：照實際行為改寫訊息。 |
| D21 | **零長度的直線** | 舊版直線工具在同一點點兩下會產生長度 0 的直線（看不到的物件）。建議：兩點相同時不建立。 |
| D22 | **虛線的長度** | 舊版線型的虛線陣列在改線型或線寬的當下才算，換工具後可能沿用另一種線寬算出的長度（例如以線寬 4 算的虛線用在厚度 12 的牆）。建議：建立物件時依當下的線型與線寬（牆壁厚度）計算。 |
| D23 | **專案檔** | 這個工具管理很多張地圖，不用共用的「專案」選單：每張地圖的 JSON 檔（F007、F009，與舊版相同的格式）就是存檔；讀取時也接受共用專案檔格式。建議接受。 |
| D24 | **新增圖層** | 舊版的「新增圖層」產生一個空的群組，但沒有辦法把物件放進去（只能拿來命名、排序）。建議：照舊保留（舊存檔裡也有），之後若要做「放進圖層」再另議。 |
| D25 | **離開時的儲存** | 舊版只在 beforeunload 嘗試非同步儲存（常常來不及）。新版在頁面隱藏（切換分頁、關閉前的 visibilitychange）時就儲存。建議接受。 |
| D26 | **匯出對話框的工具連結** | 舊版連到實驗室的四個頁面；新版連到網格產生器（grid-maker）與距離量尺產生器（range-ruler），依網格種類標示方格或六角格（不帶參數）。 |
| D27 | **手機版面** | 舊版是固定四欄，手機上畫布幾乎看不到。新版窄畫面上下排列（F022）：可以檢視、兩指平移縮放、單指作圖（含確定／取消列）、選取、改屬性、圖層操作與匯出。建議接受。 |
| D28 | **圖樣的分類** | 收錄版沒有內建圖樣與格局圖，分類只剩「全部／自訂」（圖樣）與「全部／自訂／地圖符號／圖示」（裝飾），與舊版相同。 |
| D29 | **拖曳作圖** | 舊版矩形、橢圓、直線、匯出範圍只能點兩下（觸控時第一下之後看不到預覽）。建議：另外支援按住拖曳、放開完成（移動超過 6 螢幕 px 才算拖曳；沒移動時照舊等第二下）。 |
| D30 | **鎖定的保存** | 舊版的鎖定（lockMovement…）不在存檔與復原的快照裡：重新開啟、按一次復原後鎖定就解除了。建議：存進地圖資料與快照（3.1 的鎖定欄位），舊版存檔讀進來是沒有鎖定。 |
| D31 | **群組的位置** | 舊版的群組（ActiveSelection.toGroup）放到所有物件的最上面，子物件依選取的順序疊放（先選的在下），組成群組時畫面上下關係會變。建議：群組放在原本最上面那個物件的位置、子物件維持原本的上下順序（看起來不變）；解散時放回群組的位置。 |
| D32 | **布林運算結果的種類** | 舊版地面、牆壁做布林運算後，結果失去地面／牆壁的標記與圖樣設定（之後選取時沒有圖樣的區塊、疊放規則也不再適用），而且與原物件共用同一個圖樣物件（對齊會互相影響）。建議：結果保留種類、圖樣與圖樣細節，圖樣複製一份重新對齊。 |
| D33 | **重新開啟後的外觀** | 舊版畫的當下物件不快取（描邊的陰影也落在填色上），重新開啟後 Fabric 預設快取（陰影只在外圍），同一張地圖重新開啟後外觀不同。建議：一般物件與裝飾一律不快取，與畫的當下相同（夾具的匯出圖比對也以畫的當下為準）。 |
| D34 | **選取時改牆壁圖樣的縮放** | 舊版選取牆壁後改「縮放」只改記錄的數字，線條的圖片不重新縮放（畫面沒有變化，要重畫才看得出來）。建議：線條的圖樣跟著重新縮放（3.4 的做法）。 |
| D35 | **面板輸入後回到畫布** | 舊版在面板的數字欄改完後，焦點留在欄位上，之後在畫布上點作圖再按 Enter／Esc 會被欄位吃掉（折線、多邊形完成不了）。建議：按到畫布時面板的輸入欄失去焦點（文字編輯用的隱藏輸入欄除外）。 |
| D36 | **空白鍵平移與按鈕** | 舊版的空白鍵只要不在輸入欄就是平移，焦點在按鈕上時也會按下那個按鈕。建議：滑鼠在畫布上時空白鍵是平移（不按按鈕）；滑鼠不在畫布上、焦點在按鈕等控制項上時空白鍵照常操作那個控制項（鍵盤使用者）。 |
