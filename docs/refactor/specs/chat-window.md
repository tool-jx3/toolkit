# 聊天視窗產生器（chat-window）行為規格

## 0. 概要

產生一段給 OBS「瀏覽器來源」用的**自訂 CSS**。把這段 CSS 貼進開著 CCFOLIA「聊天另開視窗」頁面（`https://ccfolia.com/rooms/<房間ID>/chat`）
的瀏覽器來源，頁面就會變成直播畫面上的聊天／擲骰視窗：只留最新幾則、可以只留擲骰、依成敗上色、自訂視窗與訊息的外觀、標題、
進場與消失的動態。工具有設定區與即時預覽（模擬 CCFOLIA 頁面，可以送測試訊息、切換秘匿分頁），輸出可以複製或下載成 `.css`。
設定自動存在瀏覽器裡，也可以存成專案檔。沒有圖片或檔案輸入（專案檔除外），全部在瀏覽器內處理，不上傳任何東西。

靈感來源：shiki365/chat-window-maker（<https://github.com/shiki365/chat-window-maker>）

名詞：本文的「視窗」指 CSS 套用後畫在來源裡的那個框；「來源」指 OBS 瀏覽器來源的整個畫面（寬 × 高）；「則」是一則聊天訊息。

## 1. 功能清單（對等驗證以此為準）

選項名稱一律是本規格自己的描述，新版的介面文字照 DESIGN.md 用詞表自訂。「範圍」欄的數字是可調範圍與間隔；
**外觀類設定的預設值由範本決定**（舊版開頁＝套用第 1 個範本，見 F01、F99），所以表中只寫範圍，不寫舊版範本的數值。

  - 他人的秘密擲骰：**沒有結果 span**，內文是「Secret dice 🎲」。
- **系統訊息**：用 `:HP-2` 之類的指令改角色數值時，由 CCFOLIA 代為發出的通知，格式是「[ 角色名稱 ] 數值名 : 舊值 → 新值」；這種訊息沒有名字也沒有頭像（頭像欄是空 div、名稱 span 是空的）。
  可用「頭像欄裡的 div 是空的」辨認。
- **虛擬捲動**（@tanstack/react-virtual）：外層 div 的高度＝已量測訊息高度總和；被隱藏（不佔空間）的訊息量到 0，因此只要隱藏較舊的訊息，
  可見範圍一定延伸到最新一則（則數上限 30＜前後 50 則的預先算繪，所以最新 30 則一定在 DOM 裡）。CCFOLIA 會把清單捲到最新一則。
- **清單高度為 0 時不算繪任何訊息**；若清單的高度取決於訊息本身（例如讓清單配合內容高度），就會一直維持 0、畫面空白（2026-09 在 OBS 確認）。
  因此清單至少要保留 1px 高。
- 分頁的選擇 CCFOLIA 不會保存：重新載入後回到主分頁「メイン」。
- 編輯過的訊息會多一個「[編集済]」標記；自己的訊息有滑過才出現的編輯按鈕。

### 3.2 外部事實：OBS 瀏覽器來源

- 在 OBS 加一個「瀏覽器」類型的來源；它的屬性有網址、寬度、高度、自訂 CSS。自訂 CSS 欄預設已有一段讓背景透明的 CSS，**要整段清空再貼上**。
- 寬高填工具上的來源大小。
- 畫面空白、第一次使用、或要看秘匿分頁時，瀏覽器來源必須有登入 CCFOLIA 帳號：把來源網址暫時換成 `https://ccfolia.com/`，在來源上按右鍵選「互動」，
  在跳出的視窗裡登入，然後把網址換回聊天頁（登入狀態會保留）。**在互動視窗裡只登入，不要進入房間**；若不小心進了房間，畫面會變成整個房間，此時把網址改成
  `https://ccfolia.com/` 確定，再改回聊天頁網址確定即可恢復。
- 要顯示主分頁以外的分頁：在來源上按右鍵選「互動」，把滑鼠移進畫面（需開 F86），從冒出來的分頁列點選。CCFOLIA 不記住這個選擇，重開 OBS 後要重選。
- 瀏覽器來源**不能複製**（右鍵「貼上（複本）」永遠是灰的，obs-browser 標了不可複製的旗標）。要同時顯示擲骰用與秘匿用，就再「新增來源 → 瀏覽器」
  建第二個、填同一個聊天頁網址、各自貼上 CSS；只有秘匿用那個要在互動裡選秘匿分頁。登入狀態所有瀏覽器來源共用；大小位置可以用右鍵
  「複製變換」→「貼上變換」對齊。
- 瀏覽器來源屬性裡「看不見時關閉」與「場景切到使用中時重新整理」這兩個選項若有勾，切換場景就會讓分頁回到主分頁。
- **OBS 31 以上**（內建 Chromium 127）才支援：以 `:has()` 判斷訊息類型、「從後面數第 n 個符合條件者」這類進階選擇器、容器查詢單位。舊版 OBS（30，Chromium 103）
  會略過這些規則：只列擲骰／隱藏系統訊息退化成「最新 N 則全部類型」、依成敗上色與成敗外框發光無效、長訊息捲動停在開頭不動。
- 使用 Google Fonts 時，跑 OBS 的電腦要能連網；使用電腦字型時，跑 OBS 的電腦要裝同一套字型，否則退回一般黑體；字型沒有中文字時只有中文字退回。
- CCFOLIA 發言時房間下方的「附立繪訊息框」可以用姊妹工具「訊息框產生器」做；那邊的擲骰只顯示最後「＞ 成功」一段，所以建議台詞用訊息框、
  完整擲骰結果用本工具（兩個來源、登入共用）。

### 3.3 房間網址的解析

- 文字（去掉前後空白）中若含「`rooms/` ＋ 一段英數 `_` `-`」，取那一段為房間 ID（後面的 `/chat`、查詢參數等忽略）。
- 否則，若整段是 4 個字元以上的英數 `_` `-`，當成房間 ID。
- 其餘（空白、太短、含其他字元）→ 無網址。
- 例：`https://ccfolia.com/rooms/AbC_d-12xyz` → `https://ccfolia.com/rooms/AbC_d-12xyz/chat`；`AbC_d-12xyz` → 同上；`abc` → 無；
  `https://ccfolia.com/rooms/Zz99/chat?x=1` → `https://ccfolia.com/rooms/Zz99/chat`；`hello world` → 無。

#### 3.4.3 要顯示的訊息

- 只顯示最新 N 則，其餘不顯示也不佔位置。

  |---|---|---|
  | 最新在下 | 貼底 | 貼頂 |
  | 最新在上 | 貼底 | 貼頂 |

#### 3.4.4 單則訊息的方框

- **每則一框**：整則（頭像＋文字）包在一個方框裡：背景色＋不透明度、實線外框、圓角、陰影（黑色、往下約 2px、模糊約 10px，不透明度＝陰影值）。

- **對話泡泡**：頭像在框外，框只包住名稱與內文（背景、外框、圓角、陰影同上，留白同上）。框左側有一個指向頭像的三角形尾巴：寬約 7px、高約 14px、
  顏色＝框的背景色（含不透明度），尾巴上緣距框頂約 min(14, 頭像大小 ÷ 2 − 7) px，此值 6 以下時改為 8px。
- **無框**：沒有背景、外框、陰影、圓角；內側留白照樣有效；有左側線條時左留白＝左右留白＋線條粗細＋6px。
- **左側線條**：在方框左緣（泡泡則為文字框左緣），從頂到底，寬＝粗細，左側兩角跟方框圓角一致。
  - 角色色：線條＝該則的角色顏色（系統訊息沒有角色色，線條變成內文顏色）。
  - 指定色：照設定。
  - 依擲骰成敗（OBS 31＋）：成功／失敗／其他結果分別用 F66 的三色；不是擲骰的訊息用指定色。
- **成敗時外框發光**（每則一框／對話泡泡；OBS 31＋）：成功與失敗的訊息，方框外框顏色換成結果色（外框粗細為 0 時看不到這部分），並加上結果色、
  模糊約 12px 的外發光；其他與非擲骰不變。
- **分隔線**：每則的下方一條 1px 線（顏色＋不透明度），與該則內容的距離＝max(2, 上下留白 ÷ 2) px；DOM 上最後一則（最新的那則）不畫。

- 不顯示：名稱與時間都不顯示，高度為 0（但角色色的左側線條仍正常）。

  - 無。
- 長訊息截斷：1～10 行時，該則（內文＋接在後面的擲骰結果合計）超過行數的部分截斷並加「…」；0 不截斷。

#### 3.4.8 擲骰結果

- 字型、大小、字重照設定；行高約 1.35；字距約 0.02em；**不在「成功」「失敗」等詞的中間斷行**（在空白處斷行；CCFOLIA 原本會任意斷行）。
- 換行：結果另起一行，上方約 0.15em；不換行：接在指令後面。
- 顏色依 CCFOLIA 的分類（3.1）：成功、失敗、其他三色。
- 樣式：
  - 純文字。
  - 外框：約 1.5px 實線外框（結果色）＋結果色約 12% 的底色、圓角約 0.35em、內距約上 0.05em、右 0.55em、下 0.08em、左 0.3em；換行時框寬剛好包住文字，
    不換行時左側多約 0.2em。
  - 實心色塊：底色＝結果色，同上的圓角與內距；文字色自動選深色（約 #15161a）或白色：以 (299R＋587G＋114B) ÷ 1000 計算亮度，大於 150 用深色；
    沒有文字效果。
- 成功與失敗發光：成功、失敗的結果文字加兩層同色光暈（約 6px、85% 不透明，約 14px、50%），再加上內文的文字效果；其他類不發光。
- 出現瞬間閃一下：結果出現時亮度約 2.2 倍，1.4 秒內降回原本（先快後慢；量測：0.35 秒約 1.75 倍、0.7 秒約 1.38 倍、1.05 秒約 1.11 倍），只在出現時一次。

  - 下底線：整個標題列下方一條 2px 實線（線條顏色），橫跨視窗內容寬，文字與線之間約 0.3em。
  - 頁籤狀：文字放在上方兩角圓（約 0.4em）的頁籤裡，頁籤底色＝線條顏色，內距上下約 0.22em、左右約 0.9em；**文字色依頁籤底色亮度自動選深色或白色**（規則同 3.4.8），
    不用「文字顏色」。
  - 左右延伸線：文字兩側各一條 1px 線（線條顏色）延伸到視窗內容邊緣，線與文字間約 0.6em，每側至少約 0.6em；一律置中。
- 對齊：靠左、置中、靠右。
- 鎖頭圖示（只在含分頁名稱時）：開 → 分頁名稱前約 0.9em 的鎖頭（文字色），與文字基線對齊；關 → 不顯示。
- F86 開啟且滑鼠在頁面上時，含分頁名稱的標題會恢復成一般的分頁列（才能選分頁），見 3.4.11。

#### 3.4.10 秘匿分頁參加者頭像列

- 只在 CCFOLIA 有那一列時（目前分頁是設定了參加者的秘匿分頁）才看得到；主分頁沒有。
- 不顯示：那一列隱藏。
- 顯示：
  - 標題是自訂文字時：在標題下方，與標題間隔約 6px。
  - 標題是分頁名稱、或不顯示標題時：放在分頁名稱標題的下方（不顯示標題時放在視窗最上方），下方與訊息的間距＝標題下方間距。
  - 水平對齊跟 F28；前綴文字在頭像左邊，與頭像間隔約 0.5em，使用標題的字型、字重、文字顏色，大小＝F34，字距約 0.06em，單行。
  - 頭像：圓形、大小 F35；彼此間隔 F36（負值重疊，左邊的蓋在右邊上面，順序與 CCFOLIA 相同）；外圈 F37（加在頭像外側）。沒有圖片的使用者顯示灰底（約 #5a5a5a）與名稱首字，字級約頭像的 45%（至少 8px）。

#### 3.4.11 OBS 互動時的分頁列（F86）

- 開啟：滑鼠在頁面上時，CCFOLIA 的分頁列（不含輸入框）出現在來源最上方，橫跨整個來源寬，深色底（約 #212121）、下方陰影，蓋在視窗之上；滑鼠離開即消失。
  標題含分頁名稱時，滑鼠在頁面上這段期間標題列改回一般分頁列的樣子；標題不含分頁名稱時，分頁列只在滑鼠在頁面上時出現。
- 關閉：分頁列永遠不出現（含分頁名稱的標題照常顯示）。
- 直播畫面上（沒有滑鼠）看不到任何分頁列。

#### 3.4.12 動態

**進場**（每則訊息出現時，包含來源載入時已經在的訊息）。時長＝設定值；緩動為先快後慢（量測淡入的不透明度：時間 25% → 約 0.38、50% → 約 0.68、75% → 約 0.91）。

| 進場 | 起點 → 終點 |
|---|---|
| 淡入 | 不透明 0 → 1 |
| 由下往上滑入 | 從下方 18px、不透明 0 → 原位、1 |
| 由上往下滑入 | 從上方 18px、不透明 0 → 原位、1 |
| 由右往左滑入 | 從右方 40px、不透明 0 → 原位、1 |
| 由左往右滑入 | 從左方 40px、不透明 0 → 原位、1 |
| 放大彈出 | 以中心縮放：0.6 倍、不透明 0 →（60% 時間）1.05 倍、不透明 1 →（100%）1 倍；每段先快後慢。量測（1 秒）：0.25 秒約 0.87 倍／0.59；0.5 秒約 1.03 倍／0.96；0.6 秒 1.05 倍／1；0.75 秒約 1.02 倍 |
| 由模糊變清楚 | 模糊約 8px、不透明 0 → 清楚、1 |

**消失**（F72）：訊息出現後停留「消失前停留」秒（長訊息捲動時再加上等待＋捲完時間，即從捲完才開始計時），然後在「消失速度」秒內：
前 75% 時間淡出到透明（先慢後快；量測：淡出段經過 1/3 時約 0.84、2/3 時約 0.49），後 25% 時間收起所佔的空間、與上一則的間距同時縮為 0，
其他訊息遞補上來。高度實際上在收起段的最後一小段才變成 0（看起來淡出後一下子遞補）。消失後不再出現；來源被重新載入時，消失過的訊息會先進場再照時間消失。

**長訊息慢慢捲動**（F71，只在開啟且則數＝1 時生效，產出才含捲動；需 OBS 31＋）：

- 該則訊息超過視窗時：等待「開始前」秒後，於「捲完所需」秒內**等速**往上移，直到內容底端貼齊視窗內容區底端（扣掉方框的上下留白與外框），然後停住。
  放得下的訊息不動；永遠不會往下移。速度不隨長度調整（越長捲越快）。
- 有頭像時只有文字欄（名稱＋內文）移動，頭像不動；沒有頭像時整則移動。移動的文字在方框內側被裁切，不會蓋過方框上緣（對話泡泡則是整個泡泡移動）。
- 量測（480 × 200、填滿、等待 2 秒、捲完 10 秒，該則高 237px、清單高 126px）：0～2 秒位移 0；4.5 秒 −27.8px；7 秒 −55.6px；12 秒 −111.3px（終點）；之後維持。
- 捲動時頭像固定上緣對齊；視窗固定為填滿。

### 3.7 對等驗證的比對方法

產生的 CSS 文字是各自的表達，**不比對文字**，比對「套到同一份中立模擬 DOM 上的畫面」：

- **中立模擬 DOM**：`/tmp/claude-0/-home-user-toolkit/4d5f38ef-cf3b-5354-95f1-00b7850b7d3f/scratchpad/specs-g4b/mock-ccfolia-chat.html`
  （觀察者依 3.1 自行撰寫；含 CCFOLIA 本身樣式的近似值、虛擬捲動的高度規則與「清單 0 高不算繪」、主分頁／秘匿分頁、參加者頭像列、通知條、
  以 `html.mock-hover` 模擬滑鼠在頁面上）。
- **設定組**：`specs-g4b/cases-chat.json`（44 組＋1 組可選；每組有白話描述，驗證者照描述在新版設定，存成 `new-css/<id>.css`）。
- **腳本**：`specs-g4b/compare.mjs`。`node compare.mjs legacy chat` 產生舊版 CSS；`node compare.mjs diff chat <新版CSS資料夾>` 對每組、每個時間點
  （動畫以固定毫秒暫停）分別截圖，輸出「舊｜新｜差異」並排圖與 `report.json`（差異像素數、比例、最大通道差）。`node compare.mjs self chat` 為自我檢查（舊對舊應為 0）。
- **容許差異**：
  - 靜態畫面：任一通道差 > 8 的像素不超過整張的 1%，並目視並排圖確認差異只在文字反鋸齒或 1px 邊界。
  - 動畫時間點：容許相當於 ±1 影格（約 17ms）的時間差，差異像素不超過 3%。
  - 質感雜訊（紙張、顆粒）：圖樣可不同，比較視窗區域的平均色（每通道 ±4）與明暗標準差（±20%）。
  - 開頭說明註解的文字、規則的寫法與順序、字型後備清單：不比較。
  - 主控核准的刻意差異（5.）在報告中註明。
- **互動功能**（F01～F111 中的介面行為）：Playwright 操作兩邊比對狀態（例如復原步數、自動存檔內容、狀態列的種類、按鈕啟用）。

## 4. 互動與手感

- 改任何設定都立刻反映在預覽與 CSS 檢視區（同一個畫面更新週期內合併成一次）。滑桿拖曳中就即時預覽，放開才記入復原與存檔。
- 預覽每次改設定都會從頭重播動態；有「消失」時全部消失後要靠測試訊息再看。
- 快捷鍵：Ctrl／⌘＋Z 復原，Ctrl／⌘＋Y 或 Ctrl／⌘＋Shift＋Z 重做（F95）；分頁列方向鍵（F101）；測試訊息欄 Enter 送出（F79）。沒有其他快捷鍵。
- 自動存檔約 0.4 秒延遲；開頁時還原設定與最後的設定分頁；測試訊息不保存。
- 預設值：來源 480 × 460、F86 開、預覽背景彩色、預覽分頁主分頁、房間空白、檔名 `chatwindow`，外觀＝第 1 個範本。
- 開頁後狀態列顯示準備完成。

## 5. 容易做壞的地方

- **CCFOLIA 自身樣式很強**：有行內樣式（名稱的顏色、內文的任意斷行設定、虛擬捲動的高度與位移），也有 MUI 的元件樣式。產生的規則必須確實蓋過，
  但**會被動畫改動的屬性（位移、不透明度、縮放、模糊）不能用壓過動畫的寫法**，否則進場、消失、捲動動畫失效。
- **名稱的顏色**：角色顏色是 CCFOLIA 寫在名稱上的行內顏色。要讓「線條＝角色顏色、文字＝指定色」同時成立，文字色與線條色要分開控制（舊版保留原本的顏色、另外改文字的填色）。
- **只顯示最新 N 則**要靠「隱藏較舊的訊息」，讓虛擬捲動量到 0 高，可見範圍才會一直延伸到最新；不能用捲動或位移來做。
- **清單至少 1px 高**，否則「隨內容伸縮」的視窗在 OBS 上什麼都不顯示（3.1）。
- **清單不可捲動、裁切要看排列方向**：CCFOLIA 會把清單捲到最新，若清單只是「隱藏超出」而仍保留捲動位置，比視窗高的單則會被切掉開頭。
  舊版改用不保留捲動位置的裁切，並以 flex 的排列方向決定切哪一側。
- **找分頁不能用 role="tab"**：除了主分頁以外的分頁 role 是 "button"。被選的分頁看 `.Mui-selected`。
- **參加者頭像列**是 header 的第 2 個 toolbar，直接放在 header 下沒有包裝；用「第 1 個 toolbar」選標題時要排除它。
- **系統訊息**靠「頭像欄裡是空 div」辨認，與擲骰的判斷都需要 OBS 31（`:has()`）；舊 OBS 要能優雅退化（不能整個壞掉）。
- **擲骰結果分類 class 是雜湊**：CCFOLIA 改主題就會變；集中放在 `web/src/ccfolia/`，並在 F69 的說明提醒可能失效。
- **字重要換成字型實有的字重**，否則 Google Fonts 的整條載入會失敗（字型全部沒載到）。
- **文字欄的跳脫**：標題文字、前綴文字、字型名稱可能含引號、反斜線、換行或 `*/`，輸出時要正確跳脫；寫進註解的部分要避免提早結束註解（舊版把 `*/` 拆成 `* /`）。
- **進場動畫也會在來源載入時對既有訊息播放**；消失動畫在 OBS 重新載入時會讓已消失的訊息再出現一次（舊版行為，說明裡要提醒）。
- **消失的計時**在捲動時要從捲完才開始，否則長訊息讀到一半就消失。
- **捲動的位移量**要用「視窗內容區高 − 該則高度」（只往上、不往下），有頭像時只移動文字欄並把方框留白加回去；捲動時頭像必須上緣對齊。
- **捲動只在則數 1 時產出**；則數不是 1 時即使開關開著也不能輸出捲動（否則會滑到別則上面）。
- **刻意差異候選（需主控確認）**：
  1. **分隔線在「最新在上」時位置錯**（3.4.4）：舊版線畫在每則的下方、最新那則沒有線，排列反過來後變成最舊那則下方多一條、最新與第二新之間沒有線。
     建議新版改成「相鄰兩則之間才有線」（兩種排列都對）。
  2. **來源寬高欄的修正值不回填**：舊版在數字欄仍有焦點時把值修正到範圍內，但欄位裡仍顯示原本打的數字（例如打 99999，實際是 2160），直到下次重繪。
     新版在離開欄位時回填修正後的值，屬刻意改善。
  3. **說明文字與實際不符**：舊版擲骰分類說明寫「失敗包含他人的秘密擲骰」，但他人的秘密擲骰其實沒有結果（3.1），不會被上色也不會被「只列擲骰」列出。
     新版說明照實際寫。
  4. **舊專案與自動存檔的匯入（F111）**：是否要做、要不要讀同網址的舊版自動存檔，需主控決定。觀察者建議：專案檔匯入要做（使用者手上可能有存檔）；
     自動存檔在第一次開頁時讀一次即可。
  5. **字型清單順序與後備字型**：新版若把繁中字型排前面、或改後備清單，屬可接受差異。
  6. **範本**：新版自做繁中範本，開頁預設外觀因此與舊版不同；對等驗證的設定組以「明確指定的數值」比較，不比較範本本身。
