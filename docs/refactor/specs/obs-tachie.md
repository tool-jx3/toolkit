# Discord 通話立繪產生器（obs-tachie）行為規格

## 0. 概要

用 Discord 語音通話跑團、以 OBS 直播時，把 Discord Streamkit 語音疊加層（每個人的小頭像＋名字）改成**常駐的立繪**：
立繪固定畫在畫面的指定位置，那個人說話時立繪會彈跳、外框發光或閃爍，可以讓沒說話的人變暗、可以只在本人在頻道裡時顯示、可以附名字標籤。
工具分三步：①登錄「誰」（Discord 的使用者 ID、備忘名稱、畫面上的名字）、②製作「外觀」預設集（立繪圖片、位置與大小、說話效果、名字標籤的樣式）、
③選一組「人 × 外觀」，產生要貼進 OBS 瀏覽器來源「自訂 CSS」的 CSS（一組＝一個瀏覽器來源），可以複製或下載。立繪圖片可以上傳或給網址，
通常以 data URI 直接嵌進 CSS。所有資料自動存在瀏覽器裡，處理都在瀏覽器內完成。

靈感來源：max-enterme/obs-tachie-generator（<https://github.com/max-enterme/obs-tachie-generator>）

## 2. 輸入

- **Discord 使用者 ID**：任意文字，新增時只留數字（F03）。正常的 ID 是 17～20 位數字（Discord 的 snowflake）；工具不檢查位數。
- **立繪圖片**（3.3）：
  - 上傳：瀏覽器能解碼的圖片（選檔對話框只列圖片類型；PNG、JPEG、WebP、GIF 等），檔案 ≤ 8 MB（8 × 1024 × 1024 位元組）。
  - 網址：`http(s)://…` 或 `data:` 開頭；格式不正確的文字（例如 `not a url`）在「直接用網址」時照樣採用並警告主機可能被擋。
- **數字欄**：距離可負；寬度 ≤ 0 視為原尺寸；名字大小 ≤ 0 時輸出成 1px；週期、外框寬等由瀏覽器的最小值限制。
- **文字欄**：備忘名稱、畫面上的名字、字型名稱可以含任何字元（見 F75）。
- 沒有其他檔案輸入。

## 3. 輸出

輸出是一段 CSS 文字（複製或 `.css` 檔，UTF-8），貼到 OBS 瀏覽器來源的「自訂 CSS」。原作產生的 CSS 文字是原作的表達，本節只描述外部事實與
**套用後看得到的效果**，新版自己寫產生規則。對等的判準是：新舊 CSS 套到同一份中立模擬 DOM 上，畫面一致（3.7）。

### 3.1 外部 DOM 事實：Discord Streamkit 語音疊加層

中立模擬 DOM 依此寫成：`scratchpad/specs-g4b/mock-streamkit-voice.html`（見 3.7）。選擇器要集中放在共用模組，Streamkit 改版時只改一處。

- **網址**：在 Discord StreamKit Overlay 網站（`https://streamkit.discord.com/overlay`）選「Install for OBS」→ 語音小工具（Voice Widget），選伺服器與語音頻道，
  網站會產生形如 `https://streamkit.discord.com/overlay/voice/{伺服器ID}/{頻道ID}?icon=true&online=true&logo=white&text_color=%23ffffff&text_size=14&…` 的網址
  （其他常見參數：`text_outline_color`、`text_outline_size`、`text_shadow_color`、`text_shadow_size`、`bg_color`、`bg_opacity`、`bg_shadow_color`、
  `bg_shadow_size`、`invite_code`、`limit_speaking`、`small_avatars`、`hide_names`、`fade_chat`；以網站實際產生的為準）。
  Streamkit 透過本機的 Discord 桌面程式取得頻道狀態，所以跑 OBS 的電腦要開著 Discord 並授權 Streamkit。
- **頁面結構**（class 名稱是 CSS Modules 產生的「`Voice_` 名稱 `__` 雜湊」，雜湊會隨 Streamkit 更新而變，**只能以前綴比對**）：

  ```
  #root
  └ div（class 含 Voice_voiceContainer__）
    └ ul（class 含 Voice_voiceStates__）
      └ li（class 含 Voice_voiceState__）× 目前在頻道裡的每個人
        ├ img（class 含 Voice_avatar__；這個人說話時同一個 img 再加上含 Voice_avatarSpeaking__ 的 class）
        │   src＝這個人的頭像網址，例如 https://cdn.discordapp.com/avatars/{使用者ID}/{頭像雜湊}.png?…
        └ div（class 含 Voice_user__）
          └ span（class 含 Voice_name__）名稱（樣式依網址參數）
  ```

  舊版只依賴以下幾點（原作以實際使用過的 CSS 為準）：頭像是 `img` 本身、說話時那個 `img` 多一個含 `Voice_avatarSpeaking__` 的 class、
  `src` 含有「`avatars/{使用者ID}`」可以用來認人、名字在含 `Voice_name__`／`Voice_user__` 的元素裡、頁面根元素是 `#root`。
  其餘層級是一般的觀察，未逐一實測。
- **在頻道裡＝DOM 裡有他的 li／img**；離開頻道就從 DOM 移除。CSS 把 img 隱藏後，仍然可以用「頁面裡有沒有這個 img」判斷在不在。
- **沒有自訂頭像的人**：頭像網址是 Discord 的預設頭像（`…/embed/avatars/{0～5}.png`），**不含使用者 ID**，因此無法辨認——說話偵測與「不在頻道時隱藏」
  對這個人無效（推測，未在真實 Streamkit 實測；模擬 DOM 上舊版確實偵測不到）。說明裡要提醒「要先設定 Discord 頭像」。
- 網址參數 `limit_speaking=true`（只顯示說話中的人）會讓沒說話的人從 DOM 消失，這時「不在頻道時隱藏」會變成「沒說話就隱藏」（推測）。
- **圖片能不能顯示**（Streamkit 頁面的內容安全政策）：舊版的判斷是 `data:` 一定可以；`discordapp.com`、`discord.com`、`discordapp.net`、`imgur.com`（含子網域）
  的網址可以直接顯示；其他主機可能被擋（未實測）。
- **Discord 附件連結會過期**：`cdn.discordapp.com/attachments/…`、`cdn.discordapp.com/ephemeral-attachments/…`、`media.discordapp.net/…` 的網址
  自 2023 年起帶簽章參數（`ex`、`is`、`hm`），約 24 小時後失效。頭像、表情等沒有簽章的網址不會過期。
- **Discord 使用者 ID 的取得**：使用者設定 →「進階」→ 開啟「開發者模式」；之後在使用者上按右鍵，選單會多出複製 ID 的項目（英文介面為 Copy User ID）。ID 是 17～20 位的數字。

### 3.2 外部事實：OBS 瀏覽器來源

- 每一組「人 × 外觀」各建一個瀏覽器來源（一個來源只能畫一張立繪＋一個名字），網址都填同一個 Streamkit 語音小工具網址。
- 來源的寬高：舊版的預覽以 1920 × 1080 為基準，立繪位置是相對於來源邊緣；建議來源大小＝OBS 畫布大小，位置才會和預覽一致。
  選右、上、中央錨點時，來源大小改變後與該邊／中央的關係不變。
- 自訂 CSS 欄預設已有一段 CSS，要清空再貼上。
- 說話偵測、「不在頻道時隱藏」都靠 CSS 的 `:has()`，需要 OBS 31 以上（內建 Chromium 127；`:has()` 從 Chromium 105 起支援）。舊版 OBS（30，Chromium 103）：
  立繪照常顯示但說話時不動；開了「不在頻道時隱藏」的話立繪**永遠不會出現**（推測）。
- 名字字型要是跑 OBS 的電腦（OBS 內建瀏覽器）裡有的字型。

### 3.3 立繪圖片的處理

- **上傳**：讀成 data URI 嵌進 CSS。沒有縮小時保留原檔的位元組與格式（JPEG 還是 JPEG、動畫 GIF 保留動畫）；需要縮小時（F15）改存 PNG。
  data URI 會讓 CSS 比圖檔大約 1.33 倍；舊版不警告 CSS 大小。
- **網址的三種處理**：

  | 輸入 | 自動 | 直接用網址 | 轉成嵌入 |
  |---|---|---|---|
  | `data:` 開頭 | 直接採用（嵌入） | 同左 | 同左 |
  | 可直接顯示的主機、且不是會過期的連結（例：imgur） | 保留網址 | 保留網址 | 下載轉 data URI；失敗則保留網址並警告 |
  | 會過期的 Discord 附件連結 | 下載轉 data URI（訊息：連結會過期，已改嵌入）；失敗則保留網址並警告「會過期且轉換失敗」 | 保留網址並警告約 24 小時後失效 | 下載轉 data URI；失敗則保留網址並警告 |
  | 其他主機（含格式不正確的文字） | 下載轉 data URI（訊息：不是可直接顯示的主機，已改嵌入）；失敗則保留網址並警告 | 保留網址並警告可能被擋 | 下載轉 data URI；失敗則保留網址並警告 |

  下載需要對方主機允許跨網域讀取（CORS）；下載到的不是圖片時視為失敗。轉成嵌入時套用 F15。失敗的警告都建議「下載圖片後改用上傳」。
- **實際尺寸的量測**：每次圖片改變就量一次圖片的寬高（最多等 8 秒，量不到就當作不知道）。用途：輸出 CSS 的繪製尺寸與名字的基準寬度、F37 是否可用、F59 警告。
- **裁切與修邊**（F20～F23）：結果一律是 PNG（保留透明），尺寸不再縮放；照片類的圖可能因此變大（確認時會顯示）。裁切直接替換圖片，**不能復原**（要重來就重新匯入）。
  量測：300 × 600、內容在 70～230／40～560 的圖，修邊 → 160 × 520（9.1 KB → 6.4 KB）。直接參照外部網址的圖無法裁切（讀不到像素），顯示說明。
- 預設集清單、編輯區、預覽都直接顯示圖片。

### 3.4 CSS 套用後的效果

數字是在 3.7 的模擬 DOM（1920 × 1080）上用測試圖 `test-tachie.png`（300 × 600，不透明內容在 x 70～229、y 40～559）量到的。

#### 3.4.1 整體

- Streamkit 的所有頭像圖片、名字與名字的底框都不顯示；頁面不出現捲軸。
- 立繪是**一個與 Streamkit 元素無關的頁面層**，固定在來源的指定位置；不論頻道裡有幾個人、這個人在不在、排第幾個，都畫在同一個地方（F43 除外）。
- 每個來源只畫一個人的立繪與一個名字。

#### 3.4.2 位置（錨點與距離）

- 水平：左錨點＝立繪左緣距來源左緣「水平距離」；右錨點＝立繪右緣距來源右緣「水平距離」；中央＝立繪的水平中心在「來源中央＋水平距離」（正值往右）。
- 垂直：下錨點＝立繪下緣距來源下緣「垂直距離」；上錨點＝立繪上緣距來源上緣「垂直距離」；中央＝立繪的垂直中心在「來源中央 − 垂直距離」（正值往上）。
- 位置以**整張圖的外框**計算，包含圖片的透明留白（所以留白會讓立繪看起來偏移，F19 提醒、F20 可修）。
- 量測（立繪 300 × 600、不透明內容的範圍）：

  | 設定 | 不透明內容的範圍（x，y） |
  |---|---|
  | 左下、0／0 | x 70～229、y 520～1039 |
  | 左下、距左 100、距下 50 | x 170～329、y 470～989 |
  | 正中央、0／0 | x 880～1039、y 280～799 |
  | 正中央、右 100、上 50 | x 980～1139、y 230～749 |
  | 右上、距右 40、距上 30 | x 1650～1809、y 70～589 |

#### 3.4.3 尺寸

- 量得到圖片實際尺寸時：畫成「寬 W × 高 H」，W＝指定的寬度（沒指定就是實際寬），H＝W × 實際高 ÷ 實際寬（四捨五入，至少 1px），圖片等比縮放剛好填滿。
  量測：寬度 150 → 內容 x 35～114、y 800～1059（整張縮成 150 × 300）。
- 量不到時（讀取中、外部網址讀不到、逾時）：退回「以圖片本身的大小畫」，有指定寬度時用那個寬度、高度依比例；CSS 裡不寫死尺寸。
- 換了圖片（尺寸不同）就要重新輸出 CSS（註解提醒）。

#### 3.4.4 說話效果

這個人（以使用者 ID 辨認）的頭像處於「說話中」時才播放；說話結束立即回到靜止狀態。開著的效果**同時、同步**播放，共用週期 P，說話期間無限循環。
每個效果在一個週期內「靜止 → 最大（P/2）→ 靜止」，每半段的緩動是先慢後快再慢，所以 P/4 時剛好在一半。

- **彈跳**：立繪往上移彈跳高度 J 再落回。量測（J＝40、P＝750）：187ms 上移 20px、375ms 上移 40px、750ms 回到原位。中央錨點時仍保持置中（只有垂直移動）。
- **外框光暈**：沿著立繪不透明部分的輪廓畫一圈顏色＝設定色的實心外框，外面再加一層同色的柔和光暈；光暈的模糊半徑在 w 與 4w 之間脈動（w＝外框寬度，≤ 0 當 1）。
  量測（w＝2，P＝750）：靜止時實心外框約 4px（≈ 2w）、帶淡光暈的範圍約 9px；P/2 時實心部分擴到約 10px（≈ 5w）、淡光暈延伸到約 23px（≈ 11w）。
  w＝6 時 P/2 淡光暈延伸約 69px。實心外框看起來是把立繪往四個斜角方向（右下、左上、左下、右上）各錯開 w 疊出來的，所以轉角處略呈方形。
- **閃爍**：整張立繪的不透明度 1 → 0.35（P/2）→ 1。量測：P/4 約 0.67、P/2 0.35。
- **沒有任何效果**時說話不會有任何變化（除非開了變暗）。
- 效果會讓立繪超出原本的範圍（光暈、往上彈），貼著來源邊緣時會被切掉；F27 提示需要的邊距（光暈每邊約 7 × w，錨點在上方時再加彈跳高度）。

#### 3.4.5 變暗與隱藏

- **安靜時變暗**：沒在說話（包括不在頻道）時，立繪亮度降到 50%（每個顏色通道減半；量測 (60,110,200) → (30,55,100)）；說話時恢復 100%（開著外框光暈時也恢復）。名字不變暗。
- **不在頻道時隱藏**：這個人不在語音頻道（頁面裡沒有他的頭像）時，立繪與名字都不顯示；在頻道裡（說不說話都一樣）就顯示。關閉時永遠顯示。

#### 3.4.6 名字標籤

- 內容＝第 1 步的「畫面上的名字」，空白時用備忘名稱；兩者都空白、或沒開「顯示名字」時不畫。換行與控制字元換成空白，**永遠單行**，前後空白去掉。
- 名字畫在立繪之上；不套用說話效果、不變暗；開「不在頻道時隱藏」時與立繪一起出現與消失。
- 字型（空白＝Streamkit 頁面原本的字型）、大小（至少 1px）、粗體（700／400）、顏色；行高約 1.2 倍。
- 描邊：開啟且寬度 > 0 時，以 8 個方向（上下左右與四個斜角）各位移「描邊寬度」的實色影子構成外框。
- 字幕條：底色＝顏色＋不透明度％（色碼是 3 或 6 位時才套不透明度）、左右／上下留白（兩者都是 0 時不加）、圓角（> 0 時）。
- **水平位置與寬度**（W＝基準寬度＝指定寬度，否則實際寬度，都沒有則「不知道」）：
  - 沒有字幕條、或字幕條「鋪滿立繪寬度」，且知道 W：名字框寬＝W（留白算在 W 內），水平位置與立繪相同再加水平偏移，文字在框內靠左／置中／靠右。
    量測：鋪滿、靠左 → 字幕條 x 0～299（與立繪框同寬）。
  - 字幕條「配合文字」且知道 W：字幕條寬度剛好包住文字＋留白，依對齊把字幕條的左緣／中心／右緣對齊立繪框的左緣／中心／右緣，再加水平偏移。
    量測：靠右 → 字幕條右緣 x≈300（立繪框右緣）；靠左 → 左緣 x≈0。
  - 不知道 W：名字框縮成文字寬，對齊錨點那一側：左錨點＝與立繪左緣對齊，右錨點＝與右緣對齊，中央＝置中；對齊設定無效（F37 停用、F59 警告）。
- **垂直位置**：下錨點＝名字框下緣在「立繪下緣往上垂直偏移」處；上錨點＝名字框上緣在「立繪上緣往上垂直偏移」處；中央錨點＝名字框垂直中心在「立繪垂直中心往上垂直偏移」處。
  預設 −8 表示名字框下緣在立繪下緣下方 8px（立繪貼著來源底邊時，名字會被切掉一部分）。量測：右上錨點、距上 30、垂直偏移 +10 → 名字框上緣 y＝20。
- 名字不跟著彈跳。

#### 3.4.7 CSS 裡的說明註解

- 圖片的定義旁註明「備忘名稱（ID）」或只有 ID。
- 用簡短註解說明：只用一個頁面層畫立繪、Streamkit 的元素全部隱藏只拿來偵測說話；立繪常駐；用實際尺寸算出的繪製尺寸（附數字）與「換圖要重新輸出」；名字（附基準寬度與提醒，有用到實際寬度時）；
  說話時的效果；不在頻道時隱藏（含名字時另註明）；帳號名稱已隱藏（顯示名字時）。新版用自己的文字。
- 沒有使用者時（舊版 UI 不會發生）只輸出一行提示註解。

### 3.5 下載的檔名

- `streamkit-<主幹>.css`，主幹＝「人的備忘名稱（空白時用 ID）」＋「-」＋「預設集名稱（空白時用 `preset`）」。
- 去掉前後空白；連續的「字母（任何文字）、數字、`.`、`_`、`-` 以外的字元」換成一個「_」；去掉開頭與結尾的「_」；結果空白時用 `streamkit`。
- 例：人「B」、預設集未命名 → `streamkit-B-preset.css`；人「阿明」、預設集「平常 v2」→ `streamkit-阿明-平常_v2.css`。

### 3.6 自動存檔（舊格式，相容用）

新版可以用自己的格式。以下是**為了讀入舊資料而必須知道的格式**（F78）。

- 舊版存在 localStorage，鍵 `obs-tachie-generator:v1`，值是 JSON：
  - `users`：陣列，每筆 `id`（數字字串）、`name`（備忘名稱）、`displayName`（畫面上的名字，可省略）。
  - `presets`：陣列，每筆：`id`（內部鍵）、`name`、`imageUrl`（data URI 或網址）、`left`／`bottom`（**不論錨點都放在這兩個欄位**：水平距離／垂直距離）、
    `anchorX`（`left`／`center`／`right`，可省略＝`left`）、`anchorY`（`top`／`middle`／`bottom`，可省略＝`bottom`）、`width`（可省略＝原尺寸）、
    `dimWhenQuiet`、`hideWhenAway`、
    `speak`：`bounce`、`jumpPx`、`outline`、`outlineColor`、`outlineWidth`、`blink`、`durationMs`；
    `nameLabel`：`show`、`offsetX`、`offsetY`、`fontSize`、`fontFamily`、`color`、`bold`、`align`（`left`／`center`／`right`）、`outline`、`outlineColor`、
    `outlineWidth`、`background`、`backgroundColor`、`backgroundOpacity`（0～100）、`backgroundPadX`、`backgroundPadY`、`backgroundRadius`、`fit`（`text`／`stretch`）。
  - `pairings`：陣列，每筆 `userId`、`presetId`。
  - `selection`：`userId`、`presetId`（可為 null）。
- 讀入時的修正（舊版行為）：沒有 `presets` 陣列（更舊的格式或壞資料）→ 全部清空；`id` 或 `name` 不是字串的使用者丟掉；沒有 `id` 的預設集丟掉；
  其他欄位缺漏或型別不符改用預設值（4.）；`width` ≤ 0 改成原尺寸；指向不存在的人或預設集的配對丟掉、重複的配對合併；指向不存在的選擇改成未選。
- 上游原作的存檔與舊版相同格式。

### 3.7 對等驗證的比對方法

產生的 CSS 文字各自表達，**不比對文字**，比對套到同一份中立模擬 DOM 上的畫面：

- **中立模擬 DOM**：`/tmp/claude-0/-home-user-toolkit/4d5f38ef-cf3b-5354-95f1-00b7850b7d3f/scratchpad/specs-g4b/mock-streamkit-voice.html`
  （觀察者依 3.1 自行撰寫；可設定頻道裡的人、誰在說話、沒有自訂頭像的人；雜湊後綴故意與真實不同，確保只靠前綴比對）。
- **設定組**：`specs-g4b/cases-tachie.json`（25 組；圖片一律 `test-tachie.png`、ID 123456789012345678；每組有白話描述，驗證者照描述在新版設定，
  存成 `new-css/<id>.css`）。
- **腳本**：`specs-g4b/compare.mjs`。`node compare.mjs legacy tachie` 產生舊版 CSS；`node compare.mjs diff tachie <新版CSS資料夾>` 以 1920 × 1080 截圖，
  動畫暫停在指定毫秒（例如 0、P/4、P/2），輸出「舊｜新｜差異」並排圖與 `report.json`。`node compare.mjs self tachie` 為自我檢查。
  另有 `specs-g4b/ot-measure.mjs`（不透明範圍與像素取樣，3.4 的數字由此而來）。
- **容許差異**：
  - 靜態畫面：任一通道差 > 8 的像素不超過 0.5%（名字文字的反鋸齒除外，目視確認）。
  - 動畫時間點：容許相當於 ±1 影格（約 17ms）的時間差，差異像素不超過 2%；外框光暈的淡光暈邊緣（不透明度 < 20%）差異不計。
  - 註解文字、規則寫法與順序不比較。
- **介面行為**（步驟、使用者、預設集、裁切、組合、存檔）：Playwright 操作兩邊比對結果（清單內容、按鈕狀態、存檔內容、下載檔名）。

## 4. 互動與手感

- 所有改動立即反映在預覽與輸出 CSS（第 3 步）並立即存檔；沒有復原／重做，沒有快捷鍵（預覽畫面可用 Enter／空白鍵切換說話）。
- 刪除使用者、刪除預設集、刪除已儲存組合、恢復預設都**不詢問**；裁切用面板內兩段式確認。
- 開頁永遠在第 1 步；圖片輸入方式預設「網址」、最大寬度 0、網址處理方式「自動」（都不存檔）。
- 新預設集的預設值：錨點左下、距離 0／0、寬度原尺寸；彈跳開（10px）、外框光暈開（白、2px）、閃爍關、週期 750ms；安靜時變暗關、不在頻道時隱藏關；
  名字標籤關、位置 0／−8、大小 32、字型空白、白色、粗體開、置中、描邊開（黑、3px）、字幕條關（黑、60%、圓角 6、留白 12／6、配合文字）。
- 複製成功的「已複製」標示約 1.5 秒後消失。
- 處理圖片時顯示「處理中」，套用網址按鈕停用。

## 5. 容易做壞的地方

- **只能以 class 前綴比對**：Streamkit 的 class 帶雜湊（例如 `Voice_avatarSpeaking__` 後面接一串），寫死完整 class 名會在 Streamkit 更新後失效。
- **說話偵測要對隱藏中的 img 也有效**：Streamkit 的 img 被隱藏，但「頁面裡有沒有說話中的那個 img」仍然可以判斷，立繪才能改畫在獨立的頁面層。
- **置中與彈跳的位移不能互相覆蓋**：置中靠位移實現時，彈跳動畫的位移會把置中蓋掉（立繪在動畫期間飛到旁邊）。舊版把置中的位移織進彈跳動畫的每一格；
  量測：下中錨點彈跳時水平位置不變（x 880～1039）。所有會改位移的效果都要一起考慮。
- **變暗與外框光暈都用到濾鏡**：說話時光暈的濾鏡會取代變暗，所以亮度自然恢復；只有變暗而沒有光暈時要明確恢復 100%。
- **不在頻道時隱藏的名字**：名字也要一起隱藏、一起出現。
- **實際尺寸寫死**：沒有指定寬度時，CSS 無法得知畫出的圖有多大，名字的對齊與繪製尺寸都要靠工具量好寫進去；量不到時要有退路（3.4.3），不能讓立繪消失。
- **透明留白會讓錨點偏掉**：位置以整張圖計算，提醒使用者修邊。
- **名字的跳脫**：名字可能含引號、反斜線、換行；備忘名稱寫進註解時要避免 `*/` 提早結束註解（舊版把 `*/` 拆開）；字型名稱要去掉 `; { } ( )` 等字元並逐一加引號
  （否則以數字開頭的字型名會讓整條字型設定被丟掉；通用字族名 `serif`、`sans-serif` 等不加引號）。
- **顏色防呆**：外框、名字、描邊的顏色不是「井字號加 3、4、6、8 位十六進位」或「rgb(…)／rgba(…) 寫法」時一律改白色，避免 CSS 壞掉（來自舊存檔的值）。
- **data URI 很大**：存檔可能超過瀏覽器 localStorage 容量（舊版靜默失敗，重新整理後圖片就不見了）；CSS 也會很大（數 MB），OBS 的自訂 CSS 欄可以接受但貼上較慢。
  新版改用 IndexedDB 存圖片、並在存檔失敗時提示，屬刻意改善，**需主控確認**。
- **沒有自訂頭像的 Discord 使用者無法辨認**（3.1）：說明要提醒；新版若改用其他辨認方式（例如 `li` 的屬性）需先在真實 Streamkit 確認，屬刻意差異，需主控確認。
- **刻意差異候選（需主控確認）**：
  1. **複製失敗沒有任何回饋**：舊版剪貼簿與退回方式都失敗時什麼都不顯示。新版顯示錯誤並提示手動選取，屬刻意改善。
  2. **刪除不詢問**：刪除使用者／預設集會連帶刪掉已儲存的組合，舊版不詢問也不能復原。新版可加確認或「復原」提示，屬刻意改善。
  3. **沒有專案檔存出／開啟（F77）**：舊版資料只在瀏覽器裡，換電腦就沒了。新版若用共用的專案選單加上存出／開啟，屬新增功能。
  4. **舊資料讀入（F78）**：同網址的舊版自動存檔要不要讀入。觀察者建議要讀（使用者的圖片與設定都在裡面）。
  5. **名字預設位置 −8**：立繪貼底時名字會被切掉一部分（舊版預設行為）。維持舊預設以求對等；是否改善由主控決定。
  6. **「直接用網址」不驗證網址格式**：`not a url` 也會被採用（只警告主機可能被擋）。新版可改成格式錯誤時拒絕，屬刻意改善。
