# 劇本文字產生器（scenario-text）行為規格

## 0. 概要

把台本或描寫的文字貼進來，切成一則一則，做成 CCFOLIA 的「劇本文字」（シナリオテキスト；房間資料裡的 `notes`），
打包成可以當**房間資料**讀入的 ZIP。讀入後 CCFOLIA 的「[GM] シナリオテキスト一覧」會多出這些劇本文字，從一覽送出時
以**標題當名稱、圖片當立繪**發言，所以訊息框會顯示立繪。台詞可以帶說話者的立繪（含表情差分），描寫與 HO 可以各自附圖。
全部在瀏覽器內處理，不上傳任何東西。

- 輸入：台本或依小標分段的文字（貼上）、圖片（拖放、選檔、網址）、專案檔（本站的 ZIP；也讀得到原作的 .json 專案檔）。
- 輸出：CCFOLIA 房間 ZIP（只有劇本文字與用到的圖）；用到的圖片打包成可讀檔名的 ZIP（附清單文字檔）；專案檔。

靈感來源：shiki365/scenario-text-maker（<https://github.com/shiki365/scenario-text-maker>，本規格依 a71e9ac〔v1.4〕；
以下稱【原作】）。授權 MIT（Copyright (c) 2026 shiki365），授權全文在 `web/src/tools/scenario-text/UPSTREAM_LICENSE`；
範例文字、預設的說話者照原作翻成繁中。

用語：

| 本文用語 | 意思（原作的用語） |
|---|---|
| 劇本文字 | CCFOLIA 的シナリオテキスト（舊稱共有メモ），一則有標題、本文、圖片。 |
| 一則 | 清單裡的一筆劇本文字。 |
| 做法 | 台本（一句台詞一則）／依小標分段（作り方）。 |
| 說話者 | 登錄的人物：名稱、其他寫法、立繪、差分（話し手）。 |
| 圖片庫 | 先放進工具的圖片，說話者、差分、每則的圖都從這裡選（画像の置き場）。 |
| 旁白 | 台本裡不是台詞的行；依小標分段時是第一個小標之前的文字（地の文）。 |
| 小標 | 依小標分段時，一段的開頭行（見出し）。 |
| 清單 | 目前的文字讀出來的劇本文字（できあがり）。 |
| 手動修改 | 在清單裡直接改某一則（手直し）。第一次修改時清單固定下來。 |
| 已確定 | 「確定，換下一段文字」收起來的清單，匯出時一起放進 ZIP（確定したもの）。 |
| key 比對 | 名稱先做 NFKC 正規化、連續空白換成一個、去頭尾空白之後再比（全形英數、全形括號與半形視為相同）。 |

## 1. 功能清單（對等驗證以此為準）

驗證方式：「自動」＝e2e（`web/tests/e2e/scenario-text.spec.ts`）或單元測試（`web/tests/unit/scenario-text-*.test.ts`）；
「資料比對」＝同樣的輸入分別給原作（本機開原作的頁面，或在 Node 執行原作的 `parse.v1.js`、`roomdata.v1.js`）與新版，比對清單與 ZIP；
「目視」＝截圖並排。

| 編號 | 功能 | 行為描述 | 預設值／範圍 | 驗證方式 |

| F29 | 差分 | 每個差分：縮圖（可拖圖）、名稱（提示「差分名稱（例：笑臉）」）、圖片選單＋「加入圖片」、刪除（不確認）、圖的警告。 | — | 自動 |
| F30 | 新增差分 | 加一個名稱空白的差分，游標移到它的名稱欄。 | — | 自動 |

| F33 | 新增說話者 | 加一位名稱空白的說話者，游標移到他的名稱欄。 | — | 自動 |
| F34 | 差分名稱加進標題 | 開關：開時有差分的一則，標題（送出時的名稱）＝「名（差分）」；關時標題維持「名」、只換立繪。手動輸入的標題不受影響。 | 關 | 自動 |

## 2. 輸入

- **文字**：貼上或打字（換行 CR、CRLF 都當 LF）。
- **圖片**：PNG（含 APNG）、JPEG、GIF、WebP，依檔頭判斷（副檔名、MIME 不對也收；AVIF、BMP 等不收，5. D3）。
  大小不限，但超過 **5 MB（5 × 1024 × 1024 位元組）** 的會一直警告（CCFOLIA 的圖片上限）。
- **網址的圖**：`https://` 開頭、沒有空白字元。只記網址（瀏覽器不能讀別的網站的圖片內容），預覽用 `<img>` 顯示。
- **專案檔**：本站的專案檔（ZIP：`project.json`＋`files/<資產 id（內容雜湊）>.<副檔名>`；3.8）；原作的專案檔（JSON：
  `{ tool: "scenario-text-maker", version: 2, state: { images: [{ id, kind, name, type, size, hash, credit, dataUrl | url }], speakers, script, opts, edited, confirmed } }`，
  也接受直接是 `state` 的 JSON；舊格式的說話者、差分直接帶 `image: { kind: "file", dataUrl, fileName } | { kind: "url", url }`，讀入時搬進圖片庫，同一張只放一次）。
  讀不懂的檔案顯示「無法開啟專案檔」與原因，目前的內容不變。
- 瀏覽器存檔：**不搬移**原作的 localStorage／IndexedDB（不同網域）。

## 3. 輸出與規則

### 3.1 房間 ZIP（外部格式，CCFOLIA 1.37.4，原作 2026-09-26 讀出、2026-09-28 以真實房間驗證）

```
__data.json   {"meta":{"version":"1.1.0"},
               "entities":{"room":{},"items":{},"decks":{},"notes":{"<ID>":{"name":"標題","text":"本文","order":<數>,"iconUrl":"<網址或圖片檔名>"}, …},
                           "characters":{},"effects":{},"scenes":{},"savedatas":{},"snapshots":{}},
               "resources":{"<圖片檔名>":{"type":"image/png"}, …}}
.token        「0.」＋任意字串（不等於 SHA-256(__data.json)）
<圖片>        ZIP 根目錄，檔名＝內容的 SHA-256（64 個小寫十六進位）＋「.」＋副檔名（png、jpeg、gif、webp）
```

- 用共用層 `@/ccfolia` 的 `createAppendRoomData`＋`buildRoomZip`（房間 ZIP 的序列化與 room-zip 相同）。
- **只追加**：`room` 是空物件 `{}`，其他類別（items、decks、characters、effects、scenes、savedatas、snapshots）是空物件。
  CCFOLIA 讀入時依 ID 一筆一筆寫入，所以只會多出新的劇本文字；`room` 是 `{}` 時只更新房間的更新時間，不改設定。
- `notes` 一則＝`{ name: 標題, text: 本文, order, iconUrl }`：
  - `name`：畫面上的標題（3.3 的標題規則；空白時是空字串＝送出時用聊天欄的名稱）。
  - `text`：本文原樣（不去空白；本文只有空白的一則不能匯出）。
  - `order`：**匯出當下的秒數（floor(毫秒 ÷ 1000)）＋序號（0 起算）**，所以之後讀入的排在先前讀入的後面。
  - `iconUrl`：送出時的圖（3.3 的圖片規則）——網址的圖是網址本身；檔案的圖是 ZIP 裡的圖片檔名（CCFOLIA 讀入時上傳並換成網址）；沒有圖是空字串 `""`。
- ID：同一個 ZIP 裡不重複（新版用共用層的 `newRoomEntityId()`；原作是 20 字的隨機英數，5. D4）。
- `resources`：用到的每張檔案圖一筆（同一張圖用很多次也只有一筆、一個檔），`type` 是圖片的 MIME。
- ZIP 項目順序：`__data.json`（不縮排）、`.token`、圖片；壓縮等級 6。寫完以共用層 `checkRoomZip` 自我檢查（不通過時不下載、顯示錯誤）。
- `.token`：CCFOLIA 會比對「0.」＋SHA-256(`__data.json`)，不符時讀入前顯示「外部ツールで作成および編集されたデータです…」確認。
  原作刻意寫固定字串讓這個確認一定出現；新版用共用層的隨機值，同樣一定出現（5. D4）。

### 3.2 解析規則（原作 `parse.v1.js`；新版 `web/src/tools/scenario-text/parse.ts`）

#### 3.2.1 名稱與差分

- 名稱的比對一律 key 比對（概要的用語表）。說話者的名稱與其他寫法（以「、」「,」「，」分隔）建成索引，同一個 key 先登錄的說話者優先。
- 寫法 → 說話者：**先比對整個寫法**（名稱本身帶括號，例「艾莉絲 (alice)」也認得）；不符時拆成「名（差分）」「名(差分)」「名@差分」「名＠差分」
  （括號裡不能再有括號；@ 後面到結尾不含空白），名的部分比對說話者；差分在那位說話者的差分裡 key 比對，有就用登錄的寫法，
  沒有就照台本的寫法並標「沒有這個差分」（F08）。

#### 3.2.2 台本：一則的切法

- 每一行去掉行尾空白。
- **一行一則**：空行不算一則；某一則「還沒關上的引號」> 0 時，下一行（含空行）以換行接上，同一則最多再接 20 行。
  還沒關上的引號＝「 與 『 的個數 − 」 與 』 的個數 ＋ “ 的個數 − ” 的個數 ＋（"的個數 除以 2 的餘數）。
- **一段一則**：連續的非空行是一則（以換行接起來）。
- 每一則記下開始的行號（1 起算）。

#### 3.2.3 台本：台詞與旁白

- **引號台詞**（「自動」與「只認 名「台詞」」）：整則（可跨行）＝名＋（空白）＋引號開頭 …（任意文字）… 引號結尾，結尾引號是最後一個非空白字。
  開頭引號「『"“，結尾引號」』"”（新版一律都讀，5. D2）。名不能以空白或引號開頭、不含引號；
  名最多 40 字；名含句讀（。、，．！？!?…）時不算（是敘述）；用拉丁引號（"“）而名有超過 4 個以空白分隔的詞時不算（是句子）。
  **名的結尾是冒號（：或 :）時去掉冒號**（「艾莉絲：「你好」」，5. D1）。
- **冒號台詞**（「自動」與「只認 名：台詞」）：名＋（空白）＋全形或半形冒號＋台詞（台詞去頭尾空白、不可空白）。名不含冒號與「」『』、最多 40 字、不含句讀；
  「自動」時只認得出說話者（3.2.1）的名，「只認冒號」時任何名都算。
- 「自動」先試引號，再試冒號。
- 本文：引號台詞在「保留引號」時是引號整段，不保留時去掉頭尾各一個字；冒號台詞是冒號後面的文字。
- 認得出說話者 → 種類「台詞」、標題＝**登錄的名稱**（不是台本的寫法）、記下說話者與差分；認不出 → 種類「未登錄」、標題＝台本的寫法。
- 不是台詞的一則：「放進旁白」時是種類「旁白」、標題＝旁白的名稱、本文＝那一則原樣（行尾空白已去）；旁白的名稱認得出說話者時帶他（與差分）。「不放」時略過。

#### 3.2.4 依小標分段

- 小標的行（去頭尾空白後）：「#」～「######」開頭（結尾的 # 去掉）；■□◆◇●○▼▽★☆◎ 其中一個開頭；整行只有【…】。小標文字去頭尾空白，空的不算小標。
- 一則＝小標＋下面到下一個小標之前的行。本文＝那些行（行尾空白去掉）接起來，去掉開頭的空行與結尾的空白；中間的空行保留。
- **本文空白時本文＝小標本身**（CCFOLIA 的劇本文字本文空白時會改送聊天欄裡的文字）。
- 第一個小標之前有文字（非空行開始）時是一則「小標之前」（種類「旁白」、標題＝旁白的名稱；本文空白的不算）。
- 小標認得出說話者（3.2.1）時標題換成登錄的名稱，帶他（與差分）的立繪。
- 每則記下小標（或第一行）的行號。

### 3.3 標題與圖片（每次顯示、匯出時依目前的說話者與圖片庫決定）

- **標題**：手動輸入的標題原樣；否則有說話者、有差分而且「差分名稱加進標題」開著時是「名（差分）」（全形括號），其餘是記下的標題。
- **圖片**（依序取第一個有的）：
  1. 這一則指定「沒有圖」→ 沒有圖。
  2. 這一則指定了圖片庫的某張 → 那張（圖已經不在圖片庫時＝沒有圖）。
  3. 「自動」：有說話者時，那位說話者裡 key 比對相同的差分的圖 → 說話者的立繪；
  4. 圖片庫裡和「畫面上的標題」同名（key 比對）的第一張 → 和「記下的標題」同名的第一張。
- 「有圖」的計數、表格縮圖、預覽、匯出、打包都用這個規則。

### 3.4 從圖片庫建立差分（F31）

- 說話者的名稱與其他寫法（key）由長到短依序比對每張圖的名稱（key）：等於某個寫法 → 這是基本立繪（說話者還沒有立繪時設成這張）；
  以某個寫法開頭、後面接 空白、`_`、`-`、`@`、`(`、`:`（key 已把全形換成半形）其中一個以上 → 差分名稱＝後面去掉這些開頭字元、去掉結尾的 `)`、去頭尾空白；
  其他（例「艾莉絲的家」）不算。差分名稱空白的不算。已經有同名（key）差分的不重複建。
- 訊息：建了 n 個「已建立 n 個差分：甲、乙。」＋（設了立繪）「也設定了立繪。」；都已經有了「沒有可以新建的差分（都已經建好了）。」；
  一張都找不到「找不到以「名」開頭的圖片。請把圖片名稱改成「名_笑臉」這種形式。」（錯誤）；說話者名稱空白「請先填說話者的名稱。」（錯誤）。

## 5. 容易做壞的地方

- **標題永遠是登錄的名稱**：台本寫的是其他寫法或差分寫法時，標題仍是登錄名稱（「小艾「…」」→ 標題「艾莉絲」）；
  差分名稱加進標題是顯示時才加的（開關可以隨時切換），手動標題不加。
- **圖片跟著說話者走**：一則記的是說話者 id 與差分名稱，換說話者的立繪後所有用到他的劇本文字一起換（手動修改中、已確定的也一樣）。
- **「自動」的冒號台詞只認登錄的名字**，所以「時間：晚上九點」不會變成說話者「時間」；引號台詞不限登錄（未登錄時標「未登錄」並提供加入的按鈕）。
- **差分寫法先比整個名字**，名稱本身帶括號的說話者不會被拆開。
- **小標本文空白時本文＝小標**；台本與手動修改的本文空白則擋下匯出（CCFOLIA 會改送聊天欄的文字）。
- **只追加**：`room` 必須是 `{}`，不可以用 `createRoom()` 的預設值（會把房間設定蓋掉）。
- `order` 以秒為單位＋序號；同一秒內連續匯出兩次，後一次的劇本文字可能和前一次交錯（原作相同）。
- 圖片庫的同內容判斷用內容雜湊；同一張圖從不同檔名加入只會有一張（名稱用第一次的）。
- 圖片刪除後可以復原（圖片內容保留到復原歷史用不到為止）。
- 舊存檔、原作專案檔裡的同一張圖（同一個 data URL 或網址）只放進圖片庫一次。
