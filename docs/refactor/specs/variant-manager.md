# 角色差分管理器（variant-manager）行為規格

## 0. 概要

整理同一角色的多張差分圖。一次載入多張圖片，替每張填上差分名（可以點建議的名稱），工具依「主名稱＋（編號）＋差分名」
即時算出每張的新檔名；可以拖曳調整順序、逐張放大檢查。最後把這些圖片以新檔名打包成一個 ZIP 檔（圖片內容原封不動），
同時產生聊天面板文字（每行一個「@差分名」，貼進 CCFOLIA 角色用來切換表情差分），可以一鍵複製。圖片不離開使用者的電腦，工具也不保留任何狀態。

靈感來源：くま。「TRPG WEBツール観測所」（<https://kumachansteps.github.io/trpg-web-tools/>）

## 2. 輸入

- 多張圖片（PNG、JPEG、WebP 為主，任何瀏覽器認得的圖片類型都收）。沒有張數或大小上限。
- 圖片只用來顯示縮圖、大圖與放進 ZIP，**不會解碼重新編碼**；類型對但內容損壞的檔案照樣列出（縮圖顯示破圖）、照樣原封放進 ZIP（實測）。新版若在縮圖上標示「無法顯示」，屬可接受差異。
- 非圖片檔略過（F03）；重複檔略過（F04）。

## 3. 輸出

### 3.1 輸出檔名

- 有差分名：`<主名稱><編號>_<差分名>.<副檔名>`；差分名清理後是空的：`<主名稱><編號>.<副檔名>`。
- 主名稱：F06 清理後的值，空的時候是 `character`。
- 編號：開啟時是清單中的位置（從 1 起算），不足兩位數補 0（01、02…99），100 以上照實際位數（100、101）；關閉時沒有編號。**編號緊接在主名稱後面，中間沒有分隔字元**。
- 副檔名：原檔名最後一個「.」之後的部分，轉成小寫；原檔名沒有「.」時一律 `png`（不論實際格式）。
- 例（主名稱 alice、編號開）：清單第 1 張 `alice_smile.png`（差分名「笑 大」）→ `alice01_笑_大.png`；第 4 張 `Alice Normal.JPG`（差分名空白）→ `alice04.jpg`；
  主名稱「 my char:01 」→ `my_char0101_…`；主名稱空白 → `character01_…`。

### 3.2 名稱清理（主名稱與差分名共用）

依序：去掉頭尾空白 → 連續的空白（含全形空白、換行等）換成一個「_」→ 刪掉 `\ / : * ? " < > |` → 連續的「_」合併成一個 → 去掉頭尾的「_」。
其他字元（中日文、emoji、「.」「-」等）保留。例：「怒り/怒?」→「怒り怒」、「a  b__c_」→「a_b_c」、只有空白 → 空。

### 3.3 主名稱自動帶入時去掉的表情詞

- 檔名（去掉副檔名後）結尾若是下列詞之一（不分大小寫），連同前面緊鄰的一個「_」或「-」一起去掉，再做 3.2 的清理：
  6 個常見的英文表情詞（例如 `smile`、`angry`）與 8 個日文羅馬拼音的常見表情詞。
- 只看結尾、不看單字邊界，所以會誤刪一般單字的字尾（實測 `chase.png` → 主名稱 `ch`，因為其中一個羅馬拼音詞很短）。
- 例：`alice_smile.png` → `alice`；`Bob-SMILE.png` → `Bob`；`Bob smile.png` → `Bob`（去掉後的尾端空白被清理掉）；`smile_alice.png` → `smile_alice`（不在結尾不去）；
  `x.tar.PNG` → `x.tar`。
- 新版的詞表見 5.。

### 3.4 ZIP

- 檔名：`<主名稱>_sabun.zip`（`sabun` 是「差分」的日文拼音；主名稱空白時是 `character_sabun.zip`）。新版是否沿用這個代號見 5.。
- 內容（平鋪、沒有資料夾），依清單順序：
  1. 每張圖片一個檔案，檔名依 3.1（重名依 F23），**內容與原檔逐位元組相同**（不重新編碼、不改尺寸）。
  2. 最後一個文字檔 `sabun-chatpalette.txt`，內容＝聊天面板文字（3.5）。
- 舊版的封裝：不壓縮（stored）；非 ASCII 檔名以 UTF-8 存（設了 UTF-8 旗標）；每個項目的時間是匯出當下的本地時間。
  新版用共用的 ZIP 模組，壓縮方式與時間戳可以不同（可接受差異）。

### 3.5 聊天面板文字

- 對清單中每一張（依清單順序）：差分名經 3.2 清理後不是空的，就產生一行「@」＋清理後的名稱；空的略過。
- 行與行之間用 LF（\n），最後一行後面**沒有**換行；UTF-8、沒有 BOM。重複的名稱照樣重複列出。
- 例：差分名依序為「怒り/怒?」「（空白）」「笑 大」「生氣」→
  第一行 `@怒り怒`、第二行 `@笑_大`、第三行 `@生氣`。
- CCFOLIA 的用法（公開功能）：在發言中寫「@差分名」可以把角色的立繪切換成該名稱的表情差分；把這段文字貼進角色聊天面板（チャットパレット），
  之後點一下就能帶入。差分名要和 CCFOLIA 角色上登錄的差分標籤一致，這部分要由使用者自己在 CCFOLIA 設定。

### 3.6 對等驗證的比對方法

1. **檔名**：準備含大小寫副檔名、沒有副檔名、檔名含多個點、含空白與禁用字元、含日文與 emoji 的一組圖片，
   在編號開／關、主名稱空白／有禁用字元、差分名各種清理情況下，比對清單上每列的輸出檔名與大圖區顯示的檔名（字串完全相同）。
2. **自動帶入**：3.3 的每個例子（依主控對詞表的裁定）。
3. **ZIP**：解開兩邊的 ZIP，比對檔案清單（名稱與順序）、每個圖片檔的位元組（必須與原檔相同）、文字檔內容（逐位元組相同）。
   壓縮方式與時間戳不比。重名情況比對 F23（若主控核准修正撞名，依核准的規則驗證）。
4. **聊天面板**：文字欄內容、複製到剪貼簿的內容、ZIP 裡的文字檔三者一致，並與舊版相同。
5. **互動**：累加、去重、選取、上下鍵、拖曳排序（往上與往下各一次）、建議按鈕、編號開關、重設確認（確定與取消）、
   四個快捷鍵與 Esc 的兩種情況，Playwright 操作兩邊比對清單狀態與狀態列的訊息類型。

## 4. 互動與手感

- 所有輸入即時反映：輸出檔名、大圖區名稱、聊天面板、按鈕啟用狀態。
- 選取一張時大圖立刻換圖；上下鍵切換時清單自動捲到選取的列。
- 拖曳排序用瀏覽器原生的拖放（拖曳中被拖的列變淡、目標列有醒目樣式）。
- 匯出後出現完成提示，約 2.2 秒後淡出。
- 鍵盤：Ctrl／⌘＋Shift＋O／E／C／N、↑／↓、Esc（見 F27～F31）。帶 Ctrl／⌘＋Shift 的快捷鍵在文字欄裡也作用。
- 不儲存任何狀態；重新整理後回到初始（清單空、主名稱空、編號開）。

## 5. 容易做壞的地方

- **ZIP 裡的圖片是原檔**：不能經過畫布重新編碼（會改變檔案大小、去掉中繼資料、可能改變色彩）。
- **編號是目前位置**：排序後編號跟著改；編號與主名稱之間沒有分隔字元（`alice01_…`）。
- **副檔名轉小寫，但檔名其他部分照原樣**；沒有副檔名時一律用 `png`。
- **聊天面板略過空名稱**，所以聊天面板的行數可能少於圖片數；最後沒有換行。
- **差分名標籤（F17）顯示原樣**，檔名與聊天面板用清理後的名稱。
- **自動帶入只在主名稱為空時**，而且取的是「清單第一張」，不是這次新加入的第一張。
- **重複檔的判斷**用檔名＋大小＋修改時間，不看內容。
- **選取中的那張被移除後**：舊版沒有單張移除，只有全部重設，所以不會發生。

以下列為**刻意差異，需主控確認**：

1. **ZIP 撞名覆蓋**（F23）：例如編號關閉時差分名為「a」「a」「a_2」，ZIP 只剩 2 張。建議新版加上數字後再檢查，直到不撞名為止（屬刻意改善）。
2. **Esc 在文字欄裡也會跳出重設確認**（F31）：建議新版在文字欄裡按 Esc 不觸發重設（只離開欄位或什麼都不做）；甚至可以考慮讓 Esc 只關面板、重設只能按按鈕。
3. **Ctrl／⌘＋Shift＋C 在 Chrome 會同時開啟開發者工具的檢查模式**（瀏覽器保留的組合鍵）：新版若改用其他組合鍵，屬可接受差異（需在快捷鍵說明寫清楚）。
4. **自動帶入的表情詞表**（3.3）：建議新版的詞表收英文常見表情詞（至少包含 smile、angry 這類常見字），日文羅馬拼音詞可保留或換成台灣玩家常用的命名；
   並且只在「詞前面是 _、- 或空白，或整個檔名就是這個詞」時才去掉，避免 `chase` → `ch` 這類誤刪（屬刻意改善）。
5. **ZIP 與文字檔的檔名代號**：舊版用 `sabun`（日文拼音）。新版可沿用（方便對照）或改成英文（例如 `variants`）；需主控決定，決定後寫進驗證條件。
6. **建議名稱與範例**：新版自選繁中詞（F19），比對時只比數量與「點了會填入選取中那張」的行為。
7. **狀態列的訊息不會過期**：例如「沒有可用的圖片」的警告會一直留到下一個訊息。新版若在之後的操作中清除過時的訊息，屬可接受差異。
8. **單張移除**：舊版沒有。新版若用共用縮圖清單而多了單張移除，屬可接受的增加（需主控確認）。

## 7. 主控裁定（審查者，2026-10-01）

- 規格審查通過；3.3 舉的 smile、angry 是一般英文表情詞，可以保留為例子。
- **ZIP 內撞名**：改成自動加序號、不覆蓋（共用的 `uniqueFileName`）——修正。
- **文字欄裡按 Esc**：不觸發重設確認——修正。
- **與瀏覽器開發者工具衝突的快捷鍵**：改用不衝突的組合，寫進快捷鍵說明（刻意差異）。
- **去掉結尾表情詞**：新版自己定詞表（繁中、英文、日文常見表情詞），而且只在詞前面有分隔符號（_、-、空白）時才去掉，不會把一般字尾誤刪——刻意改善。
- **輸出檔名的 `sabun`**：保留（CCFOLIA 社群通用的「差分」羅馬字，屬輸出結果）。
- **狀態訊息會自動消失**（共用 Toast）：核准。
- **共用縮圖清單多出單張移除**：可接受差異。

### 7.1 對等驗證後的追加裁定（2026-10-01）

- **F10 再次載入後的選取**：和舊版相同——只有「還沒有選取」或「選取的那張已經不在清單裡」時才選第一張；
  其他情況（加入新檔、全部是重複檔而加入 0 張）維持原本的選取，大圖與輸出檔名不變。規格 F10「載入後選取第一張」以此為準。
- **F30 切換編號的快捷鍵**：Ctrl＋Shift＋N 是瀏覽器保留給無痕視窗的組合，網頁收不到（舊版也無效）。
  照第 7 節「改用不衝突的組合」的精神換一組：不能是 Chrome／Edge／Firefox／Safari 保留的組合，文字欄裡也要能用；
