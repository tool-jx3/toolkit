# 匿名拼貼信產生器（collage-letter）行為規格

## 0. 概要

把一段文字做成「從雜誌剪下來拼貼」風格的匿名信圖片：每個字各自是一張歪斜的彩色紙片，字型、字級、配色、旋轉角度都隨機，
紙片邊緣是不規則的四邊形並帶投影。使用者輸入文字、調整字級範圍、圖片寬度、對齊、可用的配色與字型，按「產生」得到一張新的隨機排版；
可以下載背景透明的 PNG、紙張底的 JPG，複製圖片到剪貼簿，或複製成可貼到支援 HTML 的平台、Roll20 聊天的格式化文字。
輸入只有文字與設定；輸出是 PNG、JPG、剪貼簿圖片與兩種文字。

靈感來源：sotsotssi/collage-letter（<https://github.com/sotsotssi/collage-letter>）

說明：
- 以下「舊版」指本站收錄、已繁中化的版本（`tools/collage-letter/`），比上游多了 5 套繁中字型（預設不勾選）。
- **舊版的隨機完全沒有種子**：每按一次「產生」都是新的排版，同樣的文字不會得到同樣的圖。所以本規格的拼貼外觀以統計與範圍描述，
  對等驗證以統計比對與幾何規則為準（3.10）。
- 舊版沒有內建圖片素材。

## 2. 輸入

- 只有文字與設定，沒有檔案輸入。
- 文字：任意字元、任意長度；以換行分行。
- 數值欄（字級範圍、圖片寬度、Roll20 字級範圍）：取整數部分（45.9 → 45、12.7 → 12）；空白、0、非數字時用預設值；**沒有上下限**：
  負的字級會讓紙片的字畫不出來、尺寸錯亂；負的寬度會讓畫布變成瀏覽器的預設寬度而排版仍以負寬計算（每個字各佔一行）；
  很大的字級或寬度照用（舊版行為，見 5.）。
- 自訂字型網址：任何字串都接受，不驗證、不回報載入失敗。

## 3. 輸出

### 3.1 版面幾何（每次產生都相同的規則）

設 最小字級＝a、最大字級＝b（對調後）、寬度設定＝W。

| 項目 | 規則 |
|---|---|
| 左右、上留白 | 40 px |
| 可用行寬 | W − 80（自動寬度時不限） |
| 圖片寬 | W；自動寬度時＝最寬一行的行寬＋80（無條件進位） |
| 行距 | b × 1.3 取整數（b＝70 時 91） |
| 第 1 行中線 | 40 ＋ b ÷ 2（b＝70 時 75） |
| 第 k 行中線 | 第 1 行中線 ＋ (k − 1) × 行距 |
| 圖片高 | 第 1 行中線 ＋ 行數 × 行距（b＝70：1 行 166、2 行 257、3 行 348、4 行 439；b 非整數倍時高度可能有小數，畫布取整數部分） |
| 半形空白寬 | b × 0.4 |
| 行寬 | 該行所有紙片寬、間隔、空白寬的總和（含最後一張之後的間隔） |

量測（舊版）：
- 「一二三／（空行）／四五六七八九十」、預設 45～70、800：圖片 800 × 348，三行中線 75、166（空行）、257。
- 字級 30～30：800 × 172，中線 55、133。字級欄填 80、40（對調成 40～80）：800 × 392，第一行中線 80。
- 30 個漢字、寬 1500：兩行（15＋15），1500 × 257；同文字自動寬度：一行，約 2,625 × 166。
- 寬 200：每個字各佔一行。空白內容：用提示文字排版。

### 3.2 拼貼片外觀（統計）

實測：同一段 86 字（漢字、英文大小寫、數字）連續產生 40 次，共 3,440 張紙片。

| 量 | 分布 | 實測 |
|---|---|---|
| 旋轉角度 | −18°～＋18° 的整數，平均分布 | 最小 −18、最大 18、中位 0 |
| 字級 | a～b 的整數，平均分布 | 45～70，中位 58 |
| 紙片寬 − 字寬 | 20～30 px，平均分布（整數） | 約 20～30，中位 25 |
| 紙片高 − 字級 | 15～30 px，平均分布（整數） | 約 15～30，中位 23 |
| 每個角的內縮 | 水平 0～20% 半寬、垂直 0～20% 半高，四角獨立、連續平均分布 | 0～0.20，中位 0.10 |
| 相鄰紙片的間隔 | 2～8 px 整數，平均分布 | 2～8，中位 5 |
| 字型 | 勾選的字型平均分配 | 10 套各約 9.5%～10.7% |
| 配色 | 勾選的配色平均分配 | 8 組各約 11.7%～13.2% |

- 紙片是實色填滿的四邊形（四個角是尖角，沒有圓角），帶投影（F23）；字畫在紙片中央、隨紙片旋轉。
- **配色**：舊版 8 組「底色＋字色」，深底淺字 4 組、淺底深字 4 組；底色中無彩色（黑、白、淺灰、深灰）4 組、高彩度（紅、黃、洋紅、青）4 組。
  新版自做配色（色碼自訂），涵蓋相當即可。
- 每次產生後所有隨機量固定在這份排版裡，直到下次按產生。

### 3.4 PNG

- 尺寸＝3.1 的圖片寬 × 高，RGBA，背景完全透明；紙片投影是半透明。
- 例：兩行短文字、800 寬 → 800 × 257。

### 3.5 JPG（紙張底）

- 同尺寸，JPEG 品質約 0.95，沒有透明。
- 底色是淺米黃紙色（實測平均約 R 244、G 235、B 216），上面撒滿細小的淡黑斑點：數量約「寬 × 高 ÷ 150」個、每個 1～3 px 見方、約 4% 黑，
  位置每次下載都重新隨機。紙片與投影畫在紙張上。

### 3.6 剪貼簿圖片

與 3.4 的 PNG 相同（PNG 格式寫入剪貼簿）。

### 3.7 HTML 文字（F34）

給「可以貼 HTML 的平台」用的一段文字，結構如下（新版必須產生同等結構、同樣的數值）：

- 最外層一個區塊容器：文字對齊＝複製當下的對齊方式、行高 2.5 倍、內距 20 px、深灰底（約 #2a2a2a）、圓角 10 px。容器開頭標籤之後換行。
- 依排版順序輸出：
  - 每張紙片是**兩層行內區塊**：
    - 外層：旋轉與紙片相同的整數角度；投影濾鏡（往右 2 px、往下 3 px、模糊 2 px、50% 黑）；外距上下 2 px、左右 4 px。
    - 內層：字型＝紙片字型（後備無襯線）；字級＝紙片字級 × 0.55 取整數（px）；底色＝紙片底色；字色＝紙片字色；
      以多邊形裁切成與紙片相同的四邊形（四個角的位置以百分比表示，一位小數，與畫布上的內縮相同）；內距上下 6 px、左右 12 px；字重 900；不加文字陰影；行高 1 倍。
    - 內層裡面是那個字，**原樣放入、不跳脫**（見 5.）。
  - 每個半形空白輸出兩個不換行空白。
  - 每一行（含空行、含最後一行）結束時輸出一個換行標籤＋換行字元。
- 最後換行並關閉容器。
- 例（結構說明，不是逐字範本）：兩個字、一個空白、一個字、換行 → 容器內依序是 紙片、紙片、兩個不換行空白、紙片、換行標籤。

### 3.8 Roll20 文字（F35）

Roll20 聊天支援「連結語法裡夾帶樣式」的寫法，舊版利用它讓每個字變成一個帶底色的小方塊：

- 每張紙片輸出一段：方括號內是那個字，緊接著小括號，小括號內是「#」、一個雙引號、空白、以及一個帶樣式屬性的引號字串，
  Roll20 會把它當成帶樣式的連結顯示。字原樣放入、不跳脫。
- 樣式內容（依序）：不加底線；行內區塊；字型（基本字型開：Batang／Dotum／Gungsuh 每字隨機；關：紙片字型名稱去掉引號）＋後備無襯線；
  字級（見下）；行高 1.2；底色；字色；內距 5 px；四個角的圓角各是 2～12 px 的隨機整數（產生時決定，複製多次不變）；外距 2 px；粗體；
  深灰投影（往右 2 px、往下 3 px、模糊 5 px）。**沒有旋轉、沒有不規則裁切**（Roll20 不支援）。
- 字級＝Roll20 最小 ＋ (紙片字級 − a) ÷ (b − a) × (Roll20 最大 − Roll20 最小)，取整數部分；a＝b 時一律是 Roll20 最小。
  例：45～70 對應 16～24，字級 57 → 19、70 → 24。
- 每個半形空白輸出兩個半形空白；每一行（含最後一行）結束輸出一個換行字元。紙片之間沒有分隔。

### 3.9 檔名

`calling_card_` ＋ 下載當下的毫秒時間戳 ＋ `.png` 或 `.jpg`（例：`calling_card_1790873129562.png`）。新版可以沿用同樣的概念（固定前綴＋時間），
前綴是否改成中文需主控確認。

### 3.10 對等驗證的比對方法

1. **幾何規則（確定性）**：用不會自動換行的文字（每行很短）與各種字級範圍、寬度、對齊、空行、結尾換行、空白，比對圖片寬高、每行中線、
   行數完全相同（3.1）；自動寬度時寬度＝最寬行＋80。換行位置受隨機寬度影響，改以「每行行寬 ≤ 可用寬度，且加上下一張就會超過」驗證。
2. **統計**：同一段至少 80 字的文字新舊版各產生 40 次以上，比較 3.2 表的每一項分布（範圍相同、平均分布、中位數相差 ≤ 10%）。
   新版可以用決定性亂數，但每次按產生必須換新的種子（使用者看到的是每次不同）；建議另提供只在測試用的固定種子（例如網址參數），不出現在介面上。
3. **輸出檔**：PNG 與 JPG 的尺寸、透明度、紙張底平均色（±3）、斑點密度（±20%）；剪貼簿圖片是 PNG。
4. **文字輸出**：解析新版的 HTML 與 Roll20 文字，逐字驗證每一段的數值與排版一致（角度、字級換算、底色、字色、四角百分比、圓角範圍、空白與換行的對應），
   並與舊版同一份排版的輸出逐段比結構（屬性順序與空白可不同）。
5. **介面**：Playwright 比對開頁流程（載入中 → 自動產生）、配色／字型的新增刪除與全部未勾選、數值欄的退回與對調、自動寬度停用寬度欄、提示訊息。

## 4. 互動與手感

- 開頁約數秒內（等字型）按鈕恢復並自動產生一次。
- 改設定不會即時重畫；按「產生」才套用（對齊方式對 HTML 複製例外，取當下值）。
- 每次「產生」都換一份新的隨機排版；下載與複製都用目前這份。
- 提示訊息約 3 秒，從畫面底部以略帶回彈的動畫滑入。
- 沒有快捷鍵。不儲存任何設定（F44）。
- 預設：字級 45～70、寬 800、不自動寬度、置中、8 組配色全選、前 10 套字型勾選、Roll20 基本字型勾選、Roll20 字級 16～24。

## 5. 容易做壞的地方

- **設定不即時套用**：只有按產生才重排；但 HTML 複製的對齊取當下下拉值。保留舊行為才算對等；新版若改成改設定就重新產生，屬刻意差異，需主控確認
  （注意：每次重排都會換掉隨機結果，改成即時會讓使用者無法「先調滿意再微調」）。
- **字級範圍對調**：最小大於最大時對調使用，但欄位數字不改；Roll20 的範圍卻**不**對調。
- **行距與高度只看最大字級**：與實際抽到的字級無關。
- **行寬含最後的間隔**：置中、靠右會偏左 2～8 px。
- **逐字換行**：英文單字會被切開；造成換行的空白留在下一行開頭。
- **空白類字元**：只有半形空白不產生紙片；全形空白、Tab 會產生空白紙片。
- **中文字型**：預設勾選的字型多半沒有中文字形，中文字全退回替代字型；繁中字型預設不勾。新版若改成預設勾選繁中字型，屬刻意差異，需主控確認。
- **字型要先載入**：繁中與自訂字型只在用到時下載，舊版第一次產生可能用替代字型畫；新版畫之前要等該字型、該些字載入（共用的字型載入模組）。
- **刻意差異，需主控確認**：
  1. 表情符號與擴充漢字被拆成兩張壞掉的紙片（F45）；建議新版以字（碼位或字素）為單位。
  2. HTML 與 Roll20 文字不跳脫特殊字元：字是「<」「&」時 HTML 會壞掉；字是「]」「)」「"」時 Roll20 語法會壞掉。建議新版跳脫（HTML 用實體字元，Roll20 改用全形或略過）。
  3. 數值欄沒有上下限：負字級、負寬度、超大寬度照用（2.）。建議新版限制範圍（例如字級 8～200、寬度 100～4000）。
  4. 提示訊息的計時互相干擾（後一則被前一則的計時提早收掉，實測約 1 秒）；建議每則都完整顯示約 3 秒。
  5. 自訂字型網址不回報載入失敗；建議新版用共用的字型模組（Google 字型目錄、電腦字型、上傳字型）取代「貼網址」，或至少回報失敗。
  6. 4 套非 Google Fonts 的韓文字型（3.3）：本站規定字型只能從 Google Fonts 載入，新版無法照舊從 jsDelivr 載入；需主控決定改用風格相近的 Google 字型替代，或確認授權後隨站打包。
- **自訂配色刪除不詢問**（舊版行為）；新版可以加復原提示。
- **Roll20 基本字型每次複製都重新隨機**，同一份排版複製兩次字型不同；其他值不變。
- **JPG 斑點每次下載都不同**。
- **HTML 的投影與 Roll20 的投影數值不同於畫布**（畫布 3,4／模糊 6／40%；HTML 2,3／模糊 2／50%；Roll20 2,3／模糊 5／深灰），照各自的規則輸出。
