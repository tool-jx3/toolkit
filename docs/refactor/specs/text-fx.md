# 文字演出產生器（text-fx）功能清單與對等驗證

## 0. 概要

把一段文字做成有登場、停留、退場動畫的透明背景素材（APNG、單張 PNG、連番 PNG），給線上跑團（CCFOLIA 等）、
直播與影片疊加使用。三種模式：**標語**（畫面中央的大字，例如「戰鬥開始」「大成功」）、**長文**（開場白、預告、
旁白、信件、片尾名單，可分頁）、**字幕**（地點、時間）。輸入是文字與設定，輸出是動畫檔或圖片。

本工具的程式由 TRPG Toolkit 以無塵室方式撰寫（MIT；靈感來源見下），這次是**直接移植**舊版（`tools/text-fx/`）到新框架，不走無塵室，
所以本文件可以寫出具體的數值、公式與範本內容。程式是本站以無塵室方式獨立撰寫的（見 ATTRIBUTION）；2026-10-06 起頁尾列出靈感來源：[くま。／文字画像APNGメーカー](https://kumachansteps.github.io/trpg-web-tools/tools/text-apng-maker/)（那個工具的利用規約禁止複製工具本體，所以不讀原作程式移植）。

新版位置：`web/src/tools/text-fx/`（建置到 `next/text-fx/`）。共用排版模組：`web/src/core/typeset/`。

## 1. 功能清單（對等驗證以此為準）

驗證方式：**影格**＝對等腳本在相同設定、相同時間點從舊版與新版各畫一格算像素差（`web/tests/parity/text-fx/`）；
**檔案**＝兩邊各匯出後解碼比對；**互動**＝Playwright 操作；**單元**＝Vitest；**目視**＝並排截圖。

## 2. 輸入

- 文字：任意 Unicode（中、日、韓、英、emoji）。換行保留；長文的空白行是換頁。主文字、副文字前後的空白行忽略。
- 字型檔：TTF、OTF、WOFF、WOFF2（新版另接受 TTC）；瀏覽器讀不懂時顯示錯誤，不加入清單。
- 數值：滑桿與數字欄都夾在 1. 寫的範圍內。

## 3. 輸出

### 3.1 APNG（副檔名 .png）

- 影格數 N＝⌈總長×fps⌉（至少 1）；第 i 格取 i÷fps 的畫面，最後一格固定取在總長的最後一刻（停在完成或全透明狀態）。
- 連續相同的畫面合併成一格並延長顯示時間（延遲＝格數／fps）；每一格只存跟前一格不同的矩形（dispose NONE、blend SOURCE）。
- 256 色：所有影格（加上完成狀態，份量為 0.35×N、至少 4）實際用到的顏色 ≤ 256 時無損；否則在預乘 alpha 空間中位切割＋k-means，
  不透明與半透明分開，不抖色；減色後才變得相同的格也合併。全彩：RGBA。
- 預設圖開：完成狀態（代表畫面）當作不屬於動畫的 IDAT；關：第一格就是 IDAT。
- 播放次數：播放一次＝1、無限＝0、指定次數＝n。
- 自動裁邊：見 F250。
- 檔名：「<名稱>.png」。

### 3.2 單張 PNG

- 時間點見 F254；自動裁邊時只看這一格。檔名「<名稱>_靜止.png」。

### 3.3 連番 PNG（ZIP）

- 「<名稱>_連番.zip」，內含「<名稱>_0001.png」…（4 位數，從 1 起）與「<名稱>_資訊.txt」。
- 資訊檔（CRLF）：`文字演出產生器　連番 PNG`、`FPS：<fps>`、`張數：<N>`、`尺寸：<寬>×<高>`、`長度：<總長，兩位小數> 秒`、
  `檔名：<第一張> ～ <最後一張>`。
- 自動裁邊時所有影格用同一個範圍。

### 3.4 時間軸（每一頁）

```
t0 ─ 裝飾開場 ─┐
               ├ 文字開始（包住文字的裝飾：t0＋min(0.6×裝飾動畫時間, 0.3)）
               ├ 登場結束（≥ t0＋裝飾動畫時間）＝代表畫面
               ├ 停留結束＝登場結束＋停留時間
               ├ 文字退場結束；裝飾在「停留結束＋0.35×文字退場長度」開始收
               └ 頁結束 ─（長文：頁與頁之間）─ 下一頁
總長＝最後一頁結束＋結束後空白（至少 0.05 秒）；開始前空白在第一頁之前。
```

### 3.5 範本檔（P11 新增，F301）

- JSON（UTF-8、2 格縮排）：`{ "format": "trpg-toolkit:text-fx-templates", "version": 1, "exportedAt": "<ISO 時間>", "templates": [{ "name", "mode": "title" | "long" | "caption", "settings": { …完整設定… } }] }`。
- 檔名：一個時「文字演出範本_<名稱>.json」，多個時「文字演出範本_<N>個.json」（不合法字元移除）。
- 讀入：`format` 不同時不收；沒有 `format` 時也收 `templates` 陣列或單一個 `{ name, mode, settings }`；模式不對、沒有設定的範本略過（計數），
  設定依 F290 修正；名稱去頭尾空白、最多 40 字、空白時「未命名範本」。
- 瀏覽器存檔：localStorage `trpg-toolkit:text-fx:mine`（`{ items: [{ id, name, mode, s, savedAt }] }`），讀回時同樣修正（模式不對的丟掉、識別碼重複換新的）。

### 3.6 一次匯出多個的檔名（P11 新增，F304）

- 每個檔案：沒有填檔名時「<序號>_<自動檔名>」（序號 01、02…，超過 99 個時 3 位數；自動檔名見 F252，各自依那一個的文字與效果），
  填了檔名時「<檔名>_<序號>」；副檔名與「_靜止」照 3.1、3.2。
- 打包成 ZIP：「<檔名>_批次.zip」；沒有填檔名時，每一行（每一頁）「<目前的自動檔名>_批次.zip」，勾選的範本「文字演出_範本批次.zip」。ZIP 內是各個檔案（不壓縮）。

### 4.2 決定性

- 所有隨機感（四散方向、閃爍、雜訊、顫抖、隨機順序）都由字序、時間桶（每秒固定次數）與效果名稱雜湊而來；
  同一組設定在同一時間點畫出相同的畫面，與 fps 無關。
- 效果的種子＝效果 id 的 FNV-1a 雜湊；逐字順序的種子＝種子＋字數（退場再＋7）。

### 4.3 快捷鍵

見 F282～F288。新版另有 Ctrl＋Z／Ctrl＋Shift＋Z（復原／重做）。

## 5. 容易做壞的地方

- **畫布狀態**：每格開始要重設 transform、alpha、合成模式與 filter；模糊用 sprite 原尺寸模糊再放大（大字放大時快十倍以上）。
- **sprite 分層**：光暈、本體（陰影＋外側外框＋外框＋塗色）、閃白三張分開；淡入淡出時整張本體一起變透明，所以半透明的字不會透出外框。
- **縱向漸層的範圍**：以「那一行」的墨跡上下為範圍，不是單一字；直書與旋轉的字以字身為範圍。
- **整塊效果與副文字**：副文字「跟主文字相同」時共用同一個整塊狀態（同一個中心）。
- **雜訊、震動以秒為單位取樣**：60 fps 匯出時同一個雜訊畫面連續 3 格，不會每格亂跳。
- **自動縮小要算進外框、光暈、陰影與裝飾**，而且只排一次版（縮小後沿用原本的斷行）。
- **暫停時改設定**：畫面變空要跳到完成狀態，不然使用者以為設定沒作用。
- **範本切換保留尺寸與退場開關**。
- **字型**：先用替代字型畫，載入完再重畫；匯出前一定等字型（最多 12 秒）。
- **新版的縮放匯出**：要用「等比放大的設定」重新排版，不能把 1× 的畫面點陣放大。
- **登場關閉（P11）**：要在排好登場時間表之後再改成「開始時就出現」（停留效果用到的名次照原本排的）；裝飾、整張背景也要從頭就完整，否則第一格會是半透明的背景。
- **我的範本與文字記憶（P11）**：套用中的是我的範本時，改文字不要記到內建範本（否則切回那個內建範本時文字被換掉）。
- **一次匯出多個的通知與錯誤（P11）**：讀入多個範本檔的結果合成一則通知，成功的通知不能蓋掉失敗；批次匯出有一個失敗就停下來並標出是第幾個。

  兩邊都把 Google Fonts 換成空樣式，用同一套本機替代字型，**排除字型載入的差異**；字型本身的選擇（含西文接中文、韓文接韓文字型的順序、字重）
  另外以畫布字型字串比對（見「資料」）。
- **影格**：每個案例用舊版的 `library.js` 組出設定（舊格式），原樣交給兩邊建場景（新版先經 `normalizeSettings` 轉成新格式），
  在 0、25%、50%、75%、100% 與每個階段的起點、起點後一格、中點、終點前一格各畫一格。先比整格的雜湊，不同時才解碼比像素
  （預乘 alpha，單一通道差 > 2 才算不同；差異圖存 `out/frames/`，不提交）。場景的尺寸、字級、總長、代表畫面時間、各階段起訖也要相同。
  案例涵蓋：25 種登場、18 種退場、9 種停留、7 種長文流程、16 種逐字方式、44 個範本、11 個文字風格、8 組漸層、
  9 種裝飾（橫書、直書各一）、4 種整張背景、直書、對齊、九宮格位置、換行、自動縮小、字型、尺寸等。
- **匯出檔**：同一份設定兩邊各匯出一次。APNG 比對尺寸、色彩型態、影格數、每格延遲、播放次數、預設圖，並把合併後的影格依延遲展開成
  每 1/fps 一格逐格比像素；PNG 比像素；ZIP 比檔名、資訊檔全文與每張 PNG。
- **資料**：範本、文字風格、漸層配色、效果預設值，用舊版的 `library.js`／`motion.js` 產生後與新版逐欄比對；
  畫布的 font 字串用舊版的 `fonts.js` 產生後與新版逐字比對。
- **互動**：兩邊的測試掛鉤 `window.__textFx` 做同樣的操作（切模式、套範本、改文字後切走再切回、重設），比對結果的設定。
- **效能**：長動畫與大畫面的匯出時間，兩邊輪流跑（不搶 CPU）各 3 次取最短；新版不得超過舊版的 1.5 倍。

依派工的行為描述跟進靈感來源（くま。／文字画像APNGメーカー）的更新；text-fx 是無塵室開發的工具，這次同樣**沒有讀原作的程式碼或檔案**，只依描述與 text-fx 現有的程式做。
