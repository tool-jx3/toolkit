# CoC 7 版調查員角色卡（coc-sheet）行為規格

## 0. 概要

在瀏覽器填好克蘇魯的呼喚（CoC）7 版的調查員角色卡，直接以 A4 兩頁列印或存成 PDF。
由舊版 trpg-lab 的「CoC 7 版自訂調查員角色卡」（`tools/trpg-lab/coc7_Investigator_sheet.{html,css,js}`，介面文字的繁中翻譯在
`i18n.coc7_Investigator_sheet.js`，共用的 `common.js` 提供頁首、深淺色與說明對話框；以下稱【舊版】）改寫。

舊版是一張可以直接點字改寫（contenteditable）的 A4 角色卡，存檔是把整張卡的 HTML 原樣存進 localStorage。
新版改成**結構化的資料**＋一般的表單元件，紙面由資料排出來（預覽、列印、PNG 同一份版面），並加上多張角色卡、自動計算、
技能點數、復原／重做、專案檔、匯出 PNG、CCFOLIA 角色資料。

輸入：表單的各欄位、頭像圖片、舊版的瀏覽器存檔、專案檔。輸出：A4 兩頁的角色卡（列印／存成 PDF）、PNG、CCFOLIA 角色剪貼簿 JSON；
角色卡存在瀏覽器（自動保存），另有專案檔（ZIP）。規則（困難／極限、移動力、DB／體格、理智上限、技能點數）在共用模組 `@/core/coc`（DESIGN.md 4.2）。

靈感來源：ihoukentiku/ihoukentiku.github.io（<https://github.com/ihoukentiku/ihoukentiku.github.io>），授權 MIT（Copyright (c) 2025 ihoukentiku），
授權全文在 `web/src/tools/coc-sheet/UPSTREAM_LICENSE`。舊版的技能表、預設值與介面用詞（繁中翻譯）沿用；版面與樣式本站重新設計（規則 2）。

用語：「目前的角色卡」＝清單裡選中、正在編輯的那一張；「紙面」＝排好的 A4 兩頁；「一般／困難／極限」＝技能值與它的 ½、⅕；
「自動」＝欄位空白時依規則算出的值，「手動」＝欄位有填（取代自動的值）。

## 1. 功能清單（對等驗證以此為準）

驗證方式：「自動」＝e2e（`web/tests/e2e/coc-sheet.spec.ts`）／單元測試（`web/tests/unit/coc-sheet-logic.test.ts`、`coc-sheet-legacy.test.ts`、
`tests/components/optional-number-input.test.tsx`）；「資料比對」＝舊版頁面實際填寫存檔的 localStorage（`web/tests/unit/fixtures/coc-sheet-legacy.json`）
搬到新版後逐欄比對；「目視」＝截圖並排（新版紙面與舊版頁面）。

  不同時另外加一張「自動儲存的角色卡」放在最前面、設為目前的角色卡；什麼都沒填的角色卡不搬。都沒有可以搬的時候不顯示說明，開一張新角色卡。
- **欄位的位置**：基本資料是「調查員角色卡」框裡依序 7 個值；屬性依標籤（STR…EDU）；移動力、HP 最大值、理智初始／最大值、MP 最大值、傷害加值、體格、
  戰鬥欄的閃避依各自的框；技能依技能表的格子順序；武器依 7 列；背景故事依標籤上的語言掛勾（沒有時依位置）；裝備是左欄再右欄；資產的三個標籤欄與其餘 7 行；
  備註 26 格；頭像是頭像框裡的圖片。
- **數字**：舊版的讀法（去頭尾空白後開頭的整數，可有正負號，負數當 0），全形數字先轉半形；空白＝null；開頭不是數字（例「abc」）＝null 並列入略過；
  後面還有別的字（例「60/30」）取開頭的數字並列入略過（「只取 60」）。
- **技能**：標籤有舊版語言引擎的掛勾（`data-i18n`／`data-i18n-html`＝`sheet.skill.<鍵>`）時，依鍵換成新版的預設名稱與初始值（不論存檔時是繁中或日文）；
  沒有掛勾（使用者改過，或舊的存檔）時讀文字：和舊版字典（繁中、日文）的標籤完全相同時同上；否則拆成「名稱（初始值）」——最後一組括號是 `數字%`、`DEX×½`、`EDU%`
  時當初始值，其餘當名稱的一部分；名稱和預設技能（繁中、日文）相同時記下鍵（閃避、克蘇魯神話的規則要用）。有專長的列的第二個標籤是專長；
  空白列（`add-special-skill`、`free-skill`）的文字也照「名稱（初始值）」拆。一般框的值是**手動的技能值**（空白＝自動）。舊版只顯示前 60 格：60 格以後只留到最後一個有內容的列。
- **武器**：名稱有「徒手」的掛勾（或第一列寫「徒手」「素手」）時是「徒手」；其他欄位照原文；全部空白的列不搬；「徒手」沒有填技能值時使用「格鬥（鬥毆）」（同新角色卡）。
- **戰鬥欄的閃避**：技能「閃避」沒有值時當成閃避的技能值；兩個都有而且不同時列入略過（新版的戰鬥欄跟著技能）。
- **多行的欄位**（背景故事、裝備、資產的其他 7 行、備註、自訂欄）：每一格一行，以換行連接，去掉結尾的空行（中間的空行保留，例：裝備左欄 2 項、右欄 1 項 → 第 1、2、11 行）。
- **自訂欄的標題**：有掛勾或是「自訂」「カスタム」時是「自訂」，否則照原文。
- **基本資料的欄位名稱**：沒有掛勾、而且不是舊版字典的名稱時列入略過。
- **頭像**：data URL 的 PNG（舊版 Fabric 裁好的 520×640，高解析度螢幕上可能更大，依檔頭讀寬高）放進新版的資產庫（id 依內容算），裁切範圍＝整張；讀不出來時列入略過。
- 實際的舊版存檔（夾具）搬過來的結果見單元測試 `coc-sheet-legacy.test.ts`。

### 3.5 列印

看不見的列印文件（共用的 `printPages`）：兩頁，每頁一張 A4（`@page` 210 mm × 297 mm、邊界 0），背景色照印（`print-color-adjust: exact`），
文件標題＝姓名 → 角色卡名稱 →「調查員角色卡」。列印文件留在頁面上直到下一次列印。

### 3.6 PNG

- 每頁的排版尺寸 794 × 1123 px（A4 在 96 dpi）；解析度倍率 1／2／3 → 794×1123、1588×2246、2382×3369。
- 兩頁接成一張：上下排，中間 16 px × 倍率的白色間隔（倍率 2：1588 × 4524）。白底、不透明。
- 檔名：「<姓名>_角色卡_第1頁.png」「<姓名>_角色卡_第2頁.png」「<姓名>_角色卡.png」（兩頁）；姓名空白時用角色卡名稱、再空白時「調查員角色卡」；`\ / : * ? " < > |` 換成「_」。
- 字型：只用電腦上的字型（與畫面上的預覽相同的字型堆疊：Noto Sans TC、PingFang TC、微軟正黑體…）。

### 3.7 CCFOLIA 角色剪貼簿 JSON

`{ "kind": "character", "data": { … } }`，2 格縮排、LF、結尾沒有換行、中文不跳脫（共用的 `serializeCharacterClipboard`）；`data` 的欄位依序：

| 欄位 | 內容 |
|---|---|
| `name` | 姓名；空白時角色卡名稱；再空白時「無名氏」 |
| `initiative` | DEX（空白時 0） |
| `externalUrl` | 空字串 |
| `status` | `HP`（value＝目前值，空白時上限；max＝HP 上限）、`MP`（同）、`SAN`（value＝目前值，空白時初始理智；max＝理智上限）、`幸運`（value＝目前的幸運，空白時幸運；max＝幸運）；空白當 0 |
| `params` | STR、CON、POW、DEX、APP、SIZ、INT、EDU（`@/core/coc` 的順序，值是字串，空白是 ""），接 `DB`（空白時 "0"）、`體格`、`MOV` |
| `commands` | 聊天面板（下面） |
| `memo` | 「職業：…」「年齡：…」「性別：…」「玩家：…」（有填的才寫，一行一項） |

聊天面板（每行一個，LF 連接）：`CC<={SAN} 理智檢定`、`CC<={幸運} 幸運`；INT、EDU 有值時 `CC<=<INT> 靈感`、`CC<=<EDU> 知識`；
有值的屬性 `CC<=<值> STR`…（STR、CON、POW、DEX、APP、SIZ、INT、EDU）；名稱不是空的、技能值不是空白的技能 `CC<=<技能值> <名稱>`（有專長時「科學（化學）」）；
每把武器：名稱不是空的而且技能值不是空白時 `CC<=<技能值> <名稱>`，傷害欄有數字時 `<傷害> <名稱>（傷害）`（傷害拿掉空白、獨立的 DB 換成 `{DB}`）；
`//DB=<DB>`、體格有值時 `//體格=<體格>`、移動力有值時 `//MOV=<移動力>`、有值的屬性 `//STR=<值>`…。

### 3.8 紙面

- A4（210 mm × 297 mm），內距上下 8 mm、左右 9 mm，區塊間隔 2.2 mm；字型只用電腦上的字型（3.6）；底色白、深藍灰的標題帶。
- 第 1 頁由上而下：上排（基本資料｜屬性 3×3｜頭像框 13：16）高約 45 mm；狀態（自訂欄 8 行｜生命值、理智／幸運、魔法值）高約 48 mm；技能 4 欄 × 15 列，高 110 mm；
  下排（武器 7 列｜戰鬥：傷害加值、體格、閃避）佔其餘高度。
- 第 2 頁：背景故事（兩欄，行距 5.9 mm）、裝備與隨身物品（兩欄各 10 行）｜現金與資產（3＋7 行）、備註（兩欄各 10 行）。
- 會截掉文字的欄位：一行的欄位（基本資料、武器的每一格、裝備與資產的每一行、傷害加值）量寬；多行的欄位（背景故事、自訂欄、備註）量高（備註兩欄量寬與高）。

## 4. 互動與手感

- 所有修改即時反映在預覽、自動保存（沒有延遲）。打字時停頓超過 0.4 秒才算新的一步復原。
- 數字欄：↑／↓ 加減 1（Shift ×10）、PageUp／PageDown ×10；空白時按 ↑／↓ 從自動的值（沒有時從範圍下限）開始；Enter 確定、Esc 還原打到一半的字。
- 技能表：列有焦點時 ↑／↓ 移動、Alt＋↑／↓ 調整順序；名稱欄 Enter 插入一列、空白列 Backspace 刪除（F37、F38）。
- 快捷鍵：Ctrl／⌘＋Z 復原、Ctrl／⌘＋Shift＋Z 或 Ctrl＋Y 重做、Ctrl／⌘＋P 列印（輸入框裡也有效）、? 說明。
- 預覽：預設「配合寬度」（最大 150％）；縮放、分頁、PNG 的選項、清單收合（窄畫面）記在瀏覽器（清單收合不記，依畫面寬度）。
- 通知（複製、匯出 PNG、錯誤）約 2～5 秒。

## 5. 容易做壞的地方

- **舊存檔是 HTML**：一定要用 DOMParser 解析（不能 innerHTML 進頁面——存檔裡的 HTML 是使用者的頁面內容）；圖片不能讓瀏覽器載入（DOMParser 的文件不會載）。
  日文介面存的檔案標籤是日文、帶掛勾；改過的標籤沒有掛勾；舊版較早的存檔可能完全沒有掛勾（單元測試用拿掉掛勾的夾具驗證）。
- **搬移要立刻寫進新版的存檔**（目前的角色卡也是）：否則下次開頁又重新搬一次、id 換掉、目前的角色卡跳回第一張（coc-npc 7.1 F30 的教訓）。
- **自動儲存和存檔的比較**要比內容（搬來之後的資料），不能比 HTML 字串：舊版讀取存檔後重新套用語言與字級，自動儲存的 HTML 和存檔不會逐字相同。
- **技能表固定 60 格**：空白列也是資料（紙面上的位置）；插入、刪除會讓後面的格子移動，和舊版相同。
- **困難／極限在值是 0 時留白**、1 時是 0／0（舊版的規則）。
- **自動的技能值包含初始值**：新角色卡的預設技能紙面上就印初始值（舊版是空白，5. D4）。
- **閃避、母語的初始值依屬性算**；DEX、EDU 空白時空白（不是 0）。
- **理智上限跟著克蘇魯神話**：克蘇魯神話的技能值（含手動）改了，自動的理智上限跟著改。
- **列印與 PNG 用預覽排好的頁面**：預覽沒有排好（例如頭像還在讀）時列印的是當下的樣子；PNG 的頭像先換成 data URL 才畫得出來。
- **PNG 只用得到電腦上的字型**（SVG 當圖片時不讀網頁字型）：紙面的 CSS 不能依賴網頁字型（Google Fonts），否則預覽與 PNG 不一致。
- **Ctrl＋P 要攔下來**改印角色卡（不然會印出整個工具頁面）。
- **頭像的資產 id 要和 core/assets 相同**（SHA-256 前 24 位）：搬來的頭像之後再上傳同一張圖時不會存兩份。
- 舊版已知的問題（新版不照做）：新插入的技能列要重新整理才會算困難／極限；說明對話框之外的語言切換會讓沒改過的標籤跟著換（存檔裡留著掛勾）。
