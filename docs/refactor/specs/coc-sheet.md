# CoC 7 版調查員角色卡（coc-sheet）行為規格

## 0. 概要

在瀏覽器填好克蘇魯的呼喚（CoC）7 版的調查員角色卡，直接以 A4 兩頁列印或存成 PDF。
由舊版 trpg-lab 的「CoC 7 版自訂調查員角色卡」（`tools/trpg-lab/coc7_Investigator_sheet.{html,css,js}`，介面文字的繁中翻譯在
`i18n.coc7_Investigator_sheet.js`，共用的 `common.js` 提供頁首、深淺色與說明對話框；以下稱【舊版】）改寫。

舊版是一張可以直接點字改寫（contenteditable）的 A4 角色卡，存檔是把整張卡的 HTML 原樣存進 localStorage。
新版改成**結構化的資料**＋一般的表單元件，紙面由資料排出來（預覽、列印、PNG 同一份版面），並加上多張角色卡、自動計算、
技能點數、復原／重做、專案檔、匯出 PNG、CCFOLIA 角色資料。

輸入：表單的各欄位、頭像圖片、舊版的瀏覽器存檔、專案檔。輸出：A4 兩頁的角色卡（列印／存成 PDF）、PNG、CCFOLIA 角色剪貼簿 JSON；
角色卡存在瀏覽器（自動儲存），另有專案檔（ZIP）。規則（困難／極限、移動力、DB／體格、理智上限、技能點數）在共用模組 `@/core/coc`（DESIGN.md 4.2）。

靈感來源：ihoukentiku/ihoukentiku.github.io（<https://github.com/ihoukentiku/ihoukentiku.github.io>），授權 MIT（Copyright (c) 2025 ihoukentiku），
授權全文在 `web/src/tools/coc-sheet/UPSTREAM_LICENSE`。舊版的技能表、預設值與介面用詞（繁中翻譯）沿用；版面與樣式本站重新設計（規則 2）。

用語：「目前的角色卡」＝清單裡選中、正在編輯的那一張；「紙面」＝排好的 A4 兩頁；「一般／困難／極限」＝技能值與它的 ½、⅕；
「自動」＝欄位空白時依規則算出的值，「手動」＝欄位有填（取代自動的值）。

## 1. 功能清單（對等驗證以此為準）

驗證方式：「自動」＝e2e（`web/tests/e2e/coc-sheet.spec.ts`）／單元測試（`web/tests/unit/coc-sheet-logic.test.ts`、`coc-sheet-legacy.test.ts`、
`tests/components/optional-number-input.test.tsx`）；「資料比對」＝舊版頁面實際填寫存檔的 localStorage（`web/tests/unit/fixtures/coc-sheet-legacy.json`）
搬到新版後逐欄比對；「目視」＝截圖並排（新版紙面與舊版頁面）。

### 3.7 CCFOLIA 角色剪貼簿 JSON

| 欄位 | 內容 |
|---|---|
| `name` | 姓名；空白時角色卡名稱；再空白時「無名氏」 |
| `initiative` | DEX（空白時 0） |
| `externalUrl` | 空字串 |
| `status` | `HP`（value＝目前值，空白時上限；max＝HP 上限）、`MP`（同）、`SAN`（value＝目前值，空白時初始理智；max＝理智上限）、`幸運`（value＝目前的幸運，空白時幸運；max＝幸運）；空白當 0 |

`//DB=<DB>`、體格有值時 `//體格=<體格>`、移動力有值時 `//MOV=<移動力>`、有值的屬性 `//STR=<值>`…。

## 4. 互動與手感

- 所有修改即時反映在預覽、自動儲存（沒有延遲）。打字時停頓超過 0.4 秒才算新的一步復原。
- 數字欄：↑／↓ 加減 1（Shift ×10）、PageUp／PageDown ×10；空白時按 ↑／↓ 從自動的值（沒有時從範圍下限）開始；Enter 確定、Esc 還原打到一半的字。
- 技能表：列有焦點時 ↑／↓ 移動、Alt＋↑／↓ 調整順序；名稱欄 Enter 插入一列、空白列 Backspace 刪除（F37、F38）。
- 快捷鍵：Ctrl／⌘＋Z 復原、Ctrl／⌘＋Shift＋Z 或 Ctrl＋Y 重做、Ctrl／⌘＋P 列印（輸入框裡也有效）、? 說明。
- 預覽：預設「配合寬度」（最大 150％）；縮放、分頁、PNG 的選項、清單收合（窄畫面）記在瀏覽器（清單收合不記，依畫面寬度）。
- 通知（複製、匯出 PNG、錯誤）約 2～5 秒。

## 5. 容易做壞的地方

- **舊存檔是 HTML**：一定要用 DOMParser 解析（不能 innerHTML 進頁面——存檔裡的 HTML 是使用者的頁面內容）；圖片不能讓瀏覽器載入（DOMParser 的文件不會載）。
  日文介面存的檔案標籤是日文、帶掛勾；改過的標籤沒有掛勾；舊版較早的存檔可能完全沒有掛勾（單元測試用拿掉掛勾的夾具驗證）。
- **搬移要立刻寫進新版的存檔**（目前的角色卡也是）：否則下次開頁又重新搬一次、id 換掉、目前的角色卡跳回第一張（coc-npc 7.1 F30 的教訓）。
- **自動儲存和存檔的比較**要比內容（搬來之後的資料），不能比 HTML 字串：舊版讀取存檔後重新套用語言與字級，自動儲存的 HTML 和存檔不會逐字相同。
- **技能表固定 60 格**：空白列也是資料（紙面上的位置）；插入、刪除會讓後面的格子移動，和舊版相同。
- **困難／極限在值是 0 時留白**、1 時是 0／0（舊版的規則）。
- **自動的技能值包含初始值**：新角色卡的預設技能紙面上就印初始值（舊版是空白，5. D4）。
- **閃避、母語的初始值依屬性算**；DEX、EDU 空白時空白（不是 0）。
- **理智上限跟著克蘇魯神話**：克蘇魯神話的技能值（含手動）改了，自動的理智上限跟著改。
- **列印與 PNG 用預覽排好的頁面**：預覽沒有排好（例如頭像還在讀）時列印的是當下的樣子；PNG 的頭像先換成 data URL 才畫得出來。
- **PNG 只用得到電腦上的字型**（SVG 當圖片時不讀網頁字型）：紙面的 CSS 不能依賴網頁字型（Google Fonts），否則預覽與 PNG 不一致。
- **Ctrl＋P 要攔下來**改印角色卡（不然會印出整個工具頁面）。
- **頭像的資產 id 要和 core/assets 相同**（SHA-256 前 24 位）：搬來的頭像之後再上傳同一張圖時不會存兩份。
- 舊版已知的問題（新版不照做）：新插入的技能列要重新整理才會算困難／極限；說明對話框之外的語言切換會讓沒改過的標籤跟著換（存檔裡留著掛勾）。
