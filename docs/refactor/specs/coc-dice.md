# CoC 擲骰工具（coc-dice）行為規格

## 0. 概要

克蘇魯的呼喚（CoC）7 版跑團用的擲骰工具。由舊版 trpg-lab 的兩頁合併：

- **「CoC 7 版擲骰工具」**（`tools/trpg-lab/coc7_dice.*`，以下稱【擲骰】）：技能檢定（獎勵骰／懲罰骰、自動判定成功等級）、
  自訂算式擲骰（快速加骰鈕）、擲骰紀錄。
- **「BCDice 傷害自動計算工具」**（`tools/trpg-lab/damage_sum.*`，以下稱【傷害】）：貼上 CCFOLIA 聊天欄裡 BCDice 的傷害擲骰結果，
  每筆扣掉護甲後加總，產生改 HP 的 `:HP-總和` 指令。
- 共用的 `common.js`（以下稱【共用】）：深淺色、說明對話框（加減鈕長按連續增減只用在網格工具，這兩頁沒有）。

新版是一個工具、兩個分頁：「擲骰」（技能檢定＋自訂擲骰，共用一個結果區與一份擲骰紀錄）、「傷害計算」。
規則（骰子算式、成功等級、BCDice 結果解析）放在共用模組 `@/core/coc`（DESIGN.md 4.2），coc-npc、coc-sheet 也用。

輸入：技能值、獎勵骰／懲罰骰數、骰子算式、護甲、貼上的擲骰結果。輸出：畫面上的擲骰結果與成功等級、擲骰紀錄（存在瀏覽器）、
`:HP-總和` 指令（剪貼簿）；新版另有專案檔。

靈感來源：ihoukentiku/ihoukentiku.github.io（<https://github.com/ihoukentiku/ihoukentiku.github.io>），授權 MIT（Copyright (c) 2025 ihoukentiku），
授權全文在 `web/src/tools/coc-dice/UPSTREAM_LICENSE`。舊版的擲骰音效 `dice_sound.wav`（ニコニ・コモンズ素材，不得再散布）不收。

用語：「十位骰」＝00、10…90 的那顆 D10；「個位骰」＝0～9 的那顆；「BD/PD」＝獎勵骰（Bonus Die，正數）／懲罰骰（Penalty Die，負數）的數量。

## 2. 輸入

### 2.1 技能值、BD/PD

- 技能值：原生數字欄的值，以整數解讀（`55.9` → 55）；空白、讀不出數字或 0 時不判定成功等級。按鈕只在 0～999 之間增減；打字可以超過。
- BD/PD：−2～+2 的整數。

### 2.2 骰子算式

正規化（F12）之後，整段必須是「項（+ 或 - 項）…」，開頭可以有正負號；項＝「骰子數 D 面數」（骰子數可以省略、可以有前導 0）或整數。
錯誤的種類與訊息：

| 種類 | 例 | 訊息 |
|---|---|---|
| 看不懂 | `abc`、`1D6abc`、`1.5`、`(2D6+6)`、`3D6×5`、`1D6++2`、`5-`、`D` | 看不懂這個算式。寫法例：2D6+1D4+3（「骰子數 D 面數」或整數，用 + 或 - 連接） |
| 骰子數或面數是 0 | `0D6`、`1D0` | 骰子數與面數都要 1 以上。 |
| 骰子太多 | `1000D6`、`500D6+500D6` | 一次最多擲 999 顆骰子。 |
| 面數或常數太大 | `1D10000`、`1000000` | 面數最多 9999、常數最多 999999。 |
| 空白 | （空白） | （不顯示訊息，不做事） |

### 2.3 傷害計算

- 護甲：原生數字欄的值，以 parseInt 的規則解讀（`1.9` → 1、`-2` → −2、空白或無效 → 錯誤）。
- 擲骰結果：任意文字（通常是從 CCFOLIA 聊天欄複製的一段），換行可以是 LF 或 CRLF。

### 2.4 專案檔

本站的專案檔（3.5）；不是這個工具的資料時顯示「專案檔的內容無法使用。」，目前的內容不變。

## 3. 輸出

### 3.1 技能檢定

- 擲骰：先擲個位骰（0～9），再依序擲 1＋|BD/PD| 顆十位骰（0、10…90）。每顆十位骰＋個位骰＝候選值，十位 0＋個位 0 ＝100。
- BD/PD＞0：結果＝最小的候選值；＜0：最大的；＝0：唯一的候選值。採用的十位骰＝候選值等於結果的**第一顆**。
- 成功等級見 F04。

### 3.2 快速加骰（F17）

先把目前的算式正規化並拆成帶正負號的項。最後一項是「（正負號）骰子數 D 面數」、按鈕也是骰子、而且面數**文字相同**時：
最後一項是減號開頭 → 改成「最後一項＋按鈕」；否則 → 「（正負號）（兩者骰子數相加）D 面數」。
否則最後一項是整數、按鈕也是整數時：減號開頭 → 「最後一項＋按鈕」；否則相加。都不是時：算式不是空的 → 「算式＋按鈕」；空的 → 按鈕。
結果開頭的「+」拿掉。例：空白 →（+1D6）`1D6` →（+1D6）`2D6` →（+1）`2D6+1` →（+1）`2D6+2`；`1D6-1D4` →（+1D4）`1D6-1D4+1D4`；`３ｄ８` →（+1D8）`4D8`。

### 3.3 紀錄文字

- 技能檢定：`技能值[50] BD/PD[1] ＞ 83, 13 ＞ 13 ＞ 困難成功`；沒填技能值時 `技能值[] BD/PD[0] ＞ 45 ＞ 45`；技能值 0 時 `技能值[0] …`、不判定。
  BD/PD 寫成整數（`-2`、`0`、`1`），候選值之間是半形逗號加空白，段落之間是「 ＞ 」（全形）。
- 自訂擲骰：`<正規化後的算式> ＞ <明細> ＞ <總和>`；算式保留使用者打的小寫 d，明細一律大寫 D、去掉前導 0，
  每顆骰的點數以半形逗號分隔、不加正負號（`-1d6-2D4+10 ＞ -1D6[4]-2D4[1,4]+10 ＞ 1`）。
- 時間：新版 24 小時制「時:分:秒」（兩位數）；從舊版搬過來的紀錄照舊版存的文字（例「下午3:04:05」）。

### 3.4 傷害計算

- 一筆＝一行裡「全形＞、（可有空白）、半形數字、（可有空白）、行尾」；數字前的空白可以跨行（與舊版相同）。
  例：`(1D10+2) ＞ 3[3]+2 ＞ 5` 是 5；`CC<=50 (1D100<=50) ＞ 23 ＞ 成功` 不算；`(1D100) ＞ 45` 算 45；`＞ -3`、全形數字不算。
- 每筆 max(0, 數字 − 護甲)，加總；指令＝`:HP-` 接總和（總和 0 時是 `:HP-0`）。

### 3.5 存檔與專案檔

- 輸入：localStorage `trpg-toolkit:coc-dice`（`{ skill, bonus, expr, armor, damageText }`，技能值與護甲是原生數字欄的值字串）。
- 分頁、紀錄面板開關、擲骰紀錄：`trpg-toolkit:coc-dice:preview`（`{ tab, logOpen, log: [{ id, time, text }] }`，新的在前，最多 200 筆）。
- 舊版：`iklab_coc7_dice_v1`＝`[{ time, text }]`（新的在前）。新版沒有 `…:preview` 時讀它當初始紀錄；之後不再讀，也不刪。
- 專案檔：`{ format: 'trpg-toolkit-project', tool: 'coc-dice', version: 1, savedAt, data: { settings: <輸入>, log: <紀錄> } }`，
  檔名「CoC 擲骰_日期.json」（共用的專案選單）。

### 3.6 亂數（對等驗證用）

- 一顆 N 面骰＝⌊亂數 × N⌋＋1（亂數 0 以上、未滿 1），與舊版的算法相同。
- 取用順序：技能檢定是個位骰、十位骰（依序）；自訂擲骰是項的順序、每項的每顆依序。動畫的假點數不取用（新版用另一個亂數）。
- **注入點**：頁面上設 `window.__cocRandom = () => 數字` 時新版改用它（共用模組 `@/core/coc` 的 `cocRandom`）。
  對等驗證時舊版換掉 `Math.random`、新版設 `window.__cocRandom`，給同一串數字，兩邊的結果、成功等級、紀錄文字逐字相同
  （實作者已用 180 組技能檢定、72 組自訂擲骰比對過，全部相同；傷害計算另用 9 組護甲與文字〔含負護甲、小數、空白護甲、CRLF、
  跨行的「＞」〕比對合計與指令，全部相同）。注意舊版的動畫在 0.8 秒內也會取用 `Math.random`
  （每顆骰 16 次），比對連續兩次擲骰時，舊版每次擲骰前要重設序列。

## 4. 互動與手感

- 動畫：見 F08。跳動中再按擲骰：前一次的動畫取消，直接開始新的（舊版前一次的計時器還會把舊結果蓋上來一下；5. D5）。
- 結果數字約 40～80 px（隨畫面寬度）、等寬字；骰子方塊約 44～72 px。
- 快捷鍵：Ctrl／⌘＋Z 復原、Ctrl／⌘＋Shift＋Z 或 Ctrl＋Y 重做、? 快捷鍵說明；技能值欄、算式欄裡按 Enter 擲骰。
- 自動保存：改了就存；頁首顯示「已自動儲存（時間）」。紀錄在按下擲骰時就寫入（不等揭曉）。
- 「已複製指令！」約 2 秒後消失。

## 5. 容易做壞的地方

- **亂數取用順序**：技能檢定先個位、再十位；不能先擲十位骰。紀錄在按下時就寫，不是揭曉時。
- **「00」配「0」是 100**，不是 0；BD/PD 的候選值也照這個規則。採用的十位骰在同值時只有第一顆。
- **技能值 0 不判定**（舊版以「有沒有值」判斷、0 視為沒有），但紀錄寫 `技能值[0]`。
- **大失敗的門檻看技能值**：未滿 50 時 96～100、50 以上只有 100；1 一定是大成功（比大失敗先判斷）。
- **自訂擲骰的紀錄保留使用者打的小寫 d**，明細才換成大寫；快速加骰後算式欄會變成正規化的寫法（全形變半形、空白拿掉）。
- **快速加骰只合併最後一項**，而且面數的文字要相同（`1D06` 再加 1D6 不合併）。
- **傷害計算的規則照 BCDice 的輸出**：結果行的最後一段是數字才算；1D100 的單純擲骰也會被算進去（舊版如此）。
- **護甲先檢查**：護甲錯誤時即使沒有擲骰結果也顯示護甲的錯誤。
- **舊版紀錄只搬一次**：新版有了自己的紀錄（包括刪光之後）就不再讀舊版。
