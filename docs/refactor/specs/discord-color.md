# Discord 彩色文字產生器（discord-color）行為規格

## 0. 概要

在 Discord 打出有顏色的文字。Discord 的 ```` ```ansi ```` 程式碼區塊看得懂 ANSI 色碼：使用者在編輯區輸入文字、選取一段後按樣式
（清除、粗體、斜體、底線、刪除線）、經典 8 色、自訂 8 色或效果（彩虹、漸層、斑馬），顏色可以上在文字（前景）或背景；
編輯區照 Discord 四種主題（Light、Ash、Dark、Onyx）的配色預覽；最後一鍵複製成 ```` ```ansi ```` 程式碼區塊，貼到 Discord 送出。

輸入：打字、貼上、選取＋按鈕。輸出：剪貼簿裡的 Discord 訊息（純文字，含 ESC 控制字元）；新版另有自動保存與專案檔。

靈感來源：rebane2001／Discord Colored Text Generator（<https://gist.github.com/rebane2001/07f2d8e80df053c70a1576d27eabe97c>，
網站 <https://rebane2001.com/discord-colored-text-generator/>），2026 年 10 月版（本機副本 commit f8daa79）。
授權：公有領域（Unlicense），全文在 `web/src/tools/discord-color/UPSTREAM_LICENSE`；範例文字與預設色沿用（翻成繁中）。
原作的本機副本也放在 `web/tests/unit/fixtures/discord-color-original.html`（e2e 與單元測試拿來對照）。

用語：「格式」＝套用一次樣式或顏色產生的一段（可以一層包一層）；「經典色」＝ANSI 的 8 色（代碼 30～37 前景、40～47 背景）；
「RGB 色」＝自訂色與效果用的 24 位元色。

## 2. 輸入

- 編輯區：任何文字（含表情符號、換行）。貼上時剪貼簿的 HTML 裡有本工具的格式（`span.ansi-<代碼>`，代碼 0、1、3、4、9、30～37、40～47；
  `span.ansi-rgb` 且 `data-hex` 是色碼，有 `data-fg` 是前景）才用 HTML（其他元素只取內容、區塊元素〔div、p…〕之間補換行），
  否則用剪貼簿的純文字（換行照樣換行）。
- 色碼欄：#rgb、#rrggbb、rgb()（共用的色彩欄），存成大寫 #RRGGBB。
- 專案檔：共用格式（3.8）。讀回時逐欄整理：格式樹裡認不得的節點略過（格式的內容保留）、無效的代碼與色碼不當格式、相鄰的文字合併；
  自訂色補齊 8 個、缺的用預設；效果的顏色缺的用預設。不是本工具的專案檔時顯示共用的錯誤訊息。

## 3. 輸出

### 3.1 程式碼區塊

整則訊息＝「```` ```ansi ````」＋換行＋本文＋換行＋「```` ``` ````」。本文由編輯區的格式從頭到尾轉出（3.3），文字照原樣（含空白、全形字、表情符號），
換行是 `\n`。字數＝整則訊息的 JavaScript 字串長度（頭尾共 12 字也算）。

### 3.2 控制碼

| 用途 | 寫法（ESC＝U+001B） | 說明 |
|---|---|---|
| 樣式 | `ESC[<樣式串>;2m` | 樣式串從「2」開始，外層到內層每個樣式接「;代碼」：粗體 `ESC[2;1;2m`、底線裡的粗體 `ESC[2;4;1;2m`。清除（0）也是樣式：`ESC[2;0;2m`（0 會重設所有屬性）。2 是原作墊的代碼（Discord 不處理）。 |
| 經典色 | `ESC[7;<代碼>m` | 前景 30～37、背景 40～47；7 是原作墊的代碼。 |
| RGB 色 | `ESC[38;2;R;G;Bm`（前景）、`ESC[48;2;R;G;Bm`（背景） | R、G、B 是十進位 0～255。 |
| 重設 | `ESC[0m` | |

### 3.3 轉換規則（照原作；同樣的格式得到逐字相同的輸出）

狀態：

- **狀態堆疊**：每層三個值——樣式串（初始「2」）、前景、背景（初始「無」；有值時是經典色代碼或 RGB 控制碼整段）。開始時只有一層初始值。
- **上一次的顏色**：種類（前景／背景／無）、值、開始之後是否出現過文字、已經離開幾串。開始時是（無、無、出現過、0）。
- **剛重設過**：開始時為否。

依序走訪一串節點（同一層的兄弟），每一串有自己的輸出字串，走完接到上一層的輸出後面：

1. **文字**：長度大於 0 時，「上一次的顏色」記為出現過文字；若目前這層的前景是「無」而上一次的顏色種類是前景，把種類改成無（背景同理）。文字原樣輸出。
2. **換行**（`<br>`）：輸出 `\n`。
3. **格式裡沒有任何文字**（空的、或只有換行）：整個略過，裡面的換行也不輸出（3.5 怪癖三）。
4. **格式**：以目前這層為底建立新的一層：
   - RGB 色：控制碼 C（3.2）；新層的前景（或背景）＝C；這次的顏色＝（前景或背景，C）；推入新層；「開始顏色」，控制碼是 C。
   - 樣式（0、1、3、4、9）：新層的樣式串接上「;代碼」；這次的顏色＝（無）；推入新層；輸出 `ESC[<新樣式串>;2m`。
   - 經典色：新層的前景（30～37）或背景（40～47）＝代碼；這次的顏色＝（前景或背景，代碼）；推入新層；「開始顏色」，控制碼是 `ESC[7;<代碼>m`。

   **開始顏色**：(a) 若「剛重設過」而且上一次的顏色種類和這次相同，從**這一串**的輸出刪掉最後一個 `ESC[0m`（相鄰的同種顏色不必重設）；
   (b) 若種類或值和上一次不同：種類相同而上一次之後還沒出現文字時，先把這一串的輸出從最後一個 ESC 起刪掉（沒用到的色碼），再輸出這次的控制碼；
   種類與值都相同時什麼都不輸出（同一個顏色不重複）。

   接著「上一次的顏色」換成這次的，走訪格式裡面的節點（新的一串）。**離開**：取出這一層和外層比，三個值都相同時「剛重設過」設為否；
   不同時輸出 `ESC[0m`，再補回外層：樣式串不是「2」時每一段各輸出 `ESC[<段>;2m`（例 "2;1" → `ESC[2;2m ESC[1;2m`），前景不是「無」時輸出前景
   （RGB 控制碼原樣、經典色寫成 `ESC[7;<代碼>m`），背景同理；「剛重設過」設為是。
5. 一串走完時，「上一次的顏色」的離開串數加 1；加 1 之後大於 1 時把它的種類改成「無」。

### 3.5 原作的怪癖（照原作輸出；修正與否見 5. D1）

3.3 的「刪掉最後一個重設碼／ESC」只在**這一串**的輸出裡找；要刪的東西在外層的輸出時找不到，原作仍照位置切字串：

1. **吃掉字**：例「紅 A」後面接「綠 ab（裡面再包藍 c）」，綠色那串在打到藍色時要刪重設碼（重設碼在外層），結果「b」不見：
   `␛[7;31mA␛[7;32ma␛[7;34mc␛[0m␛[7;32m␛[0m`（應該是 …`ab␛[7;34mc`…）。字串較長時還會把第 4 個字以後的內容重複一次。
2. **吃掉換行**：同種顏色直接包在裡面、前面只有換行時（例「紅（換行、藍 c）」），換行不見：`␛[7;31m␛[7;34mc␛[0m␛[7;31m␛[0m`。
3. **只有換行的格式略過**：效果把換行也當成一個字、包成只有換行的格式，輸出時整個略過——**跨行套用彩虹、漸層、斑馬時，貼到 Discord 會變成一行**。
   例「紅 a」「綠（換行）」「藍 b」→ `␛[38;2;255;0;0ma␛[38;2;0;0;255mb␛[0m`。

新版的轉換程式另有「修正模式」（`AnsiOptions.repair`）：找不到時不刪、只有換行的格式照樣輸出換行；只在原作出錯的情況與原作不同（單元測試以 200 組對照值確認）。
工具目前**不開**（`ANSI_OPTIONS`，照主控「逐字相同」的決定）。

### 3.7 效果的逐字配色

字（字素）共 n 個，第 i 個（從 0 起）的位置 t＝i ÷ (n − 1)（n＝1 時原作是 0÷0，新版用 0；5. D2）：

- 彩虹：HSL（色相 t × 360°、飽和度 100%、亮度 50%）轉 RGB（標準公式），各色版 × 255 後**無條件捨去**。5 個字：#FF0000、#7FFF00、#00FFFF、#7F00FF、#FF0000。
- 漸層：起點 A、終點 B，各色版 A × (1 − t) ＋ B × t 後無條件捨去。預設 3 個字：#FD9855、#E77C7B、#D161A2。
- 斑馬：i 是偶數用顏色 1、奇數用顏色 2。

每個字一個 RGB 格式（前景或背景依「套用到」），換行字元也算一個字（3.5 怪癖三）。色碼大寫。

### 3.8 存檔與專案檔（新版）

- 自動保存：localStorage `trpg-toolkit:discord-color`，`{ state: { data }, version: 1 }`；`data` ＝ `{ doc, custom, gradient, zebra }`。
  `doc` 是格式樹：`{ type: 'text', text }`、`{ type: 'br' }`、`{ type: 'code', code, children }`、`{ type: 'rgb', hex, fg, children }`；
  `custom` 8 個大寫色碼；`gradient`、`zebra` 各兩個色碼。預覽：`trpg-toolkit:discord-color:preview`，`{ theme: 'light'|'ash'|'dark'|'onyx', target: 'fg'|'bg' }`。
- 專案檔：`{ format: 'trpg-toolkit-project', tool: 'discord-color', version: 1, savedAt, data }`（`data` 同上），檔名 `Discord彩色文字_<YYYYMMDD>.json`。
- 剪貼簿（F09）：`text/plain` 是選取的純文字；`text/html` 是格式樹寫成的編輯區結構（例 `<span class="ansi-1">a</span>`）。

## 4. 互動與手感

- 按鈕（樣式、色塊、效果）按下時不搶走編輯區的焦點，選取範圍留著，可以連續按；鍵盤（Tab 到按鈕、空白鍵／Enter）也可以套用。
- 套用後選取範圍是新的格式（F11、F23），再按別的按鈕就包在裡面。
- 打字、改設定立刻更新輸出與字數。
- 複製提示約 2 秒；連續複製的間隔超過 2 秒就從「已複製！」重新開始（F28）。
- 快捷鍵：編輯區 Enter 換行、Ctrl／⌘＋B／I／U；Ctrl／⌘＋Z、Ctrl／⌘＋Shift＋Z、Ctrl／⌘＋Y；? 顯示快捷鍵。
- 預設：範例文字、Ash 主題、套用到文字、預設自訂色與效果顏色。

## 5. 容易做壞的地方

- **套用格式要用瀏覽器的選取文字（Selection.toString()）**，不是 Range 的文字：換行要變成換行、不換行空白變成一般空白；然後照原作的順序
  刪內容、插入新格式、選取新格式的內容——選取的端點落在格式的哪一邊會決定新格式包在裡面還是外面（兩邊用同樣的 DOM 操作才會一樣）。
- **編輯區保留空白與換行**：Enter 插入的是文字裡的換行字元（瀏覽器在這種設定下不插 `<br>`）；套用格式後選取文字裡的換行才變成 `<br>`。
  兩者在輸出時的效果不完全相同（3.3 的第 1、2 步），所以換行的寫法也要和原作一樣。
- **ANSI 轉換的「這一串」**：刪重設碼、刪 ESC 只在同一串的輸出裡找（3.3、3.5），不能改成整段輸出一起找，否則和原作不同。
- **前景／背景切換只換顏色的代碼**：樣式按鈕不受影響；經典色背景是代碼 +10。
- **色碼大寫**：效果與自訂色都存大寫（原作輸出的 RGB 數字與大小寫無關，但色碼會出現在剪貼簿的 HTML）。
- **字數算整則輸出**：每個效果字都有一段約 19 字的色碼，很快超過 2,000 字。
