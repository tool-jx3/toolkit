# 訊息框產生器（message-box）行為規格

## 0. 概要

產生一段貼進 OBS「瀏覽器來源」**自訂 CSS** 欄的 CSS，把 CCFOLIA 房間畫面下方、發言時出現的**訊息框**（附立繪、名稱、骰子結果與逐字打出的內文）
改造成喜歡的樣式顯示在直播畫面上；房間的盤面、棋子、聊天欄等其他部分全部隱藏、背景透明，畫面上只看得到訊息框。
訊息的出現、打字速度、排隊與關閉都由 CCFOLIA 自己決定，CSS 只改外觀與位置。

輸入是外觀設定、來源寬高與房間網址；輸出是 CSS 文字（複製或存成 .css）與來源要用的房間網址。
工具內有模擬 CCFOLIA 房間畫面的即時預覽（可送出各種範例訊息、自訂訊息、關閉訊息框）、範本、復原／重做、自動存檔與專案檔。
全部在瀏覽器內完成，不連任何伺服器（Google Fonts 字型除外）。

靈感來源：shiki365/message-box-maker（<https://github.com/shiki365/message-box-maker>）

用語：「訊息框」指整個元件（含立繪與骰子圖），「方框」指放名稱與內文的那塊底，「標題列」是方框內放名稱、骰子結果與按鈕的一行，
「名牌」是名稱改放在方框上緣外的樣式，「來源」指 OBS 瀏覽器來源。

## 1. 功能清單（對等驗證以此為準）

#### 3.3.1 頁面與位置

- 頁面所有背景透明、沒有捲軸；除了訊息框根與它的所有子孫以外都看不見（F71）。關閉後 CCFOLIA 寫入的隱藏狀態必須保持有效（F72）。
- 訊息框根以來源為基準：左右各離來源邊 F08、底邊離來源底 F07、最大寬 F05，依 F06 靠齊；原本的背景、陰影、外框、圓角全部清除。
  量測：預設時方框在 x＝260～1020、底邊 y＝704；靠左時 x＝16；靠右時 x＝504；來源 800 寬時方框寬 760、x＝20。
- 出現方式「原位出現」：不做任何位移與轉場；CCFOLIA 的滑出位移被抵消，所以關閉時方框在原位停約 0.195 秒後隱藏。

#### 3.3.2 方框與內文區

- 方框寬＝訊息框寬；高＝標題列（若在方框內）＋內文區。外框計入大小（外框 4 px 時內容往內縮 4 px）。
- 標題列在方框內時：內距上＝上下留白、左右＝左右留白、下＝名稱與內文的距離；項目垂直置中。名稱 15 px、行高約 1.35 時標題列高約 36.3 px（12＋20.3＋4）。
- 標題列沒有東西可顯示時（名稱、結果都關閉，且按鈕不是「一直顯示」）整列不顯示，內文區上方改用上下留白。
- 內文區：高＝行數 × 內文字級 × 行高（預設 3 × 17 × 1.6＝81.6 px）；內距上＝0（標題列在方框內）、上下留白（沒有標題列）、或名牌模式的值（3.3.5），
  左右＝左右留白，下＝上下留白；不顯示捲軸；內文從起始行以上的部分被裁掉（長文往上捲時不會跑進上內距或名牌底下）。
  量測：預設方框高約 129.8 px；行數 5、左右 40、上下 20 時方框高約 200.3 px。
- 內文：字型、字重、大小、顏色、行高、字距依設定；保留換行，任何字元處可斷行；描邊依 F38。

#### 3.3.3 略過／關閉按鈕

- 一直顯示：兩個圖示按鈕排在標題列最右端，每個約 34 × 34 px（約 6 px 內距、22 px 圖示），圖示顏色同方框文字色；標題列因此變高（預設約 50 px）。
- 滑鼠移上才顯示：滑鼠不在頁面上時完全不佔位；滑鼠在頁面上（只有在 OBS「互動」視窗才會發生）時以同樣大小出現，並帶約 70% 黑的圓形底與白色圖示。
  出現時標題列會變高、方框往上長。
- 不顯示：永遠不佔位。

#### 3.3.4 名稱、結果（方框內）

- 名稱：單行，過長以「…」省略並可被擠窄；行高約 1.35、字距約 0.04 字；套用 F38 描邊。
- 結果：單行不換行、不被擠窄；行高約 1.35、字距約 0.02 字。接在名稱後時與名稱間隔約 0.8 字；放最右端時被撐開的空間推到按鈕之前。
- 結果顏色依分類（3.1.2）用 F33 的三色之一：
  - 只有文字：文字＝結果色，套用 F38 描邊（「無」時沒有）。
  - 細外框：文字＝結果色，1.5 px 結果色外框、約 12% 結果色的底、圓角 5 px，內距上下約 0.22 字、左約 0.5 字、右約 0.7 字。
  - 色帶：底＝結果色，文字依底色亮度自動選深灰（#15161a）或白色（以常見的亮度加權，亮度 > 150／255 用深色），沒有描邊；圓角與內距同細外框。
  量測（15 px）：只有文字時結果高約 20.3 px；細外框高約 29.1 px、色帶約 27.1 px，標題列因此略高。

#### 3.3.5 名牌模式

- 名稱和結果移出方框，排成一列放在方框上緣：左右各離方框邊 F26，名稱在左、結果緊接在後（間隔 8 px），底邊對齊。
  名牌底邊比方框上緣低「0.7 × 名稱字級（四捨五入）− 上移量」px（正值沉進方框，負值浮在上方）。
- 名牌：底色＋不透明度（F24）、圓角、外框（F25）、內距上約 0.28 字、下約 0.3 字、左右約 0.95 字，帶向下約 2 px、模糊約 6 px 的 25% 黑陰影，沒有文字描邊。
- 結果在名牌旁：只有文字樣式也加上名牌底色與名牌圓角；細外框只有外框沒有淡底；色帶照常；都沒有描邊；圓角＝名牌圓角。
- 內文區上內距＝上下留白＋max(0, 沉入量)＋名牌與內文的距離（F28）。
- 量測（名稱 15 px）：名牌高約 28.9 px；方框高約 116.6 px，名牌底邊在方框上緣下約 11 px；上移量 20、間距 10 時名牌底邊在方框上緣上方約 9 px、方框高約 115.6 px。
- 名牌模式下按鈕（若顯示）也在名牌那一列的最右端。

#### 3.3.6 立繪

- 寬＝F42、高依比例、最高 F43（超過時等比縮小，圖片貼齊底邊與所在那一側）；底邊在方框上緣往下 F46 處；左側時離方框左緣 F45，右側時離右緣 F45。
- 前後：後面時被方框蓋住、前面時蓋住方框。翻轉以底邊中央為軸左右鏡像。
- 量測：預設全身範例立繪（1:2）在 x＝268、240 × 480，底邊在方框上緣；右側、距離 30、重疊 40 時立繪右緣＝方框右緣 − 30，底邊在方框上緣下 40 px。

#### 3.3.7 骰子圖

- 依 F49 的位置規則；每顆 F50 × F50；CCFOLIA 原本的旋轉出現動畫保留（不改）。量測：兩顆 64 px 骰子在方框上緣上方 4 px、右緣 16 px 處（x＝876～1004）；
  名牌模式（15 px）時上移到方框上緣上方約 29 px；立繪在右時移到左側 x＝276 起。

#### 3.3.8 質感、四角括號、陰影

- 舊紙：方框中央偏上一塊淡白亮斑（約 22%）、往四周漸變成約 32% 的褐色暗角，再疊一層約 22% 濃度、160 px 重複的細暗顆粒。
- 顆粒：一層約 35% 濃度、140 px 重複的暗色雜訊。
- 掃描線、漸深、四角括號：見 F11、F15。掃描線與四角括號疊在方框內容之上（含文字），且跟著方框圓角裁切。
- 陰影：見 F14。

### 3.4 CSS 檔

- 純文字，UTF-8，副檔名 .css。內容依序：開頭說明註解（F69）、字型匯入（F70）、各部分的規則。
- 新版可自由安排規則的寫法與順序，只要 3.3 的外觀相同、F69、F70 的項目齊全。
- 產生的 CSS 不得依賴房間畫面其他部分的結構（3.1.2），也不得依賴雜湊 class（結果配色的三個 class 除外）。

### 3.5 字型清單

與狀態條規格 3.5 相同（同一份清單、同樣的字重規則、後備字型與電腦字型）。新版以共用字型目錄為準。

### 3.6 來源大小

來源大小由使用者指定（F03、F04），不自動量測。立繪會超出方框上緣，高度要把立繪算進去；寬度小於 900 px 時 CCFOLIA 縮小立繪與骰子，本工具會覆寫回設定值（F73）。

### 3.7 網址

- 房間 ID：從文字中「rooms/」後面接的英數、底線、連字號取出；或整段文字本身就是 4 個字元以上的英數、底線、連字號時視為 ID。
- 來源網址：`https://ccfolia.com/rooms/{房間ID}`（不加 /chat、不帶查詢參數）。

### 3.8 對等驗證的比對方法

1. **中立模擬 DOM**：`scratchpad/specs-g4/dom/ccfolia-room.html`（依 3.1 自寫：房間畫面替身＋訊息框結構、原本外觀、窄視窗的縮小規則、
   排隊／打字／滑入滑出／關閉後隱藏的行為、結果配色 class、秘密骰）。它提供「立即顯示完整內文、不播滑入」的模式供截圖比對，
   也提供照 CCFOLIA 節奏的模式供互動驗證。
2. **比對腳本**：`scratchpad/specs-g4/compare.mjs <情境.json> <舊.css> <新.css> <輸出前綴>`，情境指定來源大小、一則訊息（名稱、內文、立繪形狀、
   結果文字、骰子）、凍結時間（骰子動畫建議 700 ms 之後）與滑鼠是否在頁面上。輸出並排圖、差異圖與差異像素比例。
   預設擋掉網頁字型（兩邊用後備字型），字型另以 CSS 文字比對（F21、F32、F34、F70）。舊版 CSS 可用 `legacy-css.mjs` 取得（只供驗證者）。
3. **通過條件**：差異像素比例 ≤ 0.5%（任一色版差 > 24 視為不同）；舊紙、顆粒兩種雜訊質感不逐像素比，改比方框平均色（±4）並目視；
   範例立繪與骰子圖用模擬 DOM 內建的同一份圖（不受新版自繪影響）。
4. **必測情境**：預設；名牌（往上移 0 與 20）；結果三種樣式 × 兩種位置 × 三種分類；按鈕三種 × 滑鼠在／不在頁面上；靠左／置中／靠右；
   來源 800 × 600（窄）；立繪右側＋前面＋翻轉＋重疊；立繪關閉；骰子圖關閉；五種質感；四角括號；描邊四種；內文 5 行的長文（捲到底）；
   名稱、結果都關閉；秘密骰；沒有立繪的發言者。
5. **行為**（模擬 DOM 的 CCFOLIA 節奏模式）：F09 滑入／原位出現的位置取樣（0、100、225 ms）；F72 關閉後 300 ms 訊息框不可見、下一則再出現；
   F71 盤面、聊天欄等替身元素在截圖中不可見。
6. **互動功能**（F51～F64、F74～F81）以 Playwright 操作兩邊比對狀態與結果。

## 4. 互動與手感

### 4.1 一般

- 改任何設定立即重畫預覽；拖動滑桿時即時更新數值與預覽，**放開時**才記成一個復原步驟、才更新依設定出現／隱藏的控制項。

- 開頁時：讀自動存檔（沒有則用預設），回到上次的設定分頁，建立預覽並送出第一則範例訊息（F64），狀態列顯示就緒。

## 5. 容易做壞的地方

- **用「看不見」而不是「拿掉」來藏房間**：房間畫面其他部分的結構未知且會變，必須做到「除了訊息框都看不見」而不依賴盤面的結構（F71）。
  訊息框是房間畫面的子孫，藏起來的方式必須讓訊息框能再度顯示。
- **關閉後不能被重新顯示**：CCFOLIA 關閉時把隱藏寫在訊息框根的 style 屬性；讓訊息框顯示的規則若無條件強制可見，關閉就失效（F72）。
- **CCFOLIA 的樣式會蓋掉自訂 CSS**：頁面樣式在自訂 CSS 之後插入，產生的 CSS 需要更高的優先順序；「原位出現」還要壓過 CCFOLIA 寫在 style 屬性上的滑動位移。
- **深色模式的白色疊層**：MUI 在方框與根元素上疊了一層 11% 白的漸層（3.1.3），換底色時要一併清掉，否則顏色偏灰（「無質感」時也一樣）。
- **窄來源的縮小**：來源寬 < 900 px 時 CCFOLIA 會縮小立繪與骰子圖，要覆寫回設定值；預覽要以來源寬度作為視窗寬度才重現得出來。
- **長文上捲進名牌**：內文區上方有內距時，往上捲的文字不能露在內距或名牌底下（3.3.2 的裁切）。
- **標題列的有無**：名稱、結果都關閉、按鈕不是一直顯示時，標題列整列消失、內文改用上下留白。舊版此時若按鈕設為「滑鼠移上才顯示」，按鈕也跟著消失
  （在 OBS 互動視窗也按不到關閉）。新版若讓按鈕在滑鼠移上時仍出現，屬刻意改善，需主控確認。
- **名牌沉入量**依名稱字級（約 0.7 倍）計算，上移量可以超過沉入量（名牌浮在方框上方）；內文上內距只加正的沉入量。
- **骰子圖的位置**要避開立繪那一側，名牌模式時要抬高避開名牌。
- **結果只有最後一段**：預覽與說明都要反映 CCFOLIA 只放「＞ …」最後一段；不能讓使用者以為能顯示點數。
- **色帶的文字色**：依結果色亮度自動選深或白，淺色底不能配白字。
- **自訂訊息的 Enter**：輸入法選字中的 Enter 不送出。
- **預覽不放大**：倍率上限 1（狀態條是 2），來源大時縮小顯示。
- **內文行數**：介面是 1～8，但讀專案時接受到 10（舊版的小落差）；新版統一成 1～8 或 1～10 都可，屬可接受差異。
- **字型的預設與後備**：舊版預設字型是日文的 Noto Sans JP；新版預設改用繁中字型、電腦內建字型改列台灣常見字型，屬刻意改善，需主控確認（同狀態條規格）。
- **復原不含預覽設定**：套用前／後、背景、範例立繪形狀不受復原影響；自己的範例立繪也不進專案檔與重設。
- **快捷鍵**：焦點在文字欄、數字欄時 Ctrl＋Z 留給輸入欄本身；來源寬高是數字欄，確定後才生效。

## 7. 主控裁定（審查者，2026-10-01）

- 規格審查通過：只描述套用後看得到的結果、量測值與 CCFOLIA 的外部 DOM 事實（3.1），沒有原作的 CSS 或程式表達。
- **預設值**：數值類照第 1 節；顏色與裝飾的預設由新版自己做的預設範本決定。
- **字型**：新版預設改用繁中字型，電腦字型清單加入台灣常見字型（同狀態條）。核准，屬刻意改善。
- **名稱與結果都關掉、按鈕設為「滑鼠移上才顯示」時按鈕跟著消失**：核准修正，滑鼠移上時按鈕仍要出現（刻意改善）。
- **CSS 開頭的範本註記**：改成「以某範本為基礎」，屬可接受差異。
- **舊存檔匯入**：不提供；已經貼在 OBS 裡的 CSS 不受影響。
- **非官方聲明**：保留一句自己寫的「本工具與 CCFOLIA 官方無關；CCFOLIA 改版時可能需要重新產生 CSS」。
- **CCFOLIA 自動產生的 class（骰子結果配色）**：集中放在 `web/src/ccfolia/`。
- **中立模擬 DOM**：只給驗證者使用，不給實作者；實作者依 3.1 的外部 DOM 事實自己做預覽。
