# 訊息框產生器（message-box）行為規格

## 0. 概要

產生一段貼進 OBS「瀏覽器來源」**自訂 CSS** 欄的 CSS，把 CCFOLIA 房間畫面下方、發言時出現的**訊息框**（附立繪、名稱、骰子結果與逐字打出的內文）
改造成喜歡的樣式顯示在直播畫面上；房間的盤面、棋子、聊天欄等其他部分全部隱藏、背景透明，畫面上只看得到訊息框。
訊息的出現、打字速度、排隊與關閉都由 CCFOLIA 自己決定，CSS 只改外觀與位置。

輸入是外觀設定、來源寬高與房間網址；輸出是 CSS 文字（複製或存成 .css）與來源要用的房間網址。
工具內有模擬 CCFOLIA 房間畫面的即時預覽（可送出各種範例訊息、自訂訊息、關閉訊息框）、範本、復原／重做、自動存檔與專案檔。
全部在瀏覽器內完成，不連任何伺服器（Google Fonts 字型除外）。

靈感來源：shiki365/message-box-maker（<https://github.com/shiki365/message-box-maker>）

用語：「訊息框」指整個元件（含立繪與骰子圖），「方框」指放名稱與內文的那塊底，「標題列」是方框內放名稱、骰子結果與按鈕的一行，
「名牌」是名稱改放在方框上緣外的樣式，「來源」指 OBS 瀏覽器來源。

## 1. 功能清單（對等驗證以此為準）

## 5. 容易做壞的地方

- **用「看不見」而不是「拿掉」來藏房間**：房間畫面其他部分的結構未知且會變，必須做到「除了訊息框都看不見」而不依賴盤面的結構（F71）。
  訊息框是房間畫面的子孫，藏起來的方式必須讓訊息框能再度顯示。
- **關閉後不能被重新顯示**：CCFOLIA 關閉時把隱藏寫在訊息框根的 style 屬性；讓訊息框顯示的規則若無條件強制可見，關閉就失效（F72）。
- **CCFOLIA 的樣式會蓋掉自訂 CSS**：頁面樣式在自訂 CSS 之後插入，產生的 CSS 需要更高的優先順序；「原位出現」還要壓過 CCFOLIA 寫在 style 屬性上的滑動位移。
- **深色模式的白色疊層**：MUI 在方框與根元素上疊了一層 11% 白的漸層（3.1.3），換底色時要一併清掉，否則顏色偏灰（「無質感」時也一樣）。
- **窄來源的縮小**：來源寬 < 900 px 時 CCFOLIA 會縮小立繪與骰子圖，要覆寫回設定值；預覽要以來源寬度作為視窗寬度才重現得出來。
- **長文上捲進名牌**：內文區上方有內距時，往上捲的文字不能露在內距或名牌底下（3.3.2 的裁切）。
- **標題列的有無**：名稱、結果都關閉、按鈕不是一直顯示時，標題列整列消失、內文改用上下留白。舊版此時若按鈕設為「滑鼠移上才顯示」，按鈕也跟著消失
  （在 OBS 互動視窗也按不到關閉）。新版若讓按鈕在滑鼠移上時仍出現，屬刻意改善，需主控確認。
- **名牌沉入量**依名稱字級（約 0.7 倍）計算，上移量可以超過沉入量（名牌浮在方框上方）；內文上內距只加正的沉入量。
- **骰子圖的位置**要避開立繪那一側，名牌模式時要抬高避開名牌。
- **結果只有最後一段**：預覽與說明都要反映 CCFOLIA 只放「＞ …」最後一段；不能讓使用者以為能顯示點數。
- **色帶的文字色**：依結果色亮度自動選深或白，淺色底不能配白字。
- **自訂訊息的 Enter**：輸入法選字中的 Enter 不送出。
- **預覽不放大**：倍率上限 1（狀態條是 2），來源大時縮小顯示。
- **內文行數**：介面是 1～8，但讀專案時接受到 10（舊版的小落差）；新版統一成 1～8 或 1～10 都可，屬可接受差異。
- **字型的預設與後備**：舊版預設字型是日文的 Noto Sans JP；新版預設改用繁中字型、電腦內建字型改列台灣常見字型，屬刻意改善，需主控確認（同狀態條規格）。
- **復原不含預覽設定**：套用前／後、背景、範例立繪形狀不受復原影響；自己的範例立繪也不進專案檔與重設。
- **快捷鍵**：焦點在文字欄、數字欄時 Ctrl＋Z 留給輸入欄本身；來源寬高是數字欄，確定後才生效。
