# 地圖演出產生器（map-fx）行為規格

## 0. 概要

在一張地圖或平面圖上畫三種「演出框」，做成探索進度的動畫：**區域放大**（周圍變暗、框裡的區塊像卡片一樣浮起來放大）、
**路線・地點**（移動路線、腳印、霓虹路線、行軍箭頭沿路線畫出來；目的地圖釘、鎖定準星、危險區）、
**房間遮罩**（黑暗＋「？房名」、禁止進入的斜線、戰爭迷霧、馬賽克；揭開、一直蓋著或蓋上）。
時間軸分成開場、彈出、動作、結尾四段，多個框可以依序或同時動作；地圖可以放在模糊、透明或單色的背景上，加圓角、陰影與出處文字。
跑團用：CoC 等探索型劇本的移動路線與探索進度、CCFOLIA 的前景與面板、團報與宣傳的插圖。全部在瀏覽器內處理，不上傳。

輸入：地圖圖片（選檔、拖到視窗裡、貼上）、在預覽上拖曳畫出的框、點選的路線、各項設定。
輸出：完成圖 PNG（結尾那一格）、複製圖片、APNG（全彩或減色、循環或播放次數）、影片（背景不透明時 MP4，透明時透明的 WebM）、
X 用 MP4、房間遮罩 ZIP（CCFOLIA 自由探索用）、逐步公開／圖層／連番 PNG 的 ZIP、3D 移動影片（MP4）、專案檔（ZIP）。

分兩批：**第一批＝2D 地圖演出**（1.1～1.10）；**第二批＝進階 3D**（1.11：房間與走廊做成線框的立體空間、牆上的入口、依序點出的移動路線、鏡頭沿路線走過去的預覽與 MP4 影片；設定欄的第四個分頁）。

靈感來源：KIIN／マップ・見取り図 演出スタジオ（BOOTH 販售的付費工具，item 9022911；免費試用的 Lite 版 <https://map-stage.pages.dev/>）。
只拿得到 Lite 版的 `index.html`（程式 `app.js`、`advanced3d.js` 與樣式連不到）：功能、選項、範圍與預設值從其中的控制項（滑桿的最小值、最大值、間隔、初始值，選單的選項）、
使用說明對話框與製品版對話框讀出。原作的條款禁止再散布程式與工具固有的意匠：**視同未授權**——只參考功能、數值範圍與做法；
程式、版面、框・路線・圖釘・遮罩的外觀、範例圖、介面文字全部自己做（繁中），不放 `UPSTREAM_LICENSE`。Lite 版的浮水印與製品版限定的功能限制全部不做。

用語同截圖演出產生器的規格（[screenshot-fx.md](screenshot-fx.md) 第 0 節）：「畫面」＝輸出的整張圖（W × H）；「地圖」＝使用者放的圖；
「原圖 px」＝地圖本身的像素；「f」＝地圖放上畫面時的縮放；「u」＝短邊 ÷ 1080；「框」＝演出框；
「會動的框」＝路線・地點，以及動作是揭開或蓋上的房間遮罩；「k」＝放大框的倍率（框裡的線寬、字跟著放大，框外是 1）；「自訂」＝原作的程式拿不到，數值與外觀由本站決定。

### 0.1 與截圖演出產生器共用的部分（共用層）

原作與截圖演出產生器（スクショ演出スタジオ）是同一位作者、同一套引擎。引入 map-fx 時，把 screenshot-fx 裡兩個工具共用的部分抽成共用層
（DESIGN.md 4.1「圖片演出」、4.2 `@/core/imagefx`），兩個工具各自提供「框的種類與外觀」與介面：

| 共用層 | 內容 |
|---|---|
| `@/core/imagefx`（types、layout） | 框的共用欄位（`FrameBase`、`ZoomFrameBase`、`RedactFrameBase`）、畫面大小、圖的擺放、出處的位置、原圖 px 與畫面 px 的換算、放大框彈出後的位置、整理存檔的小工具 |
| `@/core/imagefx`（timeline） | 四段時間軸、依序／同時（`TimelineKit.isAction` 決定哪些框會動）、各框的進度、塗黑蓋住的範圍（**新增整塊淡出 `fade`**：`redactCover` 回傳範圍與不透明度）、逐步公開、運鏡 |
| `@/core/imagefx`（render） | 畫一格的流程（底圖快取 → 圖上的標記與塗黑 → 聚光 → 放大框 → 出處）、背景、只畫在外面的陰影、塗黑（黑塊、嚴格區塊平均的馬賽克、毛玻璃；工具可以加自己的樣式 `paintRedact`）、邊界演出、圖層；工具的 `RenderKit` 畫自己的標記（`drawMark`）與放大框樣式（`paintCard`），框上的文字先等字型（`fontText`） |
| `@/core/imagefx`（export、store、media） | PNG、APNG、影片、三種 ZIP 的匯出（`createFxExporter`）、影片的編碼與即時錄影（`encodeFxVideo`）、狀態與動作（`createFxStore`：復原的步數、偏好、選取、資產庫、框的新增複製刪除上下移；第二批加了 `resetForImage`：換圖時工具自己的內容怎麼處理，地圖演出用來清 3D 的房間與路線、示範演出時換上範例）、圖片載入、專案檔 |
| `@/ui/imagefx`（ImageFx*） | 預覽欄（工具列插槽、編輯區的工具列、舞台、編輯層、播放列、完成的樣子、複製）、編輯層（輔助線、拖曳畫框、選取、控點、方向鍵、手形、框選放大）、匯出區（工具可以加格式）、設定欄的共用區塊（地圖、畫面、擺放、出處、時間軸、框的清單、放大框的設定）、專案選單、快捷鍵表 |

screenshot-fx 的行為與輸出不變（抽出的 commit `c988b21`）：單元測試 62 項、e2e 21 項照舊通過；`web/tests/unit/screenshot-fx-golden.test.ts` 以抽出之前的程式畫的 138 格（每個場景、時間、運鏡、圖層、逐步公開）的 SHA-256 當基準；同一份內容在瀏覽器匯出的 PNG、APNG（128 色、全彩）抽出前後位元組相同，逐步公開、圖層、連番 PNG 的 ZIP 每個檔案位元組相同（只有 ZIP 的時間戳不同）。
以下第 1 節標「共用」的功能，行為與 screenshot-fx 規格的對應編號相同（數值見該規格第 3 節），map-fx 的編號仍各自驗證。

## 1. 功能清單（對等驗證以此為準）

原作是三欄：左欄（圖片與背景、演出的時機）、中央（畫框的工具列與新框的預設、預覽、播放列）、右欄（「演出的編輯」與「匯出」兩個分頁）。
新版用共用外框：設定欄三個分頁「地圖」（地圖、畫面、背景、地圖的擺放、出處）、「演出框」（新畫的框的預設、框的清單與個別設定）、「時間軸」；
預覽欄是畫框的工具列（含點選建立路線）、編輯區的工具列、舞台、播放列、「完成的樣子」與複製圖片、共用的匯出區。

「批次」：第一批（2D）、第二批（進階 3D）。

### 3.9 匯出

- PNG、APNG、影片、逐步公開、圖層、連番 PNG：同 screenshot-fx 3.9、3.13（共用；運鏡沒有）。圖層的第三張是路線與地點（標記），螢光筆換成路線・地點。
- 先等字型：出處、標籤、房名、「？」的字（介面字型粗體）載好才畫（預覽也在字型載好後重畫）。
- **X 用 MP4**：大小＝畫面 × min(1, 1280 ÷ 長邊)（四捨五入後往下取偶數，至少 2）；30 fps；每格先以畫面大小畫好、再以高品質縮小畫進影片；
  MP4 透明的地方鋪 `bg.color`（單色背景的顏色）；只用 H.264：逐格編碼試 H.264（High、Main、Baseline），不行時即時錄影，但只接受
  `video/mp4;codecs=avc1…`（VP9 的 MP4、WebM、沒寫編碼的 `video/mp4` 都不算）；都不行時這個格式停用，原因「這個瀏覽器編不出 H.264……一般的 MP4、WebM 照舊可以匯出」
  （瀏覽器根本不能編影片時是共用的「不能把動畫編成影片」）。檔名 `map-fx-年月日-時分秒-x.mp4`。
- **房間遮罩 ZIP**：房間＝清單裡所有房間遮罩（照清單順序，不管動作）；NN＝兩位數序號；房名的檔名用字：去掉頭尾空白、`\ / : * ? " < > |`、空白與句點換成底線、最多 24 字；沒有房名時只有序號。
  `map_<W>x<H>.png`（W、H＝地圖原圖 px ÷ 格的 px）是原本的地圖（重新編成 PNG）；`NN_房名_full.png` 是地圖大小的透明畫布上、在房間的位置畫蓋滿的遮罩；
  `NN_房名_x<cx>y<cy>_<cw>x<ch>.png` 是同一張往外對齊格線裁下來的：g＝格的 px，cx＝⌊x ÷ g⌋、cy＝⌊y ÷ g⌋、cx₁＝max(cx＋1, ⌈(x＋w) ÷ g⌉)、cy₁ 同理
  （比較前各留 10⁻⁹ 的誤差，剛好在格線上的不多擴一格），cw＝cx₁－cx、ch＝cy₁－cy，裁切範圍＝(cx·g, cy·g, cw·g, ch·g)（原圖 px，左上角＝第 0 格）；
  超出房間或地圖的地方是透明的（例 1 格 48 px、房間 y 72～336 → 第 1～7 格，上面 24 px 透明）。
  畫遮罩時用地圖原本的解析度：線寬、字級的 u 換成 u ÷ f（看起來和預覽一樣，只是解析度是地圖的）、馬賽克的格數同預覽。ZIP 只打包不壓縮。檔名 `map-fx-年月日-時分秒-rooms.zip`。
  原地圖檔名的格數＝px ÷ 格的 px，四捨五入到小數一位，整數不寫小數點（例 144 px ÷ 24＝`6`、150 ÷ 24＝`6.3`）。

## 5. 容易做壞的地方

- 共用的那些見 screenshot-fx 第 5 節（框存原圖 px、放大框裡要重畫跟它重疊的框、聚光在透明背景時只蓋圖、陰影只畫在外面、馬賽克自己算平均…）。
- **點選路線的範圍與點要一起動**：拖曳、控點、方向鍵、複製只改 x、y、w、h 的話，點會留在原地；整理存檔時範圍以點為準重算。
- **淡出的遮罩沒有邊**：邊界演出只在掃描時畫；淡出時用不透明度，不能剪成一條。
- **房名跟著遮罩走**：「？」與房名畫在遮罩裡（同一個剪裁、同一個不透明度），揭開時一起消失。
- **房間遮罩 ZIP 用地圖的解析度**：u 要除以 f，不然字與斜線在大地圖上變得很細；馬賽克的格數要和預覽一樣。
- **X 用 MP4 不能改到編輯中的設定**：縮小在每一格畫完之後做，透明處鋪的是單色背景的顏色而不是黑。
- **X 用 MP4 只用 H.264**：偵測只試 avc1（不要用共用的 avc1→VP9 順序）；即時錄影的 `video/mp4` 沒寫編碼時可能是 VP9，不算。
- **房間遮罩的裁切往外對齊格線**：不是裁成房間大小；超出地圖的部分要留透明（畫布照格數開，地圖往左上移 (cx·g, cy·g) 畫進去）。
- **標籤的字型**：標籤、房名的字不在出處裡，要另外等字型（RenderKit.fontText），不然第一次匯出會用系統字型。
- **點選路線的鍵盤**：Backspace 在建立中是退回上一點，不能讓它刪掉選取的框；焦點在文字欄時不能攔。

- **進階 3D 的鏡頭穿過標記**：鏡頭站在起點（或終點）時在標記的光柱裡面，整個畫面被光柱的顏色蓋住；鏡頭靠近時把光柱與標籤藏起來，結尾停在目的地前。
- **three.js 不要進工具的主程式**：WalkPreview 用 `lazy()` 載入，測試入口用 `import()` 拿 walk3d；平面圖與設定欄（walk.ts、WalkPanel、WalkPlan）不 import three。
- **地圖貼圖重用**：場景重組時先把地板材質的貼圖拿掉再釋放，不然每次改設定都重新上傳整張地圖。
- **LineMaterial 的 resolution**：線寬是螢幕 px，換大小（匯出的擷取）時要跟著改 resolution 與線寬，不然匯出的線粗細不對。
