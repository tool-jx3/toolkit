# 驗證題梗圖產生器（captcha-card）行為規格

## 0. 概要

做一張「圖片驗證題」樣式的梗圖：上方的主題色色帶寫「請選出所有包含 ○○ 的圖片」＋代表的小圖，下面是 3 × 3 或 4 × 4 的圖片格，
可以勾選；匯出靜態的 PNG，或滑鼠游標一格一格點選勾選的圖片、最後按「驗證」並出現結尾（通過、失敗、錯誤文字、跳出視窗）的動畫。
跑團用：推角色、劇本宣傳、團後梗圖（「請選出所有包含『探索者』的圖片」）。全部在瀏覽器內處理，不上傳。

輸入：代表圖與格子的圖片（選檔、拖放、貼上）、文字、選項。
輸出：PNG（預設 3 倍＝1140 × 1695）、GIF（預設 1.5 倍＝570 × 848）、APNG、WebP；新版另有專案檔（ZIP）。

靈感來源：dearmysn1p3r/DearMySn1p3r_44（<https://dearmysn1p3r.github.io/DearMySn1p3r_44/>；對照的原始碼是 repo 的 `index.html`，a93c2ea，單檔約 930 行，
html2canvas、gif.js、Pretendard 從 CDN 載入）。原作**沒有授權檔（未授權）**：只參考功能、數值與做法；程式、介面文字（原作是韓文）、預設文案、範例、
圖示都自己做（繁中），不放 `UPSTREAM_LICENSE`；原作的 `MOMO.png`（網站圖示）不用。

**商標**：原作的名字與外觀仿 Google 的 reCAPTCHA。新版不用「reCAPTCHA」這個名字與 Google 的標誌，做成通用的「圖片驗證題」樣式
（版面、色帶、格子、底部圖示列參考原作的配置；圖示自己畫；文案自己寫）。

用語：「原作」＝上述網站；「卡片單位」＝卡片的座標（寬 380，CSS px；輸出時乘上倍率）；「有圖的格子」＝放了圖片的格子；
「影格表」＝動畫每一格的畫面與顯示多久（毫秒）。

## 1. 功能清單（對等驗證以此為準）

原作是左邊的預覽（卡片＋下方一排文字按鈕）＋右邊一欄設定（設計、GIF、預覽三段，最下面是 PNG 與「做 GIF」兩個按鈕）。
新版用共用外框：設定分成兩個分頁「卡片」（題目、代表圖、外觀）、「動畫」（結尾、播放、動畫預覽）；預覽區是舞台（卡片＋操作層）、
格子的操作列、說明與共用的匯出區。

## 2. 輸入

- 圖片：瀏覽器能解碼的圖片都可以（PNG、JPEG、WebP、GIF〔第一格〕、AVIF…；沒有副檔名的看檔頭）；長邊超過 1200 px 時等比縮小再存進資產庫
  （格子在 3 倍的 PNG 裡最大約 370 px、代表圖約 234 px）。拖放、選檔、貼上的當下就把檔案讀進記憶體（共用的 FileDrop／WindowDrop／pickFiles）。

2. 每個勾選的格子（依點選順序）：游標移到格子裡（x 在 38%～62%、y 在 40%～62% 之間，依第幾下決定）→ 點一下（按下時出現這一格的勾選），hold＝D(90)；
   沒有游標時只有一格「出現勾選、停 D(140)」。
3. 停 D(380)。
4. 有底部操作列時按按鈕：游標移到按鈕（寬 55%、高 55%）→ 按下 90（按鈕變暗 18%）→ 放開 60 → 停 D(260)；沒有游標時按下 D(130)、放開 D(260)。

## 5. 容易做壞的地方

- **新放的圖自動勾選**（同原作），全選是「有沒勾的就全勾，否則全取消」。
- **打亂含空格**：只打亂看得到的格子，空格也跟著換位置。
- **清空也清掉 3 × 3 時藏起來的格子**。
- **動畫的底圖不畫勾選標示**：勾選一格一格出現；PNG 則全部畫上。
- **錯誤文字的結尾**：最後勾選取消，但錯誤文字留著。
- **搖晃時連疊在上面的東西一起動**（勾選、小視窗、錯誤文字），露出的邊是白色。
- **陰影的模糊與位移以像素計**（不跟著畫布的縮放），要乘上輸出倍率，否則 3 倍時陰影太淡。
- **游標點下去的位置**要在格子中央附近（38%～62%、40%～62%），不是正中央也不是每次亂跳（同一個設定每次相同）。
- **小視窗的不透明度 0 的那格**和前一格畫面相同，GIF 會合成一格（總長不變）。
- **代表圖的縮放以框的中心縮放**，位移跟著等比例，再夾回蓋滿的範圍（不露空白）。
