# 狀態條產生器（status-bar）行為規格

## 0. 概要

產生一段貼進 OBS「瀏覽器來源」**自訂 CSS** 欄的 CSS，把 CCFOLIA 的「角色狀態頁」（只顯示一個角色的頭像、先攻與 HP／MP／SAN 等狀態列的頁面）
改造成直播畫面用的狀態條：條的形狀、填色、文字、角色名稱、頭像、危急與歸零演出、隨數值減少而損壞的裂痕與道具、各種裝飾。
數值由 CCFOLIA 頁面即時提供，CSS 只改外觀，所以在 CCFOLIA 聊天欄改了 HP，OBS 上的條會跟著動。

輸入是外觀設定、房間網址與角色清單（名稱、顏色、角色 ID）；輸出是 CSS 文字（複製或存成 .css）、該角色要填進瀏覽器來源的網址，
以及瀏覽器來源需要的寬高。工具內有模擬 CCFOLIA 角色狀態頁的即時預覽、調整數值的測試列、範本、復原／重做、自動存檔與專案檔。
全部在瀏覽器內完成，不連任何伺服器（Google Fonts 字型除外）。

靈感來源：shiki365/status-bar-maker（<https://github.com/shiki365/status-bar-maker>）

用語：本規格中「條」指一個狀態（例如 HP）的整列，「條本體」指會伸縮的那條長方形區域，「填充」是條本體中代表剩餘量的部分，
「底槽」是填充後面代表已消耗部分的底，「剩餘比例」＝目前值 ÷ 最大值（夾在 0～100%）。

**不可用來選取**；要用元素的階層與第幾個子元素來指定。

#### 3.1.3 隨數值變動的屬性

- **填充的寬度**：寫在填充元素的 style 屬性裡，值是剩餘比例 × 100 再加「%」，剩餘比例先夾在 0～1。瀏覽器把它序列化成
  「width: 83.3333%;」這樣的字串（最多 6 位有效數字，整數時沒有小數點：「width: 0%;」「width: 100%;」）。
  在 CSS 裡，這是唯一能得知剩餘比例的地方。
- **紅字**：目前值的 span 有一個 `color` 屬性：目前值 ÷ 最大值 ≤ 0.8 時是 `secondary`，否則是 `default`。
- **先攻**：先攻為 0 時徽章多了 MuiBadge-invisible（CCFOLIA 會把它縮成 0 而看不見）。
- 數值變化時 CCFOLIA 只改這些文字與屬性，元素本身不會重建（CSS 的動畫與轉場因此能接續播放）。

| 底線 | 沒有底，下方一條 2 px 強調色線，內距左右約 0.1 字、下方約 0.25 字；套用文字外框線。 |
| 側色條 | 背景色底板，左側一道 4 px 的強調色直條，內距上下約 0.35 字、左右約 0.7 字。 |
| 頁籤 | 強調色底，上方兩角圓角約 0.45 字、下方直角，內距上下約 0.3 字、左右約 0.9 字。 |
| 徽章 | 強調色底，全圓角膠囊形，內距上下約 0.25 字、左右約 0.9 字。 |

  底板、側色條、頁籤、徽章四種外觀的文字帶一點向下的淡黑陰影（文字外框線為「無」時則沒有）。
- 位置：最上方／最下方與內容之間隔 F61；條群上方與條群隔 F61；左側時在所有內容（含頭像）左邊、垂直置中、隔 F61。
- 壓在頭像底部：名稱貼齊頭像底部、左右撐滿頭像、文字置中、下方兩角配合頭像圓角（頭像圓角 − 外框粗細）。「只有文字」「底線」兩種外觀在這裡改成
  由透明漸變到背景色（不透明度至少 60%）的底，上方內距約 0.9 字。
- 直書（F60）：由上而下排、行由右往左；換行時名稱最高為 max(整體內容高, 3 × 名稱字級)。

#### 3.3.8 裂痕（F71）

- 裂痕畫在整個條本體（含底槽部分）上，被輪廓裁切；疊在填充與裝飾覆蓋層之上、條外框之下。
- 階段：剩餘比例 < 75% 一處撞擊點、< 50% 兩處、< 25% 三處、＝ 0% 四處並把整條蓋上約 30% 黑。每升一階段，前面的撞擊點維持原樣，再多一處。
- 每處撞擊點放射出約 5～7 道細折線，沿條方向的線較長；第一處大約在條長 2/3～4/5 處，第二處約 2/5～1/2，第三處約 1/10～1/4，
  第四處（碎裂）在中右段且線更長；撞擊點的高度在條高 30%～70% 之間。線寬約條高的 7%（0.9～2 px），旁邊有一道偏移約 0.6 px、
  約 45% 濃度的細白線（像玻璃破裂的亮邊）。
- 同一條每次看到的裂痕形狀相同（開頁、改數值都不變），不同條的形狀不同。形狀細節由新版自行設計，對等驗證只比階段與大致位置（3.9）。

#### 3.3.9 道具（F72、F73）

- 每條的道具欄放「數量」個正方形道具，大小 F73，間距 F73，在條的左或右，與條隔 F73 的距離，垂直置中。
- 每個道具有 5 個樣子：完好、三級逐漸損壞、毀壞（可以是殘骸或消失）。樣子以該條的顏色 1、顏色 2 上色；種類「無」的條不畫。
- 損壞規則（n＝數量，由左數第 j 個道具負責剩餘比例的第 (j−1)/n～j/n 這一段）：該段剩下不到 3/4 時進入第 1 級、不到 1/2 第 2 級、
  不到 1/4 第 3 級、整段用完時毀壞。所以最右邊的先壞；數量設成與最大值相同時，每少 1 點壞掉 1 個。
  - 精確的切點：當門檻是整數百分比時，剩餘比例 ≤ 門檻即進入該級；門檻不是整數時，剩餘比例 < 門檻無條件進位後的整數即進入
    （誤差小於 1%，受限於 3.1.3 只能用字串判斷）。
  - 例：數量 12、最大值 12，目前值 11（91.67%）時最右一個毀壞、其餘完好。
- 損壞瞬間發光見 F74；發光的是整排道具，不只是正在損壞的那一個。

#### 3.3.10 裝飾

- **背景面板**：鋪在整體後面，大小＝內容＋內距（開色線時左側內距多 4 px，並在內側左緣畫一道 4 px 的角色顏色直條）；圓角、外框依設定。
  質感「舊紙」：中間偏上一塊淡淡的白色亮斑、四周往外漸暗成褐色（約 30%），再疊一層細顆粒；「顆粒」：只疊較明顯的暗色顆粒。
- **整體外框**：畫在整體（含面板）外圍，四邊離內容 F76 的間距，不影響內容位置。單線／虛線＝粗細的線；雙線＝總寬約 3 × 粗細（至少 3 px）的雙線；
  發光線＝單線加內外各一圈同色光暈（外約 5 × 粗細、內約 4 × 粗細）；只畫四角＝四角各一個長 F76「四角長度」、粗細寬的 L 形，沒有圓角；
  細框加四角＝約一半粗細的細線框，四角再疊 2 × 粗細的 L 形。改用角色顏色時以角色顏色乘上濃度。
- **光澤**：條本體上方白色，不透明度在頂端＝強度，到約 46% 高處降到強度的約 35%，在一半高度處降到 0（量測強度 100%：頂端幾乎純白，約 42% 高處仍有約 50% 白）。
- **外圈光暈**：條本體四周向外擴散 F78 px 的 c1 光暈（量測擴散 6 px、強度 100%：緊貼邊緣約 47% 不透明，向外約 10 px 淡到 0）。
- **前端光線**：填充右端內側一道 3 px 寬、全高的白線（不透明度＝強度），向左帶一圈約 6 px 的淡色光暈（c1 混白）。
- **流動光線**：寬＝max(40 px, 0.4 × 條本體長) 的斜向白色光帶（中央最亮＝強度，兩側透明），只在填充範圍內可見。
  每個週期（F80 的間隔）的前 40% 時間內由填充左外側慢入慢出地移到條本體右端之外，其餘時間不出現。
- **掃描線**：從條本體頂端起每「間隔」px 一條 1 px 的黑線（不透明度＝濃度）。
- **刻度**：條本體下方 40% 高的範圍內，每「條本體長 ÷ 分割數」px 一條 1 px 的直線，落在每格的最後 1 px（量測 300 px、5 格：x＝59、119…）。
- **顆粒**：條本體上一層暗色細雜訊（每 100 px 重複），濃度越高越明顯。圖樣細節不比對。
- **角落括號**：每一整列（含文字欄、符號欄）向外擴 F84「間距」後的四角各一個 L 形，長度與粗細依設定，畫在條之上。
- 光澤、掃描線、刻度、顆粒、條外框都疊在填充之上、被輪廓裁切，順序（由上而下）：條外框、裂痕、光澤、掃描線、刻度、顆粒。

### 3.4 CSS 檔

### 3.9 對等驗證的比對方法

輸出是 CSS，新舊版的 CSS 文字不會相同，因此以「套用後的畫面」比對：

1. **中立模擬 DOM**：`scratchpad/specs-g4/dom/ccfolia-character.html`（依 3.1 自寫，模擬 CCFOLIA 的元素、屬性與原本外觀，含通知列）。
   比對腳本 `scratchpad/specs-g4/compare.mjs <情境.json> <舊.css> <新.css> <輸出前綴>`：把兩份 CSS 分別套上、等字型、凍結動畫在指定毫秒、
   量來源尺寸並截圖，輸出並排圖與差異圖，印出差異像素比例。情境可指定狀態列（名稱、目前值、最大值）、先攻值、改值步驟與凍結時間。
   舊版的 CSS 可用 `legacy-css.mjs` 取得（只供驗證者使用）。
2. **字型**：預設擋掉網頁字型，兩邊都用後備字型以求穩定；字型名稱、字重與匯入另以 CSS 文字比對（F41～F43、F107：匯入的家族與字重集合相同）。
   需要時以 環境變數 `WEBFONT=1` 實際載入抽查。
3. **通過條件**：
   - 來源尺寸（模擬 DOM 量測值）與工具顯示的尺寸一致，且新舊版相同（±1 px）。
   - 一般情境差異像素比例 ≤ 0.5%（任一色版差 > 24 視為不同，用來吸收反鋸齒差異）。
   - 有新版自繪圖案的區域（符號、道具、頭像範例圖、裂痕線條、顆粒與舊紙雜訊）不做逐像素比對：符號與道具比位置、大小、顏色主調與損壞階段；
     裂痕比出現的階段數、撞擊點的大致位置（條長的哪一段）與整條變暗；雜訊比平均色（±4）並目視。
   - 動畫：在固定時間點（例如脈動 0／275／550／825 ms、閃爍每半週期、震動每 1/4 週期、流動光線 0／400／800／1600 ms）凍結後比對，條件同上；
     時長與緩動另以讀取頁面上的動畫資訊比對（時長 ±5%）。
4. **必測情境**（各至少一張）：每個 F 的開與關、每個選項值、門檻上下各一點（例如危急門檻 25%：3/12 與 2/12）、裂痕每階段、道具數量 1 與 12、
   名稱 10 字以上與含引號、5 個狀態而條數 3（F04）、先攻 0。
5. **互動功能**（F85～F118）以 Playwright 操作兩邊比對狀態與結果。

## 4. 互動與手感

### 4.1 一般

- 改任何設定立即重畫預覽；拖動滑桿時即時更新數值與預覽，**放開時**才記成一個復原步驟、才重建會隨之出現或消失的設定列
  （舊版是為了避免拖動中元件被重建而中斷拖曳）。
- 滑桿旁顯示目前值：px 值、百分比（整數）、秒（0 時顯示「無」）、字距（兩位小數）、條數（「N 條」）、分段（≤ 1 時「無」，否則「N 個」）、
  道具數（「N 個」）、危急門檻（「N% 以下」）。
- 依設定出現／隱藏的控制項（各 F 已註明），隱藏的設定值保留不變。
- 開頁時：讀自動存檔（沒有則用預設），回到上次的設定分頁，建立預覽，狀態列顯示就緒。

### 4.3 電腦字型清單對話框（F120）

- 第一次打開時向瀏覽器要求讀取本機字型的權限（瀏覽器會詢問）；讀取期間顯示提示。拒絕或回傳空清單時顯示說明（如何在網站設定中允許），
  下次點按鈕會再試；頁面無法讀取（例如以本機檔案開啟）時顯示另一種說明。兩種情況都可以直接手打字型名稱。
- 清單依字型家族名稱排序（同一家族只列一次），每一項顯示家族名稱與一行用該字型顯示的樣張；樣張文字可在對話框上方修改（預設樣張要含「永」字，
  用來確認有沒有漢字）。
- 搜尋欄：以空白分隔多個關鍵字，全部都要符合（不分大小寫，比對家族名稱與完整字型名稱）；顯示「共 N 套」或「N 套之中的 M 套」。
  在搜尋欄按 Enter（不在輸入法選字中）選第一個符合的字型。
- 點一個字型：寫進對應的字型名稱欄（等同使用者輸入並確定，會記一個復原步驟並重畫），關閉對話框。
- 打開時目前欄位的字型會被標示並捲到清單中央；焦點在搜尋欄。對話框內的按鍵不觸發頁面快捷鍵（F112）。可按關閉鈕或 Esc 關閉。
- 字型清單讀過一次就留著，下次打開不再要求。

### 4.4 預設值

1. 列出的數值預設（尺寸、比例、開關）為準。顏色、字型與每條的符號／道具等「外觀組合」由新版的預設範本決定（新版預設字型建議用繁中字型，見 5.）。

## 5. 容易做壞的地方

- **CCFOLIA 的樣式會蓋掉自訂 CSS**：頁面自己的樣式在自訂 CSS 之後插入（3.1.4），所以產生的 CSS 必須有更高的優先順序。但是會被動畫改動的性質
  （危急脈動與陰影所在的濾鏡、填充的不透明度與背景位置、流動光線的位移、目前值的顏色）若用「強制優先」的方式寫死，動畫就會失效——兩者要兼顧。
- **剩餘比例只能從字串判斷**：3.1.3 的寬度字串是唯一來源。門檻是「低於」（危急、裂痕）或「≤」（道具的整數門檻），不是四捨五入；100% 開頭也是「1」，
  10～19% 與 100% 要能分開；0% 與 0.x% 要能分開（只有剛好 0% 才算歸零）。
- **危急、歸零、裂痕、道具需要 OBS 31 以上**（3.1.5）；舊 OBS 只有這些演出不動，其餘外觀必須正常，不能整份 CSS 失效。
- **CCFOLIA 原本的配置要全部消掉**：#root 的 100% 高度、8 px 內距、16 px 下外距、210 px 最大寬、96 px 列寬、條本體 16 px 高與內容寬計算、
  底槽 0.38 不透明度、文字層的絕對定位與八方向淺灰描邊、徽章的平移與縮放。任何一項沒蓋掉，OBS 上就會跑版或尺寸算錯（模擬 DOM 會重現這些，用來抓漏）。
- **頭像關閉時**：頭像與徽章都不能佔位。
- **水平漸層的長度是整條**，不是填充長；剩一半時只顯示左半段。
- **填充依輪廓裁切**：膠囊形剩 10% 時，填充左端是圓的、右端被輪廓切成直的（不是另一個小膠囊）。
- **外框在輪廓內側**，不能讓條變大或往外溢；雙線的空隙與線同寬。
- **符號佔用單條寬度、道具加寬整列**：兩者對條本體長度的影響相反。
- **「只有目前值」時「/最大值」不能佔位**；「只顯示置中的數值」時標籤不顯示。
- **名稱為空的角色不顯示名稱**，版面要像「不顯示名稱」一樣收起來；「壓在頭像底部」但頭像沒開時也不顯示。
- **名稱跳脫**：名稱含「"」「\」或換行時 CSS 不能壞。
- **來源尺寸**要在網頁字型載入後重算；範例要以 10 個字的名稱估算（3.6）。尺寸算小了，OBS 上會被切掉。
- **損壞閃光會在回升時也閃**：舊版只要剩餘比例跨過任何一個階段（往下或往上）就閃一次，開頁時若已在某階段也會閃一次。新版若改成只在往下時閃，
  屬刻意差異，需主控確認（純 CSS 難以分辨方向，保留舊行為較單純）。
- **閃光是整排道具一起閃**，不是單一個。
- **F04 的預覽**：舊版預覽只畫條數那麼多列，「隱藏多餘的條」關閉時看不出效果。新版若讓測試列可多放幾個狀態以預覽這個差別，屬刻意改善，需主控確認。
- **多餘的條與危急演出**：「隱藏多餘的條」關閉時，若條數以內每一條都勾了危急，舊版的危急演出也會作用到條數之後的條；只勾了部分時則不會。
  這是舊版的副作用，新版可以統一成「只作用在條數以內有勾的條」，屬刻意差異，需主控確認。
- **CSS 開頭的範本註記**：舊版套用範本後再怎麼改，註記仍是那個範本。新版可沿用，或改成「以某範本為基礎」，屬可接受差異。
- **字型的預設與後備**：舊版預設字型是日文的 Noto Sans JP，電腦內建字型只列日文 Windows 字型。新版預設改用繁中字型、電腦內建字型改列台灣常見字型
  （微軟正黑體、新細明體、標楷體）並保留舊的三套，屬刻意改善，需主控確認。
- **復原不含測試數值**：測試數值、預覽角色、預覽背景不受復原／重做影響（復原時維持目前的測試狀態）。
- **快捷鍵**：焦點在文字欄、數字欄時 Ctrl＋Z 要留給輸入欄本身；滑桿、勾選、選單上則照樣觸發工具的復原。

## 7. 主控裁定（審查者，2026-10-01）

- 規格審查通過：只描述套用後看得到的結果、量測值與 CCFOLIA 的外部 DOM 事實（3.1），沒有原作的 CSS 或程式表達。
- **預設值**：數值類照第 1 節；顏色、符號、道具的預設由新版自己做的預設範本決定。
- **字型**：新版預設改用繁中字型；電腦字型清單加入微軟正黑體、新細明體、標楷體並保留原本三套；Google Fonts 清單照 3.5（另加繁中字型）。核准，屬刻意改善。
- **道具與符號**：新版自己設計題材與圖案，數量與階段數相當（約 6 種道具 × 5 個損壞階段、約 13 種符號）即可；比對時只比階段、位置與數量，不比圖案。
- **損壞閃光在回升與開頁時也閃**：保留舊行為。
- **「隱藏多餘的條」關閉時**：核准兩項刻意改善——預覽可以多放幾個狀態看出差別；危急演出統一成「只作用在條數以內有勾的條」。
- **CSS 開頭的範本註記**：改成「以某範本為基礎」，屬可接受差異。
- **舊存檔匯入**：不提供（原作的存檔格式不描述、不相容）；已經貼在 OBS 裡的 CSS 不受影響。
- **非官方聲明**：保留一句自己寫的「本工具與 CCFOLIA 官方無關；CCFOLIA 改版時可能需要重新產生 CSS」。
- **CCFOLIA 自動產生的 class（例如骰子結果配色）**：集中放在 `web/src/ccfolia/`，改版時只改那裡。
- **中立模擬 DOM**（觀察者在 scratchpad 寫的）：只給驗證者使用，不給實作者；實作者依 3.1 的外部 DOM 事實自己做預覽。
