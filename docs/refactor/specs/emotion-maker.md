# 表情產生器（emotion-maker）行為規格

## 0. 概要

用「組合部件」的方式快速做出一張張 Q 版表情：在固定的頭部底圖上，從眼睛、眉毛、嘴巴各選一種，再疊上任意多個漫畫式的裝飾符號
（汗滴、怒筋、臉紅、陰影、整臉色調等），即時預覽後存進表情清單。清單可以編輯、複製、刪除、勾選，也能一鍵加入一組內建的
常見情緒預設；最後把挑選的表情排成一張合輯圖（每格下方可加文字）匯出 PNG。使用者也能上傳自己的圖片當成任一類的部件。
清單與自訂部件保存在瀏覽器裡，並可匯出／匯入成 JSON 檔。所有處理都在瀏覽器裡完成，不上傳。

靈感來源：sotsotssi/emotion-maker（<https://github.com/sotsotssi/emotion-maker>）

**素材聲明**：舊版內建的約 39 張部件圖片是原作者的著作，新版**不沿用**，全部自己重新繪製（向量或程序生成）。本規格只描述素材的類別、
題材與可做的操作；對等條件是「題材涵蓋相當、每種素材可做的操作相同」，不比對圖案本身。

## 2. 輸入

- **自訂部件**：瀏覽器能解碼的任何圖片，可一次多張；建議與底圖同樣是正方形、背景透明、與臉的位置對齊（舊版不會幫忙對齊或縮放）。
  非正方形的圖在預覽與合輯圖中的處理不一致，見 5.。舊版把圖片以文字形式存在 localStorage，大圖很快就會超過容量。
- **匯入清單**：本工具匯出的 JSON 檔（F43）。
- **標籤**：任意文字，可多行。

### 3.2 預覽與縮圖

- 預覽、選項縮圖與清單縮圖都是把圖層依 F06 疊合；部件圖片在這些地方是**等比縮放、置中**放進正方形。

### 3.3 合輯圖 PNG

- **格式**：PNG，8-bit RGBA。背景透明時，格子以外與頭像以外的像素完全透明 (0, 0, 0, 0)；白色或自訂色時整張鋪滿該色。
- **排列**：取清單中**有勾選**的那些筆、依清單順序，由左到右、由上到下填入；最後一列靠左。欄數依 F32，列數＝勾選數 ÷ 欄數無條件進位。
- **每格**＝上方一個「格子大小」見方的頭像（各圖層**拉伸**到格子大小後疊合，見 5.）＋下方一個文字區。
- **文字區**：所有格子同高。高度＝（所有格子中文字的最多行數）× 行高 ＋ 2 × 內距；行高約為字級 × 1.28（四捨五入），內距約為字級 × 0.5（四捨五入）。
  只有「全域顯示文字開啟、該筆顯示文字開啟、且標籤不是空的」的格子才畫文字；沒有任何格子要畫文字時文字區高度為 0。
- **文字**：每行水平置中於格子；第一行的上緣在頭像下緣往下一個內距處，行與行相隔一個行高；顏色＝文字顏色；字重為半粗體；
  寬度超過「格子大小 − 2 × 內距」時**逐字**換行（中文、英文都一樣逐字，不避頭尾）；標籤裡的換行照用，連續換行產生空白行（也算行數）。
  舊版字型是系統內建的無襯線字型；新版改用繁中字型，屬刻意差異。
- **尺寸**：寬＝欄數 × 格子大小 ＋（欄數 ＋ 1）× 間距；高＝列數 ×（格子大小 ＋ 文字區高）＋（列數 ＋ 1）× 間距。
  第 c 欄、第 r 列（0 起算）的頭像左上角在（間距 ＋ c ×（格子大小 ＋ 間距），間距 ＋ r ×（格子大小 ＋ 文字區高 ＋ 間距））。
- **檔名**：`emotion-grid_<YYYYMMDD>_<HHMM>.png`（本機時間）。

## 5. 容易做壞的地方

- **疊放順序**是「眉毛在眼睛下面」，摘要卻是「眉毛 · 眼睛 · 嘴巴」；兩者順序要照做。
- **裝飾清單上面＝前面**，序號 1 是最前；新點的裝飾在最前。
- **隨機只給一個裝飾**，而且會取代原本的裝飾；候選包含自訂部件。
- **再點一次已選的單選部件會取消**，四類都可以是空的；但四類全空時不能儲存。
- **編輯是原地更新**（位置、勾選不變），複製是插在正後方，儲存新的是加在最後。
- **合輯圖的文字區所有格子同高**（取最多行數），沒有任何文字時完全不留文字區。
- **欄數不超過張數**，0 與負數都是自動；各數字欄的實際接受範圍與欄位標示不同（F32～F37），新版若統一成欄位標示的範圍，屬刻意差異，需主控確認。
- **非正方形的自訂部件**：舊版在預覽與縮圖中等比置中，在合輯圖中卻被**拉伸成正方形**（實測 200 × 400 的圖在合輯圖裡被橫向拉寬、縱向壓扁）。
  新版建議兩邊一致採等比置中，屬刻意改善，需主控確認。
- **移除自訂部件時的連帶清除**：舊版刪除某一類的自訂部件時，也會把**裝飾類中同名**的自訂部件引用一併從表情中拿掉（例如眼睛類與裝飾類都有一個叫 B 的自訂部件，刪掉眼睛的 B，表情裡的裝飾 B 也不見了）。新版只清除同一類的引用，屬刻意改善。
- **匯入時的選擇**：舊版用一個「確定／取消」的確認框，按確定是加入，按**取消反而會覆蓋**目前的清單（而且沒有真正的取消）。新版改成三個明確選項（加入／取代／取消），屬刻意改善，需主控確認。
- **匯出不含自訂部件的圖片**：換一台電腦匯入後，用到自訂部件的表情會少掉那些圖。新版若把自訂部件一併放進匯出檔，屬刻意改善，需主控確認。
- **自訂部件存放位置**：舊版存在 localStorage，容量小（幾 MB），存不下時只顯示通知、那張圖重新整理後就不見了。新版存 IndexedDB，屬刻意改善。
- **預設組的標籤**：舊版預設組的標籤會跟著介面語言變；一旦編輯或複製，就變成固定文字。新版只有繁中，標籤就是普通文字。
- **舊版素材是 500 px 的點陣圖**，格子大小 800 時會被放大而模糊；新版向量素材更清晰，屬可接受差異。
- **字型**：合輯圖文字改用繁中字型（刻意差異）；換行位置可能因字寬不同而略有差異。
