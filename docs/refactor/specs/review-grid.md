# 劇本心得九宮格（review-grid）行為規格

## 0. 概要

把跑過（或帶過）的劇本排成一張「劇本心得」圖：最上面是自己的頭像、暱稱、帳號，下面每一格是一個劇本——劇本的圖片、規則（系統）、
劇本名稱、作者，以及最多 3 個「心得標籤」（例如「後勁超強」「強力推坑！」）。可以排成**九宮格**（一列 3 格、有圖片）或**清單**
（一列 2 格、不畫圖片、改畫每一格的感想），存成 PNG 分享。團員各自存成專案檔後，可以把好幾個人的檔案依劇本名稱排成一張**心得比較圖**。
全部在瀏覽器裡處理，不上傳。

輸入：個人資料與每一格的文字、圖片（選檔、拖放、貼上）、心得標籤的選擇與標籤清單；比較時是好幾個人的專案檔（或原作的資料備份）。
輸出：PNG（寬 900，預設 2 倍＝1800；高度依內容，見 3.1）；比較圖 PNG（寬 1000，2 倍＝2000）；新版另有專案檔（ZIP）。

靈感來源：sotsotssi/scenario-review「시나리오 후기 구절판」（<https://github.com/sotsotssi/scenario-review>；對照的原始碼是 commit
`280a550` 的 `index.html`、`script.js`、`style.css`，本機 `/home/user/upstream/sotsotssi_scenario-review/`）。原作**沒有授權條款（未授權）**：
只參考功能、數值與畫法，程式、介面文字、說明、心得標籤的文字、範例都自己寫（繁中），不放 `UPSTREAM_LICENSE`。
原作只有韓文介面、沒有語言切換、沒有分析碼；標題旁的作者 X 帳號連結與副標題不移植（頁尾只有靈感來源）。

用語：「原作」＝上述網站；「px」＝1 倍時的畫布 px（輸出 2 倍時全部乘 2）；「格子」＝原作的「항목」（一個劇本）；
「心得標籤」＝原作的「후기」（從固定的 20 句裡選，畫成小圓角方塊）；「感想」＝原作的「코멘트」；「規則」＝原作的「룰 이름」。

## 2. 輸入

- **圖片**：瀏覽器能解碼的圖片都可以（PNG、JPEG、WebP、GIF〔第一格〕、AVIF…）。長邊超過 1024 px 時先等比縮小（JPEG 存成 JPEG 品質 0.92，其他存 PNG）再存進
  IndexedDB；畫的時候才縮放（高品質）。不是圖片、讀不了：通知，其他照常。原作把原圖以 data URL 存在記憶體與備份裡（D19）。
- **文字**：暱稱 30、帳號 40、規則 20、劇本名稱 60、作者 30 字，單行（貼上的換行換成空白）；感想 500 字（保留換行）；標籤 20 字；
  都以字元計（emoji 算一個）。欄位旁顯示「字數／上限」。
- **數量**：格子 30、每格標籤 3、標籤清單 40（D6）。
- **原作的資料備份**：見 3.8。

### 3.9 對等驗證的比對方法

1. 用 Playwright 開原作（`file://`；html2canvas 從本機送出、Pretendard 字型擋掉，兩邊都用系統的黑體）。原作用「데이터 불러오기」讀一份測試資料（6 格、各種比例的純色圖、韓文標籤、有的格子沒有感想），
   依序在九宮格、清單、依原圖下「이미지로 저장」；新版用「開啟專案檔…」讀同一份檔，同樣三種排列下載 PNG。
2. 逐像素比對：寬度相同；差異只能出現在文字（字型、字距、行高的細微差別，D15）、圖片與圓角的反鋸齒；空白欄位、清單的標籤底色、依原圖的寬圖是刻意的差異（D2、D8、D9）。
3. 比較圖：同一份資料加上第二個人（改名、拿掉頭像、只留 3 格）的檔，原作「여러 명 비교하기」與新版各產生一張，並排目視。
4. 原作的檔：用原作的頁面填資料（頭像、圖片、標籤、感想）後「데이터 백업」存的 JSON（`web/tests/unit/fixtures/review-grid-original.json`），新版讀進來比對每一格。

## 4. 互動與手感

- 文字欄：打字即時畫到預覽上；單行欄位按 Enter 離開（套用）；從聚焦到離開算一步復原。字數上限之外的字不收。
- 預覽：寬畫面時以預覽欄的寬度縮放（卡片長的時候預覽欄自己捲動），窄畫面最高 75% 畫面高；工具列可以縮放、回到符合畫面。點格子選取；滑過的格子虛線框；
  選取中的格子淡色虛線框。
- 圖片：拖放到視窗任何地方時整個畫面出現「放開即可放進格子」；放開的位置在預覽的哪一格就從哪一格開始放。Ctrl＋V：有指著預覽的格子（或個人資料列）時放那裡，
  否則放選取的格子；焦點在文字欄而且剪貼簿有文字時照常貼上文字。
- 預設：9 格、九宮格、正方形、預設 20 個標籤、沒有個人資料、選取第 1 格、匯出 2×；「心得標籤清單」「比較多人的心得」兩區預設收合（記在瀏覽器）。

## 5. 容易做壞的地方

- **同一列等高**：格子的內容靠上，列高取最高的那一格；清單的灰底要撐到整列，不是各自的內容高。
- **空白的欄位不佔位置**：只有劇本名稱的格子，名稱下面不能留作者、標籤的空隙；三項都空時圖片框下面也不留 12。
- **陰影不受 canvas 縮放影響**：2 倍輸出時陰影的模糊與位移要自己乘 2。
- **依原圖的高度用圖片的原始寬高**（存在狀態裡），不用等圖片讀好才能排版；匯出列的大小在圖片還沒讀好時也正確。
- **標籤用文字存**：改標籤清單的字時，用到它的格子要一起改；同一格改完重複時只留一個；刪掉時格子裡一起拿掉。
- **原作的示範字**：原作每一格開頁就填好「룰 이름」等字，沒改過的備份裡就是這些字；讀進來（開啟、比較）時要當成空白，否則圖上會出現韓文的示範字。
- **貼上不能搶走文字欄的貼上**：剪貼簿同時有文字與圖片、焦點在文字欄時照常貼上文字。
- **比較的人數**：每個檔案是一個人，同一個人兩格同名時兩列；讀不了的檔不算人數。
