# 證件與票券產生器（id-ticket）行為規格

## 0. 概要

做跑團用的**證件與票券道具圖**（CoC 等現代背景的 handout）：員工證、學生證、記者證、刑警證、會員卡、1920 年代的偵探執照，
以及電影票、登機證、車票、收據。放上照片、填好欄位、自動產生編號，條碼（Code 128）與 QR code 跟著編號；證件有正反兩面，
可以匯出卡片（54 × 86 mm、圓角、透明底）或印刷用（含 2 mm 出血，58 × 90 mm）的 600 dpi PNG；票券匯出 PNG，或微微浮起、
一道光掃過的 GIF。全部在瀏覽器內處理，不上傳。

輸入：照片（選檔、拖放、貼上）、欄位文字、選項。輸出：PNG（證件寫入 600 dpi）、GIF（票券）；新版另有專案檔（ZIP）。

靈感來源（兩個原作合成一個工具，D1）：
- **ID Studio**：dearmysn1p3r/DearMySn1p3r_20（<https://dearmysn1p3r.github.io/DearMySn1p3r_20/>；對照的原始碼是 repo 的 `index.html`，
  `c08d489`，單檔 927 行；html2canvas 1.4.1、html-to-image 1.11.11、qrcodejs 1.0.0、Pretendard、Yellowtail 從 CDN 載入）。
- **Ticket Studio**：dearmysn1p3r/DearMySn1p3r_36（`index.html`，`5636d9d`，1063 行；html2canvas 1.4.1 從 CDN、gifenc 1.0.3 內嵌；
  Instrument Serif、Inter、JetBrains Mono、Big Shoulders Display、Pretendard）。頁尾的靈感來源只列 ID Studio（registry），
  Ticket Studio 由主控寫進 README／ATTRIBUTION。

兩個原作都**沒有授權檔（未授權）**：只參考功能、版面數值與做法；程式、介面文字（原作是韓文）、範本（欄位標籤、範例資料、機構名稱、
配色、圖樣、版面）都自己做（繁中），不放 `UPSTREAM_LICENSE`；原作的 `MOMO.png`（網站圖示）不用。範本裡的公司、學校、媒體、
警察單位、航空公司、鐵路公司、店家都是虛構的；不用真實的警徽、國徽、政府、公司標誌，樣式做成「看得出是什麼」的通用版（D2）。

用語：「原作」＝上述兩個網站（分開說時「ID Studio」「Ticket Studio」）；「設計單位」＝證件的座標（1 mm＝5.5 單位，
成品 297 × 473、四邊出血 11；同 ID Studio 的 work size）；「票券單位」＝票券的座標（CSS px，同 Ticket Studio）；
「墊紙」＝票四周的底色（Ticket Studio 的 stage：四邊 46、圓角 34）。

## 1. 功能清單（對等驗證以此為準）

原作：ID Studio 是左邊設定欄（範本按鈕、內容／樣式兩個分頁）＋右邊預覽（掛繩、翻面）＋右上「儲存」選單（卡片圖片／印刷用 × 三種輸出）；
Ticket Studio 是上方四個分頁（Movie、Boarding、Train、Receipt）＋中間的票（每個字都可以直接改）＋下方的配色列與「重新產生條碼」、
右上 PNG／GIF 兩個按鈕。新版用共用外框：設定欄最上面是「範本」（類別＋範本縮圖），下面兩個分頁「內容」「樣式」；預覽區是舞台
（證件另有正面／背面）＋共用的匯出區。

## 2. 輸入

- 照片：瀏覽器能解碼的圖片（PNG、JPEG、WebP、GIF〔第一格〕、AVIF…；沒有副檔名的看檔頭）；長邊超過 1600 px 時等比縮小再存進資產庫
  （600 dpi 的證件照片格約 500 × 650 px，1600 綽綽有餘）。拖放、選檔、貼上的當下就把檔案讀進記憶體（共用的 FileDrop／WindowDrop／pickFiles）。
  一次多個檔案：用第一張圖片，其他的與不是圖片的在同一則通知裡說明。目前的範本沒有照片格（兩款車票、關掉照片格的收據）時，拖放區停用、
  貼上或選檔時通知「這一款沒有照片格」。
- 文字：每個欄位的上限見 3.2、3.3（以字元計，emoji 算一個）；單行（換行換成空白）；下拉選單只接受選項或空白。
  收據品項：品名 16 字、數量 0～999（整數）、單價 0～9,999,999（小數 2 位）。票上的欄位名稱 12 字。
- 專案檔：見 3.6；讀入時整理（不認得的範本換成預設、顏色不是色碼用預設、文字截到上限、品項最多 12 項、位置夾回範圍）。

### 3.7 對等驗證的比對方法

1. 原作以本機伺服器開（port 8238；html2canvas、html-to-image、qrcodejs 從 npm 的套件檔案送；Google 字型、Pretendard 擋掉）。
2. 輸出：同樣的匯出選項比 PNG 的尺寸、pHYs、檔名；GIF 的尺寸、格數、每格延遲。範本、字型、配色、條碼（真的 Code 128）是刻意的差異，
   不比像素。
3. 行為：範本切換回到正面、欄位共用、重新產生的格式、清空、收據合計、翻面、掛繩只在預覽。
4. 新版的條碼以 Code 128 的規則解回文字（單元測試）、QR code 以模組矩陣比對 qrcode-generator 的輸出。

  匯出：證件「卡片」「目前這一面」；票券 PNG 2 倍、有墊紙、GIF 長邊 1400、無限循環。
- 文字欄從聚焦到離開算一步復原；滑桿放開才算一步；色彩欄從按下到放開算一步；其他每個動作（換範本、類別、重新產生、清空、填入範例、
  放入／拿掉照片、調整範圍、品項的新增／刪除、配色組合）各一步。分頁、顯示的面、掛繩、匯出設定不列入復原。
- 點預覽上的字：設定欄切到「內容」、欄位捲到中央、聚焦（文字欄全選）、外框閃一下（約 0.9 秒）。
- 翻面 0.75 秒；「減少動態效果」時沒有動畫。
- 預覽上滑過可以點的地方：虛線外框（主色）＋提示文字；鍵盤可以用 Tab 走到每一個（按鈕的名稱例「編輯「姓名」」「重新產生「員工編號」」）。

## 5. 容易做壞的地方

- **欄位共用**：證件的姓名等同一個代號在各款之間是同一個值（清空也一起清空）；票券每一款各自一份。
- **換範本回到正面**（證件）。
- **出血**：背景要畫滿到出血（印刷匯出才不會露白邊），字、照片放在安全範圍裡；卡片匯出要裁掉出血、圓角外透明。
- **600 dpi 的 pHYs**：每公尺 23622 像素、單位 1（公尺），放在 IHDR 後面；瀏覽器的 `toBlob` 不寫，要自己補。
- **排在一張**：中間 6 mm（142 px）；卡片是透明底、印刷是白底。
- **條碼**：真的 Code 128（拿掉空白；數字連續 4 個以上用 C 字集）；深色卡面要墊白底（反白掃不出來）；中文等不能編碼的字略過，
  什麼都不剩時預覽上畫虛線框。
- **QR code 的中文**：UTF-8；所有模組畫在同一條路徑一次填滿（相鄰模組之間不會有細縫）。
- **照片的位置與框的比例無關**：各款證件的照片格比例不同，畫的時候夾回蓋滿的範圍；縮放以框的中心縮放。
- **票的缺口、鋸齒外是透明的**：墊紙或棋盤格從那裡露出來（不是畫成墊紙色）。
- **GIF 的光只畫在票上**（source-atop），浮動的位移取整數像素（字才不會糊）；陰影的模糊與位移要乘倍率。
- **收據合計**：金額＝數量 × 單價；折扣一律當減項（−｜折扣｜）；千分位。
- **欄位空白時的淡色名稱只在預覽**，匯出不畫。
