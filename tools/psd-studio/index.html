本工具是（@Hamurabi_F）為了自己作業方便而製作的非官方網頁工具，
開發過程中有一部分使用了 vibe coding（由 AI 協助寫程式）。

放進來的 ZIP、PSD 和圖片檔案不會傳送到外部伺服器，
只會在使用者的瀏覽器（裝置）裡安全地處理。

禁止擅自轉售程式碼本身，或收費散布。
不過，為個人目的修改程式碼、改良功能，以及以此為基礎再散布，都可以自由進行。

關於預覽畫面：
為了盡量避免瀏覽器卡頓，
檢視畫面裡的圖片會以比實際低的畫質算繪。

關於 APNG 預覽：
預覽播放時影格可能會閃爍或看起來有點破圖，這是為了減輕畫面算繪的負擔，實際儲存的最終檔案完全沒有問題，請放心下載。

關於解壓縮 zip：
使用 Windows 內建的解壓縮功能時可能會出錯。
要確認檔案是否正常，建議使用 Bandizip、ALZip 等壓縮軟體。

關於把 APNG 上傳到 CCFOLIA 時跳出的警告：
這是因為修改圖片時改動了 json 檔案，請直接按確認。
如果出現 faild 警告、地圖設定也沒有套用，請重新下載檔案再試一次，
還是不行的話，請回報錯誤！

關於功能建議：
不經過 CCFOLIA、自行產生／製作地圖的功能，可能侵害 CCFOLIA 官方服務的政策與付費範圍，因此不接受這類建議，敬請見諒。
其他功能建議和錯誤回報隨時歡迎！

原始程式碼：fyam-hamu/F_Ccfolia-PSD-Studio

1. 載入檔案與多種格式辨識
- 可以自由載入 CCFOLIA 備份 ZIP（含 data.json）、Photoshop PSD 圖層、一般圖片（PNG／JPG／APNG 等）和資料夾。

2. 整體與個別素材的色彩調整
- 調整色相（Hue）、飽和度（Sat）、亮度（Bri）、對比（Con）、曝光（Exp）
- Photoshop 風格的漸層對應與 RGB 色調曲線編輯
- 可儲存自訂調色預設集，並支援個別素材專用的調整偏移

3. CCFOLIA 房間與 PSD 圖層配置檢視器
- 以 2D 畫布即時算繪 Z-Index 與圖層配置
- 提供圖層堆疊面板，方便確認圖片。

4. APNG／靜態圖片容量自動壓縮
- 自動分階段壓縮到 CCFOLIA 上傳上限（4.8MB）以下，減少畫質損失。
- 如果改過 APNG 動畫的循環／重複播放次數設定，儲存時請另外確認。

5. 24px 補齊留白與 CCFOLIA ZIP 匯出
- 依 CCFOLIA 格線倍數（24px）批次補齊畫布留白
- 修改圖片後自動同步 data.json 並打包成 ZIP，可以直接拿到 CCFOLIA 使用。
