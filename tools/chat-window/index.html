聊天視窗產生器

製作「自訂 CSS」，把 CCFOLIA 的骰子結果與秘匿聊天以喜歡的樣式顯示在 OBS 上。右邊的預覽可以一邊送訊息一邊確認。所有處理都在瀏覽器內完成，輸入的內容不會傳送到任何地方。這是依據讀者許願做出來的工具。

設計範本

要顯示的訊息

從最新的往回數，只顯示這麼多則。視窗裝不下的舊訊息會在邊緣切掉。系統訊息是改動 HP 或 SAN 時（例如 :HP-2）CCFOLIA 自動送出的「[ 角色名 ] HP : 12 → 10」這類通知。要顯示哪個分頁是在 OBS 裡選（見「OBS 與儲存」分頁）。

瀏覽器來源大小

OBS 瀏覽器來源要填的寬與高。視窗會放在這個範圍裡。

視窗

選「配合內容大小」時，訊息少視窗就跟著變小，並從靠齊的那一側往外延伸。

標題

會直接顯示 OBS 上開著的分頁名稱（「メイン」或秘匿分頁的名稱）。可用預覽上的「顯示分頁」切換確認。

秘匿分頁的參加者

CCFOLIA 只有在開著指定參加者的秘匿分頁時，才會顯示該分頁參加者的頭像（主分頁等不會顯示）。頭像不是角色圖，而是使用者的個人檔案圖片。間隔設成負值會互相重疊。對齊方式與文字顏色、字型都跟標題共用。

單則訊息的方框

選「依骰子成敗上色」時，會用結果的顏色（在「文字與結果」分頁設定）畫線。不是骰子的訊息則用「線條顏色」（需 OBS 31 以上）。

頭像
名稱

「角色顏色」指的是在 CCFOLIA 發言時名稱所用的顏色。

內文

把「長訊息」設為 1 以上時，超過該行數的訊息會以「…」截斷。描邊也會套用到名稱與骰子結果。

骰子結果

選「以名稱指定（電腦字型）」時，可以使用這台電腦上安裝的字型。跑 OBS 的那台電腦也必須裝有同一套字型。

成功 失敗 其他

分色方式與 CCFOLIA 一致。成功包含「成功」「スペシャル」等，失敗包含「失敗」以及別人的秘密骰。沒有成敗的擲骰（例如 2D6）算其他。大成功與大失敗分別套用成功、失敗的顏色。

訊息送達時
過一段時間後消失

適合像骰子快報那樣，只在擲骰當下顯示的用法。消失的訊息騰出的位置，其他訊息會遞補上來。
在 OBS 重新載入來源時，已經消失的訊息會先出現一次再消失。
預覽在每次改動設定時都會從頭重播動態，所以全部消失之後，請用右邊的按鈕再送一則訊息。

確認方式

按右邊「送訊息來確認」的按鈕，預覽就會收到新訊息。可以確認動態，以及超過則數時的遞補效果。

房間

貼上在 CCFOLIA 開啟房間時的網址，就會產生要填進 OBS 的聊天畫面網址（結尾是 /chat）。它也會寫進匯出 CSS 的開頭。

OBS 的「互動」

開啟後，在 OBS 對來源按右鍵 →「互動」，只有把滑鼠移到視窗上時才會出現 CCFOLIA 的分頁。要顯示秘匿分頁時，就在這裡選分頁。實況畫面上不會出現。

專案

編輯內容會自動存在這個瀏覽器裡。要做好幾份（例如骰子用與秘匿聊天用）時，用「儲存專案」分開存比較方便。

送訊息來確認（只影響預覽，不會寫進匯出的 CSS）

OBS 瀏覽器來源要填的網址（結尾是 /chat 的聊天畫面，不是房間網址）

把房間網址直接填進 OBS，整個房間的畫面（背景與棋子）都會被映出來。填入房間網址後，這裡就會產生給 OBS 用的網址。

OBS 的設定

  1. 新增來源 →「瀏覽器」。網址填聊天畫面的網址：
    https://ccfolia.com/rooms/{房間ID}/chat
  2. 寬與高填上面顯示的 瀏覽器來源大小。
  3. 把「自訂 CSS」的內容全部清空，貼上複製好的 CSS。
  4. 如果什麼都沒顯示，或是要顯示秘匿分頁，就必須先登入 CCFOLIA。先把網址改成 https://ccfolia.com/，對來源按右鍵 →「互動」登入之後，再把網址改回來（做過一次就會記住）。
  5. 主分頁以外的分頁，要開啟「互動」並把滑鼠移到視窗上，再從出現的分頁裡選。分頁的選擇不會被保存，所以重新啟動 OBS 後要再選一次。

同時顯示骰子用與秘匿聊天用時

  • 瀏覽器來源受 OBS 的限制無法複製（右鍵的「貼上複本」一直是灰的）。請用「新增來源」→「瀏覽器」另外建第二個，填入同一個聊天畫面的網址，再各自貼上這個工具做好的 CSS。只有秘匿聊天那一份要用「互動」選秘匿分頁。
  • 登入狀態是所有瀏覽器來源共用的，第二個不必重新登入。大小與位置可以用右鍵 →「複製變換」→ 在另一個上「貼上變換」對齊。
  • 秘匿分頁只有用該分頁的參加帳號（例如 GM）登入時才看得到。
  • 若在瀏覽器來源的設定裡開啟「不顯示時關閉來源」「場景啟用時重新整理瀏覽器」，每次切換場景分頁都會退回主分頁。

關於這個工具

這個工具源自讀者的許願：「想要一邊預覽一邊自訂骰子視窗與秘匿聊天」。「希望有這樣的工具」「這裡不好用」之類的意見，也歡迎透過 Marshmallow 告訴作者。

只靠瀏覽器就能運作的免費工具。做出來的 CSS 可以自由使用。
CCFOLIA 的畫面結構若有變動，顯示可能會跑版。這是與任何服務都沒有關係的非官方工具。
