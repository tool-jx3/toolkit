CCFOLIA 日誌轉換器

要不要來點餃子？

使用說明

基本流程

  1. 選擇從 CCFOLIA 下載的日誌檔。
  2. 選擇輸出樣式。
  3. 按下開始轉換，下方會出現預覽與下載按鈕。
  4. 用下載 HTML儲存成品。

輸出樣式

  • 小說 — 把台詞和敘述像文章一樣接起來。
  • 時間軸 — 附上頭像，依時間順序排列。
  • CCFOLIA 風格 — 做成接近 CCFOLIA 畫面的樣子。

詳細設定

選好日誌檔後，下方會出現四個分頁。

  • 基本 — 標題、指定旁白角色、旁白的顯示方式、指定閒聊分頁、副旁白
  • 外觀 — 頭像圖片、角色名稱顏色、字型與版面
  • 插圖 — 在日誌中間插入圖片
  • 進階 — 閒聊與系統訊息的顯示方式、分頁名稱與顏色、分割檔案、設定檔、轉成網頁貼文用

小提醒

  • 日誌很多時，預覽只會畫出其中一段。可以在預覽下方的預覽範圍移動區段或顯示全部。下載的檔案一定包含全部內容。
  • 插圖的位置用預覽裡顯示的日誌編號來指定。這些編號不會出現在下載的檔案裡。
  • 成品太大時，可以用進階 → 檔案分割選項分成多個檔案儲存。
  • 要直接貼進部落格內文時，請用進階 → 轉成網頁貼文用。有些部落格面板可能無法完整套用樣式。
  • 設定會自動儲存在瀏覽器裡。想恢復原狀請按進階 → 重設設定。
  • 建議使用最新的桌面版瀏覽器（Chrome、Edge、Firefox）。

開始

  1. 選擇從 CCFOLIA 下載的日誌檔。舊格式（只有文字的 HTML）和新格式（連頭像資訊都包含的 HTML）都支援。
  2. 新格式是每個分頁各一個檔案。全部一起選的話，分頁名稱會自動填好。
  3. 選了多個檔案之後，也可以刪掉或加入部分檔案。
  4. 編輯中用不到的分頁，也可以在進階 → 選擇要顯示的分頁排除。

字型使用說明
1. Google Fonts
  1. 前往 fonts.google.com
  2. 搜尋想用的字型（例：Noto Serif TC）
  3. 點「Get font」→「Get embed code」
  4. 在 <link> 分頁複製 href 網址
  5. 字型網址： https://fonts.googleapis.com/css2?family=...
  6. 字型名稱： 'Noto Serif TC'（含單引號）
2. noonnu（noonnu.cc，韓文字型網站）
  1. 前往 noonnu.cc
  2. 選好字型 → 找到「當作網頁字型使用」的區塊
  3. 從 @import url('...') 只複製 url() 裡的網址
  4. 字型名稱：複製 font-family: 後面的名稱（含單引號）

注意 字型名稱一定要用單引號（''）括起來
