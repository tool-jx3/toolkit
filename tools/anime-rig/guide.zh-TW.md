# Anime2.5DRig

這是一款 2.5D 虛擬形象工具：只要把分好部件的 PSD 拖放進瀏覽器，就會自動綁定並動起來。
以往需要手動完成的設定工作（切分網格、變形、物理設定）全部自動化。免安裝，所有處理都在瀏覽器端完成。

原作是 hakoniwa 的 [Anime2.5DRig](https://github.com/852wa/Anime2.5DRig)（MIT）。這個頁面是收錄在 TRPG Toolkit 的版本，說明以原作的 README 為基礎，並配合收錄版改寫（未收錄範例 PSD、OBS 用的本機伺服器與開發用測試）。

## 使用說明

1. 把分好部件的 PSD 拖放到預覽區，或按「選擇 PSD 檔案」開啟。
2. 自動綁定隨即執行，模型當場就會帶著待機動作、眨眼、嘴型與頭髮物理動起來。
3. 在右側面板調整表情、眼睛、嘴巴、頭髮與身體的動作，再匯出成 PNG 或影片。

## 編輯與儲存

- 隨時可以從上方的「開啟 PSD」（Ctrl+O）更換模型。讀取中會顯示進度，按「中止讀取」即可取消。即使新的 PSD 讀取失敗，編輯中的模型也會保留。
- 用「搜尋設定」篩選眼睛、頭髮、嘴巴等設定，只會顯示符合的項目。區塊標題可以用點擊、Enter 或 Space 展開／收合，展開狀態會被記住。
- 滑桿右邊的數值可以直接輸入。在滑桿上按兩下，只有該項目會還原成初始值。
- 變更可以用「↶ / ↷」或 Ctrl+Z / Ctrl+Shift+Z 復原與重做（參數、表情、圖層、錨點、背景）。
- 在「圖層」可以調整顯示／隱藏、濃度（不透明度）、深度與繪製順序。列表越上面越靠後，越下面越靠前。拖曳縮圖或按 ↑↓ 可以重新排序，按 ▸ 展開濃度與深度。滑鼠移到卡片上時，預覽會標示出該部件的範圍。深度影響轉頭時的移動量，和繪製順序是分開的設定。
- 「儲存調整」（Ctrl+S）會依模型分別把參數、自動動作、背景、圖層設定與錨點儲存在瀏覽器裡。有未儲存的變更時，按鈕上會出現「●」，關閉頁面前也會先確認。讀取內容相同的 PSD 時會自動還原。按「還原成已儲存的狀態」可以回到上一次儲存的狀態。
- 要搬到其他瀏覽器或電腦時，請使用「匯出設定 JSON」。開啟同一個 PSD 後按「讀取設定 JSON」，或把 JSON 拖放到預覽區，即可套用。也能讀取舊版（v1）的設定 JSON。設定 JSON 不包含 PSD 的圖像本身，也不包含攝影機與麥克風的開啟狀態。PSD 重新編輯過的話，會被當成另一個模型。
- 按「暫停」（Space）可以停住動作，方便調整數值。
- 「儲存輕量 PSD」會儲存去除雜點並裁切過的 PSD。動作、繪製順序、深度等調整請存成設定 JSON。
- 套用表情預設時，不會被自動眨眼與隨機嘴型蓋掉。使用攝影機輸入時，也會優先採用追蹤值，而不是自動眨眼與隨機嘴型。
- 「模型資訊與診斷」會列出必要的圖層是否找到、是否為自動產生，以及有沒有未分類的圖層。

## 鍵盤與滑鼠操作

| 操作 | 功能 |
|---|---|
| `Space` | 暫停／播放 |
| `1`～`7` | 表情預設（一般、笑臉、瞇眼、驚訝、鄙視眼、左眼眨眼、右眼眨眼）。再按一次同一個鍵即可解除 |
| `0` | 解除表情預設 |
| `Ctrl+Z` / `Ctrl+Shift+Z`（`Ctrl+Y`） | 復原／重做 |
| `Ctrl+S` / `Ctrl+O` | 儲存調整／開啟 PSD |
| `E` | 錨點編輯模式（按 `Esc` 結束） |
| `F`、按兩下 | 讓預覽回到顯示全圖 |
| `B` | 切換背景 |
| 滾輪、雙指開合／拖曳 | 放大、縮小預覽／移動預覽 |
| `?` | 快捷鍵列表 |

## 編輯錨點

眼睛、嘴巴、脖子的位置會自動偵測，但依畫風不同，有時會有偏差。按下「編輯錨點」（`E`），就會在靜止的姿勢上顯示基準點。

- **臉部中心**：轉頭時的深度與瀏海區塊交界的基準
- **左眼、右眼**：瞳孔縮放與視線移動的中心
- **閉眼位置**（藍色）：眼皮閉上的高度。拖曳時會讓該眼閉上以便預覽
- **嘴巴**：嘴巴開合、縮放與閉嘴差分旋轉的中心
- **脖子旋轉軸**：頭部轉動的支點
- **胸部**（紫色）：胸部晃動的中心（有上身服裝圖層時）

直接拖曳，或選取點之後用方向鍵（1px）／Shift+方向鍵（10px）移動。錨點調整也會納入設定儲存、JSON 與復原。按「還原成自動偵測的位置」即可重設。

## 攝影機與麥克風

- 開啟「攝影機追蹤」後，會追蹤頭部方向、眨眼、視線、嘴巴開合、眉毛與笑臉（嘴形）。左上角會顯示小小的攝影機畫面與偵測點（取消「顯示攝影機小畫面」即可關閉）。
- **記錄正面（校正）**：請在攝影機追蹤時面向正前方，以自然的表情按下。之後會以這張臉為基準來判斷，因此即使眼睛偏細、嘴角偏上揚等個人差異，也比較不會誤判。記錄會儲存在這個瀏覽器裡。
- 關閉「左右眼同步眨眼」就能偵測單眼眨眼。眉毛與笑臉的追蹤可以個別關閉。
- 可以調整頭部、眨眼、嘴巴、眉毛、視線的靈敏度，以及動作的平滑度（抑制抖動的強度）。
- 「麥克風嘴型」可以調整靈敏度與噪音閘門（忽略低於此值的小聲音），輸入音量會顯示在音量表上。
- 臉部追蹤使用 MediaPipe FaceMesh（Apache-2.0）。收錄版會從 jsDelivr 的 CDN 讀取固定版本，所以第一次開啟攝影機追蹤時需要連上網路。攝影機畫面本身不會傳送到外部。

> 攝影機追蹤與麥克風嘴型只能在 https 或 localhost 下運作（瀏覽器的權限規範）。

## 匯出

- 「儲存 PNG」會以原始 PSD 尺寸匯出目前的姿勢，不包含操作介面。
- 「錄影」會匯出原始 PSD 尺寸的影片。長度（3～60 秒）、影格率（30/60 fps）與格式可以在「匯出」區選擇。錄影中再按一次，就會儲存到目前為止的內容。
- 背景可以從「透明・綠幕・深色」中選擇，PNG 與影片都會套用。能保留透明的是 WebM（Chrome / Edge / Firefox），MP4 不支援透明。

## 關於 OBS 連動

原作有一項功能，可以把編輯畫面中開啟的 PSD、調整、表情與臉部追蹤自動同步到 OBS 的瀏覽器來源。這需要在自己的電腦上啟動原作發布套件中附帶的本機伺服器（`start_obs.bat` / `obs_server.py`，需要 Python 3），而 TRPG Toolkit 的網頁版並未收錄。想在 OBS 中使用的話，請從 [原作的 GitHub](https://github.com/852wa/Anime2.5DRig) 下載整套套件，並依照原作 README 的步驟操作。

只用網頁版也可以：把背景設成綠幕，用 OBS 的視窗擷取來擷取畫面，或是匯出透明的 WebM 來使用。

## 自動處理項目

- 直接接受 [see-through](https://github.com/shitagaki-lab/see-through) 輸出的 PSD（`mouth`→`mouth_open` 自動改名；`hair` 的繪製順序在臉上層時視為瀏海，在下層時視為後髮）
- **自動辨識日文與英文別名**（`前髪`、`白目`、`瞳`、`まつ毛`、`閉じ目`、`bangs`、`iris` 等，見下表）
- **缺少閉眼、閉嘴差分時，自動產生通用差分**（依錨點縮放與擺放，並自動配合睫毛／嘴巴的顏色；可用專用滑桿微調位置與角度）
- 去除低 alpha 值的雜點（連通區域過濾）
- 遞迴讀取可見的圖像圖層（包含資料夾內的圖層）
- 眼睛、眉毛、睫毛、閉眼的**左右自動分離**（依連通區域的重心判斷）
- 眼皮位置、虹膜中心、嘴巴、脖子支點等**錨點自動偵測**（可在錨點編輯模式中修正）
- 頭髮的**髮束（strand）自動偵測**（偵測髮梢輪廓的峰值，每個圖層最多 6 束）
- 耳飾與尾巴的**鐘擺式擺動**
- 依圖層分配深度，實現**擬 3D 轉頭**（視差＋剪切變形）
- 每一束頭髮各自的雙重彈簧物理（**髮根較硬、髮梢輕飄飄**）、跟隨身體傾斜、胸部晃動、呼吸
- 閉眼／閉嘴差分的**交叉淡化**、瞳孔裁切（依眼白的形狀平滑裁切，不受繪製順序、眼白濃度或顯示狀態影響）

另外加入名為 `eyeclose2`（或 `eye_close2`、`閉じ目2`）的閉眼圖層後，會以 4:1 的機率和一般閉眼交替使用。`eyeclose2` 的閉眼時間是一般眨眼的 10 倍。

## 圖層命名規則

本工具只辨識英文與日文的圖層名稱（見下表），中文名稱（例如「瀏海」、「眼白」）無法辨識，建議直接使用英文名稱。

圖層名稱（日文的「のコピー」與「copy」、全形字元、大小寫，以及 `_`、`-`、空白的差異都會自動正規化）：

| 圖層名稱 | 別名範例 | 內容 | 必備 | 備註 |
|---|---|---|---|---|
| `face` | 顔、輪郭 | 臉部底圖（臉、輪廓） | ◎ | 錨點的基準，唯一一定要有的圖層 |
| `eyewhite` | 白目 | 眼白（左右兩眼） | ○ | 左右自動分離；也是裁切瞳孔用的形狀 |
| `irides` | 瞳、黒目、iris | 虹膜（左右兩眼） | ○ | 用於視線移動與瞳孔縮放 |
| `eyelash` | まつ毛、アイライン | 睫毛（睜眼，含眼線） | ○ | |
| `eye_close` | 閉じ目 | 閉眼 | ○ | 眨眼時交叉淡化 |
| `eye_close2` / `eyeclose2` | 閉じ目2 | 長閉眼 | | 以 20% 的機率使用，閉眼時間 10 倍 |
| `eyebrow` | 眉、眉毛 | 眉毛（左右兩邊） | ○ | 可調整角度與上下位置 |
| `mouth_open` | 口、開き口、mouth | 張嘴 | ○ | 張得越開，下巴越往下 |
| `mouth_close` | 閉じ口 | 閉嘴 | ○ | |
| `nose` | 鼻 | 鼻子 | | |
| `ears` | 耳 | 耳朵 | | |
| `earwear` | ピアス、イヤリング | 耳飾（耳針、耳環） | | 鐘擺式擺動 |
| `eyewear` | 眼鏡、メガネ | 眼鏡 | | 跟隨頭部 |
| `facedetail` | 頬、頬染め、blush | 臉部細節（臉頰、腮紅） | | |
| `neck` | 首 | 脖子 | | 上端跟隨頭部 |
| `neckwear` | ネクタイ、チョーカー | 領口配件（領帶、頸鍊） | | |
| `topwear` | 服、体、上半身 | 上身服裝（衣服、身體） | | 套用呼吸與胸部晃動 |
| `bottomwear` | スカート、ズボン | 下身服裝（裙子、褲子） | | |
| `handwear` | 腕、手 | 手臂與手 | | 可調整手臂高度 |
| `legwear` / `footwear` | 脚、靴下 / 靴 | 腿、襪子／鞋子 | | |
| `headwear` | 帽子、髪飾り、カチューシャ | 頭飾（帽子、髮飾、髮箍） | | |
| `front hair` | 前髪、bangs | 瀏海 | | 髮束物理，可分 3 區塊調整 |
| `side hair` | 横髪、もみあげ | 側髮（含鬢角） | | 與瀏海共用擺動設定 |
| `ahoge` | アホ毛 | 呆毛 | | 與瀏海共用擺動設定 |
| `back hair` | 後ろ髪、後髪 | 後髮 | | 髮束物理 |
| `hair` | 髪 | 頭髮（未指定前後） | | 在臉的上層視為瀏海，下層視為後髮 |
| `tail` / `wings` | 尻尾 / 羽、翼 | 尾巴／翅膀 | | 尾巴會擺動 |

- **把頭髮分成多個圖層時**：像 `front hair_1`、`front hair_2`、`前髪2`… 這樣加上流水號，每個圖層都會作為獨立的髮束群組進行物理運算（髮束數依圖層寬度自動決定）。
- 不符合命名規則的圖層也會讀取（依位置推測屬於頭部或身體，只做跟隨）。這些圖層會在「模型資訊與診斷」中顯示為未分類。
- 也支援圖層群組（資料夾）內的圖像圖層。隱藏的資料夾與圖層不會讀取。
- **關於脖子（neck）與身體（topwear）**：直接使用 see-through 的輸出時，脖子與身體的前後關係很難處理，動起來時交界處可能會破圖。效果不好時，改成把脖子合併到身體圖層的**一體式**（不使用 neck 圖層，topwear 一直畫到脖子），會比較容易成功。
- 建議使用正方形畫布（已在 768×768～2048×2048 確認可正常運作）。

## 功能

表情預設（笑臉／驚訝／鄙視眼／左右眼眨眼，可用按鍵切換）、左右獨立的睜眼程度、眉毛角度（左右獨立＋對稱）、視線、瞳孔縮放、眼睛／嘴巴的「閉合難易度」門檻、瀏海 3 區塊調整與**瀏海專用的擺動、柔軟度**、手臂高度／位置、胸部晃動（可調整強度與位置）、小物擺動、身體傾斜、待機／隨機動作、隨機嘴型、麥克風嘴型（靈敏度、噪音閘門）、滑鼠追蹤、**網路攝影機追蹤**（頭部 XYZ、左右眨眼、嘴巴、眉毛、笑臉、視線、校正）、編輯錨點、復原／重做、匯出透明 PNG 與透明影片、切換背景（透明／綠幕／深色）。

執行環境為 WebGL1（網格變形＋瞳孔用的遮罩紋理）。PSD 在瀏覽器內處理，不會上傳到外部伺服器。

## 已知限制

- 本工具不會拆解單張插圖。請先用 [see-through 官方示範（HuggingFace Space）](https://huggingface.co/spaces/24yearsold/see-through-demo) 等工具分割成 PSD，再拖放進來（後續處理全自動）
- 嘴巴開合是以切換差分＋變形的簡易方式呈現（中間差分越多越流暢）
- 初始深度依圖層名稱決定，但讀取後可以逐一調整各圖層。
- 支援 RGB、每色版 8 bit、128 MB 以下、2400 萬像素以下、單邊 16384 px 以下的 PSD。此外，可讀取的大小還會受圖層總像素數、解析用記憶體與裝置 GPU 上限的限制。
- 會反映資料夾的顯示／隱藏狀態，但不會完整重現群組合成、群組不透明度的繼承、特殊混合模式、調整圖層與遮色片效果。需要的效果請先合併到圖像部件中。
- 設定儲存使用瀏覽器的本機儲存空間。若因無痕模式或容量限制等原因無法儲存，請改為匯出 JSON。
- 透明影片僅支援 WebM。在 Safari 等無法匯出透明 WebM 的瀏覽器中，請加上背景色再匯出。
- 臉部追蹤的準確度會受照明、攝影機、眼鏡等因素影響。判斷不準時，請試試「記錄正面」並調整靈敏度。
