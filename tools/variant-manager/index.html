使用方式

  1. 把圖片拖放進來，或點一下選擇多張圖片。
  2. 輸入主檔名，再編輯每張縮圖旁的差分名稱。
  3. 需要時打開「加上編號」，檔名就會變成 主檔名01_差分名.png 的格式。
  4. 按「以 ZIP 下載圖片」可以把整組圖片存下來。
  5. 按「複製 @差分聊天面板」，可以複製切換差分用的聊天面板，貼到 CCFOLIA 等地方使用。
