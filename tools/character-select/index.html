選擇檔案格式

正在計算輸出尺寸與影格數。

準備中0%

AVI 與 MP4 會照設定的 FPS 逐格存下所有影格。透明的地方會存成黑色；MP4 只能在支援的 Chrome、Edge 上使用。

GIF 會依場景挑選顏色並加上抖色，減少色塊斷層。最高 50FPS，半透明的表現有限。想原樣保留顏色與半透明的話請選 APNG。

圖片與專案都在這個瀏覽器裡處理。想用原始解析度輸出的話，尺寸請選 100%。
