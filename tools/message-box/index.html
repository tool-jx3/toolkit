訊息框產生器

製作「自訂 CSS」，把在 CCFOLIA 發言時出現在房間畫面下方、附立繪的訊息框，以喜歡的樣式顯示在 OBS 上。房間的盤面與棋子會消失，只映出訊息框。所有處理都在瀏覽器內完成，輸入的內容不會傳送到任何地方。這是依據讀者許願做出來的工具。

設計範本

瀏覽器來源大小

OBS 瀏覽器來源要填的寬與高。立繪會超出方框的上緣，所以高度也要把立繪的部分算進去。寬度小於 900 時，CCFOLIA 會把立繪與骰子縮小，因此這個工具會重新指定它們的大小。

位置

方框寬度指的是最大寬度。來源比較窄時，會保留左右留白並跟著縮小。

方框

內文高度指的是能放進幾行內文（以內文的字級計算）。比這更長的發言，CCFOLIA 每打出 1 個字就會往下捲，所以能一直讀到最後一行。
按鈕指的是略過（▶）與關閉（×）。選「滑鼠移上去時才顯示」的話，實況畫面上不會出現，只能從 OBS 的「互動」按。

名稱

名牌會稍微疊在方框的上緣。用「名牌往上移」可以減少重疊，再往上移，名牌與方框之間就會空出間隔。「與內文的間距」是名牌與內文第 1 行之間的空隙。

訊息框裡的名稱沒有角色顏色的資訊（和聊天欄不同，CCFOLIA 沒有替它上色），所以名稱只有 1 種顏色。選「在方框上方加名牌」時，骰子結果也會排在名牌旁邊。

骰子結果
成功 失敗 其他

分色方式與 CCFOLIA 一致。成功是含有「成功」「スペシャル」的結果，失敗是含有「失敗」的結果（大失敗也算），沒有成敗的擲骰（例如 2D6）算其他。

CCFOLIA 放進訊息框的，只有骰子結果最後「＞ …」那一段（CCB<=50 是「＞ 成功」，2D6 是「＞ 9」）。擲出的點數（例如 23）不在訊息框裡，所以 CSS 也顯示不出來。目標值會以內文的指令（CCB<=50）出現。
想連點數一起顯示時，請搭配聊天視窗產生器使用（見下方「想連點數一起顯示時」）。

內文

描邊也會套用到放在方框裡的名稱與骰子結果。

選「以名稱指定（電腦字型）」時，可以使用這台電腦上安裝的字型。跑 OBS 的那台電腦也必須裝有同一套字型。

無法更改的部分

打字的速度（每個字 0.08 秒，標點與換行之後 0.8 秒）、到下一則發言之前的間隔（打完之後 1.2 秒）、要顯示哪些發言（主分頁與情報分頁裡，開啟頁面之後的發言），都是由 CCFOLIA 的程式決定的，CSS 無法更改。

立繪

立繪會站在方框上方。調高「與方框重疊」，腳邊就會沉到方框後面（或前面）。縱長的立繪可以用「高度上限」縮小。
角色設定裡開了「發言時不顯示角色」時，或是沒有立繪的角色（例如 KP）發言時，不會顯示。在 CCFOLIA 像「…@笑容」這樣發言，就能切換差分。

骰子圖片

會一邊旋轉一邊出現在方框的右上方（立繪在右側時則是左上方）。
只有在 CCFOLIA 的房間設定開啟「使用舊版骰子演出」時才會出現。關閉時（預設值）3D 骰子會在盤面上滾動，但盤面整個被隱藏了，所以不會映在 OBS 上。秘密骰不會出現。

房間

貼上在 CCFOLIA 開啟房間時的網址。它也會寫進匯出 CSS 的開頭。

專案

編輯內容會自動存在這個瀏覽器裡。每個團想用不同設計時，用「儲存專案」分開存比較方便。

發言來確認（只影響預覽，不會寫進匯出的 CSS）

OBS 的設定

  1. 新增來源 →「瀏覽器」。網址填房間網址：
    https://ccfolia.com/rooms/{房間ID}
    和聊天視窗產生器不同，結尾不加 /chat。
  2. 寬與高填上面顯示的 瀏覽器來源大小。
  3. 把「自訂 CSS」的內容全部清空，貼上複製好的 CSS。房間的盤面與棋子消失、畫面上什麼都沒映出來，就代表成功了。
  4. 開啟「透過 OBS 控制音訊」，再到音訊混音器把這個來源設為靜音。沒開的話，房間的 BGM 與骰子音效會從電腦重複播出兩次。
  5. 必須先登入 CCFOLIA。先把網址改成 https://ccfolia.com/，對來源按右鍵 →「互動」登入之後，再把網址改回來（做過一次就會記住，其他瀏覽器來源也共用）。

顯示的方式

  • 會顯示的是來源載入之後、主分頁與情報分頁裡的發言。剛啟動 OBS 或剛重新載入來源時，在下一則發言之前什麼都不會顯示。
  • 連續發言時會 1 則 1 則依序顯示。最後一則發言會一直留著，不會消失。
  • 想讓它消失時，在 OBS 對來源按右鍵 → 開啟「互動」，把滑鼠移到訊息框上，按下出現的「關閉」（×）（「方框與位置」分頁的「按鈕」設為「滑鼠移上去時才顯示」時）。在自己的 CCFOLIA 畫面上關閉，OBS 那邊並不會跟著關閉（有沒有關閉，是每個瀏覽器各自記住的）。在來源的屬性裡按「重新整理目前頁面的快取」也能讓它消失。
  • 如果在房間設定裡把訊息框隱藏了（例如在聊天輸入 hide mb），OBS 上也不會出現。
  • 給別人的密語不會顯示（給目前登入帳號的密語會顯示）。
  • 要在方框上方顯示骰子圖片，請在房間設定開啟「使用舊版骰子演出」。關閉時的 3D 骰子會跟盤面一起消失。

想連點數一起顯示時（搭配聊天視窗產生器）

訊息框只會出現「＞ 成功」這樣的最後一段，但聊天欄會像 (1D100<=50) ＞ 23 ＞ 成功 這樣全部顯示。建議台詞從訊息框、骰子結果從聊天欄，分開來顯示。

  1. 在聊天視窗產生器選範本「骰子快報（單則放大）」。它只把最新一則骰子放大顯示，10 秒後消失。顏色與字型可以用跟這個工具相同的方式挑選、互相搭配。
  2. 在 OBS 再新增 1 個瀏覽器來源，網址填結尾是 /chat 的聊天畫面（https://ccfolia.com/rooms/{房間ID}/chat），貼上聊天視窗產生器的 CSS。登入是共用的，不必重新登入。
  3. 把骰子視窗放在訊息框的上方或旁邊（沒有立繪的那一側）。

顯示不正常時

  • 什麼都沒顯示 → 請確認重新載入來源之後有沒有人發言，以及是否已經登入。把 CSS 清掉的話，應該會看到房間畫面。
  • 映出的是進入房間前的畫面或登入畫面 → 請依步驟 5 登入。
  • 立繪上方被切掉 → 請調高瀏覽器來源的高度，或調低「立繪與骰子」分頁的「高度上限」。

使用電腦上安裝的字型時

  • 在字型欄選「以名稱指定（電腦字型）」，再填入字型名稱。在 Chrome / Edge 可以按「從清單選」，看著外觀挑選電腦上安裝的字型（第一次會詢問是否允許使用字型）。
  • OBS 是用它所在那台電腦的字型來顯示，所以跑 OBS 的電腦也要安裝同一套字型。沒有安裝的話，會顯示成一般的黑體。

關於這個工具

這個工具源自讀者在 Marshmallow 的許願：「希望主畫面的對話框也能自由設計」。要顯示骰子結果或秘匿聊天的話，也歡迎使用姊妹工具聊天視窗產生器。「希望有這樣的工具」「這裡不好用」之類的意見，也歡迎透過 Marshmallow 告訴作者。

只靠瀏覽器就能運作的免費工具。做出來的 CSS 可以自由使用。
CCFOLIA 的畫面結構若有變動，顯示可能會跑版。這是與任何服務都沒有關係的非官方工具。
