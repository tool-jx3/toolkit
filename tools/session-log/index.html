跑團紀錄簿

𝕏

記錄玩過的團，串起感想、團報與已通關劇本清單的紀錄管理工具。用表格整理歷程，每一列都能連到「團報產生器」。

v1.99 2026.09.13

HOW TO USE

使用方式

1在跑團紀錄表格中新增、編輯玩過的團的資訊。
2用「＋ 新增欄位」／「− 移除欄位」調整要顯示的欄位。
3按最右邊的送出按鈕，就能把資料帶到團報產生器。

SHORTCUTS

快捷鍵

Esc關閉側欄／快捷鍵面板
Ctrl/⌘ + Shift + S開啟快捷鍵面板
Ctrl/⌘ + Shift + N新增一筆跑團紀錄
Ctrl/⌘ + Shift + F移到搜尋欄
Ctrl/⌘ + J匯入（試算表／JSON）
Ctrl/⌘ + E匯出 JSON

IMPORT

匯入跑團紀錄

複製 Excel／Google 試算表／Notion 的表格後貼上，或讀入 CSV／TSV 檔。第一列請放標題。匯入的內容可以直接在下方表格裡編輯。
Notion 的跑團紀錄範本（「已通關劇本」「Play Log」等）可以複製表格或匯出 CSV 後匯入。

預覽

點儲存格即可編輯／用標題的 ▼ 指定每一欄對應的欄位。

貼上過去的團報（X 貼文等），或本工具的「匯出文字」。多筆之間請空兩行以上，或插入 --- 分隔線。自動擷取後可以在下方預覽確認。

選擇 CCFOLIA 的房間資料（.json）、聊天紀錄（.html），或 Dodontof／Tekey 的紀錄（可多選）。會從房間名稱推測劇本名稱、從角色名稱與擲骰次數推測 PC、從時間戳記推測日期，再轉成試算表格式。請在該分頁確認、編輯內容後再匯入。
多選聊天紀錄時，會把每份紀錄當成不同場次，各轉成一列（房間資料 .json 會當作同一團的線索一起使用）。

會把有擲骰的日子全部抓出來，填成多個日期。如果只是跨過午夜 0 點而多出日期，請在這裡刪掉。

指定發言者（依擲骰次數由多到少・只有 PC 會套用到下方欄位）
