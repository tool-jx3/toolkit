                    使用說明
                    
                

                

                    

                        
基本流程

                        

                            add_circle
                            

                                
新增 NPC

                                
用左側面板的「＋ 新增」按鈕新增 NPC，點清單裡的項目即可切換。不需要的 NPC 可以按 ✕ 刪除（至少會留下 1 個）。

                            

                            tune
                            

                                
選擇版本

                                
用 EDIT 面板右上角的 CoC7 / CoC6 切換版本。切換後，衍生屬性（HP、DB 等）會自動重新計算。

                            

                            casino
                            

                                
輸入屬性／擲骰

                                

                                    在骰子欄輸入算式（例：3D6），按各欄的 casino 按鈕個別擲骰，或按「全部擲骰」一次擲完。CoC 7 版的結果會自動 ×5。
                                

                            

                            monitor_heart
                            

                                
確認／編輯衍生屬性

                                
HP、MP、DB 等會由屬性自動計算，也可以手動覆寫。用 SAN 開關可以切換要不要輸出理智。

                            

                            psychology
                            

                                
新增技能

                                
用「新增技能」按鈕新增一列技能，輸入技能名稱與成功率（%）。CoC 6 版還要選擇檢定類型（CC / CCB）。

                            

                            code
                            

                                
新增指令／傷害

                                

                                    登錄武器攻擊等的骰子算式。在算式中寫 DB 或 db，會轉換成對傷害加值的參照（例：1D6+2+DB）。
                                

                            

                        


                        
輸出面板

                        

                            data_object
                            

                                
CCFOLIA（JSON）分頁

                                
輸出可以直接貼到 CCFOLIA 等處的角色 JSON。按「複製」按鈕即可複製到剪貼簿。

                            

                            chat
                            

                                
聊天面板分頁

                                
輸出 BCDice 用的聊天面板，內含屬性、技能、指令與狀態註解。

                            

                            replay
                            

                                
擲骰並複製

                                
一次擲完所有屬性後立刻複製，大量製作 NPC 時很方便。

                            

                        


                        
資料儲存

                        

                            save
                            

                                
自動儲存

                                
輸入的內容會自動儲存在瀏覽器裡（localStorage），關閉頁面後，下次開啟時會還原。

                            

                            warning
                            

                                
注意

                                
清除瀏覽器資料時，NPC 資料也會一起消失。重要的角色請複製 JSON 另外保存。
