ツールバー

build
ツールの構成
左のツールバーに全ツールを「基本図形 / 地図 / 共通」のセクションで配置。どのツールもいつでも使えます。

基本図形ツール

crossword
セル塗り (B)
ペン / 消しゴム / 塗りつぶしの 3 モード。グリッドのマス単位で塗る。同色は自動でまとまった面として描かれる。
crop_square
矩形 / 楕円 (R / E)
1 クリック目で開始点、2 クリック目で対角を確定。楕円は「枠 / 中心→半径 (正円)」を設定パネルで切替可。塗り色・線色・線幅・角丸を指定。
timeline
直線 / 折線 / 多角形 / 曲線 / 閉曲線 (L / P / G / C / Shift+C)
クリックで頂点追加 → Enter で確定 / Esc でキャンセル。折線・多角形は設定パネルの「角丸」で角を丸められます。スナップ点 (頂点 / 中点) に吸着。

地図ツール

landscape
地面
セル / 矩形 / 楕円 / 多角形 / 閉曲線 で床面を塗ります。パターン (草・水・石畳など) または単色を選択。
outdoor_garden
壁
矩形 / 楕円 / 直線 / 折線 / 多角形 / 曲線 / 閉曲線 で壁を線として描画。太さとパターンを設定可能。
home
部屋
矩形 / 楕円 / 多角形 / 閉曲線 を描くと「地面 + 外周壁」がセットで生成されてグループ化。地面と壁のパターンは独立設定可。
chair
装飾
家具 (ベッド・椅子・机・トイレ・テーブル等)・ドア・木・地図記号などの SVG / 画像スタンプを配置。SVG はピッカーで色変更、サイズ・回転・反転も自由。間取り図の家具は実寸スケールで揃えてあります。

共通ツール

draw
フリーハンド (D)
マウス/タッチドラッグでブラシ描画。ブラシ種 (鉛筆 / 円 / スプレー / 消しゴム) や線幅・色・平滑化を設定可能。
title
テキスト / 画像 (T / I)
テキストは書式 (太字・斜体・下線・取消線) を部分適用可。画像は読み込んで配置・拡縮できます。

作図の便利機能

square_foot
計測表示 (HUD)
作図中、図形に沿って寸法を表示。矩形 / 楕円は縦横のマス数、正円は半径、直線 / 折線 / 多角形は長さ・角度・縦横マス数、曲線は制御点とマス数。マスを数えずに作図できます。
rounded_corner
角丸 (フィレット)
矩形に加え、折線・多角形も設定パネルの「角丸」で角を丸められます。
grid_goldenratio
スナップ
交点 (格子点) / セル中心 / 辺の中点に吸着。設定パネルで対象を切替。Shift 押下中は一時無効。移動時のスナップはオブジェクト中心が基準です。

パターン・装飾

texture
パターン選択
各タブのパターンピッカーでテクスチャを選択。「単色」ピックでカラー指定も可。パターン詳細でオフセット・回転・倍率を微調整。
upload
ユーザー素材アップロード
パターン / 装飾の「ユーザー」ジャンルにある「＋」タイルから PNG / JPG / WebP / SVG を追加。マップごとに保存され、次回もそのまま使えます。

レイヤー / 選択

layers
レイヤーパネル
右側のパネルでオブジェクト一覧を確認、表示/非表示・並び替え・名前変更・削除。ダブルクリックで名前編集。
content_copy
アクションバー
選択枠の上に表示。複製 (複製元のすぐ上に配置) / 表示・非表示 / ロック / 最前面・最背面 / 削除。複数選択時はグループ化やブール演算も。
folder
グループ化 (Ctrl+G / Ctrl+Shift+G)
選択ツールで複数選択 → アクションバーのフォルダボタンまたは Ctrl+G でグループ化。Ctrl+Shift+G で解除。
join_full
ブール演算
同種の図形を 2 つ以上選択 → 選択枠上のバーで「合体 / 交差 / 差 / 排他」を実行。複雑な形を効率的に作れます。
opacity
不透明度 / ブレンド
レイヤーパネルから個別に不透明度・ブレンドモード (通常 / 上重ね / 切り抜き / XOR / 乗算など多数) を設定。
content_cut
グループ内だけ切り抜き
「切り抜き」などのブレンドはそのままだと下の全レイヤーに効きますが、対象をグループ化するとグループ内だけに限定できます。

保存と出力

save
自動保存
編集中は約 2.5 秒間隔で IndexedDB に自動保存。ヘッダーの「保存済み / 未保存」表示で状態を確認できます。Ctrl+S で即時保存 + サムネ再生成。設定パネルの「自動保存」をオフにすると自動保存しません (Ctrl+S で手動保存)。
download
画像出力
ツールバーの「出力」を押して範囲をドラッグ → PNG / JPEG / SVG でダウンロード。背景の透明 / 白、グリッド表示、解像度を選択可。
undo
Undo / Redo
Ctrl+Z で取消、Ctrl+Shift+Z または Ctrl+Y でやり直し。最大 50 ステップ保持。

主要ショートカット

keyboard
編集

ads_click
ツール切替

キャンバス操作
Space ドラッグで移動 / マウスホイールでズーム
