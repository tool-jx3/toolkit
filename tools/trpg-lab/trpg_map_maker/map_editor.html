使用說明

工具列

build
工具配置
左側工具列依「基本圖形／地圖／共通」分區排列所有工具，任何工具隨時都能使用。

基本圖形工具

crossword
格子填色 (B)
有畫筆／橡皮擦／填滿 3 種模式，以網格的格子為單位上色。同一種顏色會自動合併成一整塊。
crop_square
矩形／橢圓 (R / E)
第 1 次點擊決定起點，第 2 次點擊決定對角。橢圓可以在設定面板切換「外框／中心→半徑（正圓）」。可指定填色、線條顏色、線寬與圓角。
timeline
直線／折線／多邊形／曲線／封閉曲線 (L / P / G / C / Shift+C)
點擊新增頂點 → 按 Enter 確定／按 Esc 取消。折線與多邊形可以用設定面板的「圓角」把轉角修圓。會吸附到吸附點（頂點／中點）。

地圖工具

landscape
地面
用格子／矩形／橢圓／多邊形／封閉曲線塗滿地板。可以選單色，或是自己上傳的圖樣。
outdoor_garden
牆壁
用矩形／橢圓／直線／折線／多邊形／曲線／封閉曲線把牆壁畫成線條，可以設定粗細與圖樣。
home
房間
畫出矩形／橢圓／多邊形／封閉曲線後，會一起產生「地面＋外圍牆壁」並組成群組。地面與牆壁的圖樣可以分開設定。
chair
裝飾
放置家具（床、書桌、書架等）、門、樹木、地圖符號等 SVG／圖片圖章。SVG 可以用顏色選擇器改色，大小、旋轉、翻轉也能自由調整。

共通工具

draw
手繪 (D)
用滑鼠或觸控拖曳以筆刷作畫。可以設定筆刷種類（鉛筆／圓點／噴槍／橡皮擦）、線寬、顏色與平滑化。
title
文字／圖片 (T / I)
文字可以只對部分內容套用格式（粗體、斜體、底線、刪除線）。圖片讀取後可以放置並縮放。

繪圖輔助功能

square_foot
測量顯示（HUD）
繪製時會沿著圖形顯示尺寸：矩形／橢圓顯示長寬格數，正圓顯示半徑，直線／折線／多邊形顯示長度、角度與長寬格數，曲線顯示控制點與格數。不用數格子也能畫。
rounded_corner
圓角（Fillet）
除了矩形，折線與多邊形也能用設定面板的「圓角」把轉角修圓。
grid_goldenratio
吸附
吸附到交點（格點）／格子中心／邊的中點，可以在設定面板切換對象。按住 Shift 時暫時停用。移動物件時以物件中心為吸附基準。

圖樣・裝飾

texture
選擇圖樣
在各分頁的圖樣選擇器挑選紋理，也可以點「單色」指定顏色。在「圖樣細節」可以微調偏移、旋轉與縮放。
upload
上傳自訂素材
從圖樣／裝飾「自訂」分類裡的「＋」方塊加入 PNG／JPG／WebP／SVG。素材會跟著每張地圖一起儲存，下次開啟也能直接使用。

圖層／選取

layers
圖層面板
在右側面板查看物件清單，可以顯示／隱藏、調整順序、重新命名與刪除。雙擊可以編輯名稱。
content_copy
動作列
顯示在選取框上方：複製（放在原物件的正上一層）／顯示・隱藏／鎖定／移到最上層・最下層／刪除。多選時還可以群組或做布林運算。
folder
群組 (Ctrl+G / Ctrl+Shift+G)
用選取工具多選 → 按動作列的資料夾按鈕或 Ctrl+G 建立群組，Ctrl+Shift+G 解散群組。
join_full
布林運算
選取 2 個以上同類的圖形 → 用選取框上方的列執行「聯集／交集／差集／互斥」，可以有效率地做出複雜形狀。
opacity
不透明度／混合模式
在圖層面板個別設定不透明度與混合模式（正常／覆蓋於上／挖空／XOR／色彩增值等多種）。
content_cut
只在群組內挖空
「挖空」等混合模式直接使用時會作用到下方所有圖層；把對象組成群組後，就能只在群組內生效。

儲存與匯出

save
自動儲存
編輯時大約每 2.5 秒自動儲存到 IndexedDB，可以從頁首的「已儲存／未儲存」確認狀態。按 Ctrl+S 會立即儲存並重新產生縮圖。在設定面板關閉「自動儲存」後就不會自動儲存（請用 Ctrl+S 手動儲存）。
download
匯出圖片
按工具列的「匯出」後拖曳出範圍 → 以 PNG／JPEG／SVG 下載。可以選擇背景透明或白色、是否顯示網格與解析度。
undo
復原／重做
按 Ctrl+Z 復原，按 Ctrl+Shift+Z 或 Ctrl+Y 重做，最多保留 50 步。

keyboard
編輯

ads_click
切換工具

D 手繪 / T 文字 / I 圖片
pan_tool
畫布操作
按住 Space 拖曳可以移動／滑鼠滾輪縮放
按住 Shift 時暫時停用吸附
