狀態條產生器

製作「自訂 CSS」，把 CCFOLIA 角色的 HP、MP、SAN 等數值以喜歡的樣式顯示在 OBS 上。數值會與 CCFOLIA 連動。所有處理都在瀏覽器內完成，輸入的內容不會傳送到任何地方。

歸零時
越少越損壞

剩餘量每低於 75%・50%・25%，裂痕就會增加，歸零時碎裂。道具會從右邊依序損壞。把排列數量設成與最大值相同，每減少 1 點就會壞掉 1 個（HP 12 就是 12 個）。放了道具之後，條左邊的「符號」就不會顯示。

CCFOLIA 的紅色數字

CCFOLIA 在目前值低於最大值的 80% 時會把數字變紅（與危急判定無關）。不使用時，數值減少也會維持平常的文字顏色。

在 OBS 的設定

  1. 新增來源 →「瀏覽器」。在 URL 欄填入角色的 URL：
    https://ccfolia.com/rooms/{房間ID}/characters/{角色ID}
  2. 寬度與高度請填上方顯示的 瀏覽器來源尺寸。
  3. 把「自訂 CSS」的內容全部刪掉，貼上剛才複製的 CSS。
  4. 如果畫面一片空白，在來源上按右鍵 →「互動」登入 CCFOLIA 並進入房間（做過一次就會記住）。
  5. 第二位角色起，請用「新增來源」→「瀏覽器」另外建一個，再把 URL 與 CSS 換成該角色的。瀏覽器來源受 OBS 的限制無法複製（「貼上複本」一直是灰的），用「貼上參照」增加則會讓所有人變成同一個角色。大小與位置可以用右鍵 →「複製變換」→「貼上變換」對齊。

在 CCFOLIA 的設定

  • 角色「狀態」的排列順序會對應第 1 條、第 2 條⋯的顏色（例：HP → MP → SAN）。
  • 在聊天室輸入 :HP-3、:SAN=45 之類的指令，OBS 那邊也會立刻跟著變動。
  • 設為「隱藏狀態」的角色，除了持有者以外都不會顯示狀態條。

使用電腦上安裝的字型時

  • 在字型欄選「以名稱指定（電腦字型）」，再填入字型名稱。Chrome／Edge 可以用「從清單選」，直接看樣子挑電腦上有的字型（第一次會詢問使用字型的權限）。
  • OBS 是用自己那台電腦的字型顯示的，所以請在跑 OBS 的電腦上也裝同一套字型。沒裝的話會變回一般的黑體。
  • 字型若沒有漢字，只有漢字的部分會變回一般的黑體（可以用清單樣張裡的「永」確認）。
只靠瀏覽器就能運作的免費工具。做出來的 CSS 可以自由使用。
CCFOLIA 的畫面結構若有變動，顯示可能會跑版。這是與任何服務都沒有關係的非官方工具。
