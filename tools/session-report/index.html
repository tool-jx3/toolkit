✦ A 團報產生器

v1.70 2026.09.09

參考社群上團報的寫法，產生多種風格、適合貼到 X 的團報文。 輸入劇本名稱、參加者、END 與裝飾風格，就能做出方便複製的團報文。

使用方式

  1. 從團報範本清單選擇想用的文案風格。
  2. 輸入系統、劇本名稱、KP / GM / DL、PC / PL、END 等資料。
  3. 視需要選擇文字樣式或文字藝術，也可以直接編輯右側的預覽。
  4. 完成後按「複製」，或用下方的「貼到 𝕏」開啟貼文畫面。

快捷鍵

Cmd / Ctrl + Shift + C
複製預覽內文（也可以用 Cmd / Ctrl + Enter）。
Cmd / Ctrl + Shift + P
把預覽內文貼到 𝕏。
Cmd / Ctrl + Z
復原一次預覽的編輯。
Cmd / Ctrl + Shift + Z
重做剛才復原的編輯。
Cmd / Ctrl + E
把游標移到預覽編輯欄。
Cmd + Option + ↑ / ↓
切換上一個／下一個團報範本。
Cmd + Option + ← / →
切換上一個／下一個文字樣式（字型）。
Cmd + Option + R
捨棄手動編輯，依輸入內容重新產生預覽。
?
開啟／關閉這個快捷鍵面板。
Esc
關閉使用方式／快捷鍵面板。

Windows 請把 Cmd 換成 Ctrl、Option 換成 Alt。

輸入

只參考社群實例的結構做成的範本。

只轉換範本指定的部分，例如系統名稱、職位、標記、END、日期等。

敬稱

按綠色的＋可以新增主持人。KPC/KP 型的範本，在名字欄填成「KPC名稱 / KP名稱」會比較好看。

每一行輸入 HO、PC 名稱、PL 名稱。HO 補充通常不用填。

標記選 PC/PL 或 PL/PC 時會反映在標題；PC1、HO1 會顯示在各自的那一行。

點一下就會插入到右側預覽目前的游標位置。
