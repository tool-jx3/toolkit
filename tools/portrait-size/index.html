這個工具能做什麼

解決在 CCFOLIA 切換角色立繪時，棋子圖突然變大或變小的問題。
檔案全部在你的瀏覽器裡處理，不會傳送到任何伺服器。

◆為什麼尺寸會變

CCFOLIA 是用圖片的寬度決定棋子圖大小的

舉例：
• 一般立繪：寬 500px → 棋子圖大小正常
• 戰鬥立繪（拿著武器）：寬 700px → 會被縮小到與一般立繪相同，棋子圖因此變小
• 幼年差分：寬 300px → 會被放大到與一般立繪相同，棋子圖因此變大

就算是同一個角色，只要姿勢或差分的寬度不同，每次切換立繪棋子圖的大小就會跟著變

◆使用方式

  • 一次載入多張圖片 — 把同一角色的差分（一般、戰鬥、幼年等）全部選起來
  • 按下「處理圖片」 — 刪掉透明留白，再統一成最寬那張的寬度
  • 用「全部下載」儲存 — 把處理好的圖片一次存下來

結果：所有圖片的寬度一致，切換立繪時棋子圖的大小不會變，身高差與姿勢也照原樣保留

◆備註

  • 前提是立繪本來就以同一比例繪製。若不是這樣（例如小孩畫在大畫布、大人畫在小畫布），只統一寬度反而會讓實際的體型差跑掉
  • 同時也會裁掉圖片的透明部分
  • 也可以只放一張圖，單純拿來裁掉透明部分並縮減檔案大小
