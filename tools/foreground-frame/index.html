前景框產生器

製作 CCFOLIA 前景用的「框」圖片。組合形狀、顏色與裝飾來設計，還能把天氣、時間帶等差分一次匯出。所有處理都在瀏覽器內完成，圖片不會傳送到任何地方。

      還沒有任何項目。

      選取中的素材

      製作差分時，{差分} 會換成「早晨」「雨」等名稱，{英文} 會換成「MORNING」等英文標示。

      差分

      把同一個框，依天氣或時間帶等條件做出好幾張的功能。每個差分都能改變顏色、窗的效果（雨、雪等）與標示，並打包成 ZIP 一次儲存。素材與裝飾也能依差分分別顯示。

      種類

      更換種類會整批替換下方的清單（可用 Ctrl+Z 復原）。不論哪一種，名稱與效果都能自由修改。

      差分清單

        點擊即可編輯與預覽。取消勾選的差分不會匯出。

        「」的設定

        色彩覆蓋與效果會疊在窗的部分。可以讓透過窗看到的背景在夜晚變暗、在雨天像隔著雨看一樣。

        差分標示

        也可以直接在預覽上拖曳移動。

        專案

        編輯內容會自動存在這個瀏覽器裡。要帶到別台電腦或備份時，請用「儲存專案」（載入的圖片與字型也會一起存進去）。

        字型

          支援 .ttf / .otf / .woff / .woff2。電腦上已安裝的字型，可以從字型欄的「以名稱指定」使用（Chrome／Edge 可用「從清單選」邊看樣子邊挑）。

          預覽背景

          放上打算用作房間背景的圖片，比較容易確認成品效果。背景不會包含在匯出的圖片裡。

          使用方式

          • 在「框」分頁決定形狀、顏色與線條，在「裝飾」分頁疊上藤蔓或花朵。選擇範本會整套一次替換。
          • 自己的素材與文字請到「素材與文字」分頁。可以在預覽上拖曳移動（方向鍵微調、Shift 加大幅度、Delete 刪除）。
          • 想依天氣或時間帶做出好幾張時，請到「差分」分頁打開製作差分。每個差分都能改變顏色與窗的效果，並打包成 ZIP 一次儲存。
          • 預覽中的「風景」只是確認成品用的範例。匯出的圖片中，窗的部分會是透明的。

          在 CCFOLIA 的設定

          • 在盤面的前景上按兩下（或按右鍵 →「變更前景／背景」），把匯出的 PNG 選為前景。
          • 前景的寬與高請填「框」分頁輸出尺寸下方顯示的格數（寬 1 = 24px）。比例不符時，自動裁切關閉會把圖片拉伸，開啟則會切掉邊緣。
          • 窗的部分是透明的，房間的背景圖片會透出來。
          • 為每個差分先建立一個場景，切換就只要一瞬間（場景會保存前景、背景、BGM 與標記面板）。
